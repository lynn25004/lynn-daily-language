# 2026-10-12（週一）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **firmware** (n.) — 韌體，介於硬體和軟體之間
   - *Updating the firmware usually fixes a lot of bugs.*
   - 更新韌體通常能修復許多錯誤。
2. **optimize** (v.) — 優化、最佳化，使效率提升
   - *We need to optimize the code for better performance.*
   - 我們需要優化程式碼以提升效能。
3. **troubleshoot** (v.) — 排除故障、解決技術問題
   - *I spent all morning trying to troubleshoot the network issue.*
   - 我花了整個早上在排除網路問題。
4. **prototype** (n.) — 產品的初步模型或樣品
   - *The team is building a prototype for the new IoT device.*
   - 團隊正在為新的物聯網裝置建造一個原型。
5. **integrate** (v.) — 將不同部分結合為一體
   - *We need to integrate this module into the main system.*
   - 我們需要將這個模組整合到主系統中。
6. **efficient** (adj.) — 高效的、有效率的，不浪費資源
   - *This new algorithm for data processing is much more efficient.*
   - 這個用於數據處理的新演算法效率高很多。
7. **debug** (v.) — 修復程式中的錯誤
   - *I spent hours debugging this tricky error in the code.*
   - 我花了數小時在除錯程式碼中這個棘手的錯誤。
8. **deploy** (v.) — 將軟體或系統上線運行
   - *The new software will be deployed next week.*
   - 這個新軟體將於下週部署上線。
9. **feedback** (n.) — 關於工作或產品的回饋、意見
   - *We got some good feedback on the new design.*
   - 我們收到了關於新設計的一些良好回饋。
10. **colleague** (n.) — 工作上的合作夥伴
   - *My colleague helped me with the project last week.*
   - 我的同事上週幫助了我這個專案。

## 📘 英文文法
### 未來式 (will / be going to)
表達未來計畫、預測或自發決定，will更廣泛，be going to多用於確定計畫。
- I will check the system logs tomorrow morning. (我明天早上會檢查系統日誌。)
- We are going to launch the new feature next month. (我們下個月將會推出新功能。)
- Oh, the server crashed! I'll restart it right away. (喔，伺服器當了！我馬上重啟它。)
### 過去進行式 (Past Continuous)
描述過去某特定時間點正在進行的動作，常與簡單過去式一同使用。
- I was working on the embedded system when you called. (你打電話來時，我正在處理嵌入式系統。)
- While she was debugging, the power went out. (她正在除錯時，停電了。)
- They were discussing the IoT project all afternoon. (他們整個下午都在討論那個物聯網專案。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - しごとはどうですか？
   - 工作怎麼樣？
2. **まいにち** / 毎日 / mainichi — 每天
   - 毎日コーヒーを飲みます。
   - 我每天都喝咖啡。
3. **でんき** / 電気 / denki — 電、電力、電燈
   - このへやはでんきがくらいです。
   - 這房間的電燈很暗。
4. **べんきょう** / 勉強 / benkyou — 學習、讀書
   - 日本語をべんきょうします。
   - 我學習日文。
5. **すき** / 好き / suki — 喜歡
   - わたしはAIツールがすきです。
   - 我喜歡AI工具。
6. **あたらしい** / 新しい / atarashii — 新的
   - あたらしいスマホがほしいです。
   - 我想要一台新手機。
7. **じかん** / 時間 / jikan — 時間
   - しごとのおわりにじかんがありますか。
   - 工作結束後有時間嗎？
8. **いそがしい** / 忙しい / isogashii — 忙碌的
   - きょうはいそがしいです。
   - 今天很忙。
9. **はじめる** / 始める / hajimeru — 開始
   - プロジェクトをはじめる。
   - 開始專案。
10. **わかる** / 分かる / wakaru — 懂、明白
   - わたしはそれがわかります。
   - 我明白那個。

## 🗾 日文文法（N5）
### 〜ます / 〜ません (Masu Form)
**結構**：動詞ます形 / 動詞ません形
表示現在或未來發生的動作，或習慣性的行為，是禮貌體。
- 毎日日本語を勉強します。 (我每天學習日文。)
- このシステムはまだ動きません。 (這個系統還不會動。)
### 名詞 + は + 名詞 + です / ではありません
**結構**：名詞 + は + 名詞 + です / ではありません
用於介紹或說明主語的身份、狀態或屬性，是日文最基本的肯定/否定句型。
- わたしはエンジニアです。 (我是工程師。)
- これはわたしのパソコンではありません。 (這不是我的電腦。)
