# 2026-08-30（週日）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **optimize** (v.) — 優化，使其達到最佳
   - *We need to optimize the code for better performance.*
   - 我們需要優化程式碼以獲得更好的效能。
2. **integrate** (v.) — 整合，結合不同部分
   - *It's challenging to integrate new features into old systems.*
   - 將新功能整合到舊系統中很有挑戰性。
3. **troubleshoot** (v.) — 排除故障，解決問題
   - *I spent all morning troubleshooting the network issue.*
   - 我整個早上都在排除網路問題。
4. **prototype** (n./v.) — 原型/製作原型
   - *Let's build a quick prototype to test the idea.*
   - 我們快速做個原型來測試這個想法吧。
5. **debug** (v.) — 除錯，找出錯誤並修復
   - *I'm trying to debug this tricky error in my code.*
   - 我正在努力修復程式碼中這個棘手的錯誤。
6. **schedule** (n./v.) — 行程表/安排時間
   - *What's your schedule like for next week?*
   - 你下週的行程是怎樣的？
7. **prioritize** (v.) — 優先處理，排列順序
   - *We need to prioritize urgent tasks first.*
   - 我們需要先優先處理緊急任務。
8. **feedback** (n.) — 回饋意見，反應
   - *Could you give me some feedback on my resume?*
   - 你能給我一些關於我履歷的回饋意見嗎？
9. **solution** (n.) — 解決方案，解答
   - *We're looking for a good solution to this problem.*
   - 我們正在尋找這個問題的好解決方案。
10. **update** (v./n.) — 更新/最新消息
   - *Did you update the software to the latest version?*
   - 你把軟體更新到最新版本了嗎？

## 📘 英文文法
### 假設語氣 (Conditional Sentences Type 1)
用於表達未來可能發生且結果真實的狀況，結構為 If + 主詞 + 現在簡單式, 主詞 + will + 原形動詞。
- If the system works, we will launch it next month. (如果系統能運作，我們下個月就會推出。)
- If you debug it well, the project will be smooth. (如果你除錯做得好，這個專案就會很順利。)
- If I finish my tasks, I'll go for a run later. (如果我做完我的工作，我等下會去跑步。)
### 動名詞 (Gerunds) 作為主詞或受詞
動名詞以 -ing 結尾，可以像名詞一樣在句子中作主詞、受詞或介系詞的受詞，表達動作的行為。
- Learning new skills is crucial for engineers. (學習新技能對工程師來說至關重要。)
- I enjoy reading about embedded systems. (我喜歡閱讀有關嵌入式系統的內容。)
- Debugging code can be quite frustrating sometimes. (除錯程式碼有時可能會非常令人沮喪。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - しごとは どこですか。
   - 你的工作在哪裡？
2. **べんきょう** / 勉強 / benkyou — 學習
   - まいにち にほんごを べんきょうします。
   - 我每天學習日文。
3. **やすみ** / 休み / yasumi — 休息、假日
   - きょうは 休みです。
   - 今天是假日。
4. **ぎじゅつ** / 技術 / gijutsu — 技術
   - この ぎじゅつは すごいですね。
   - 這項技術真厲害呢。
5. **つくる** / 作る / tsukuru — 製作、製造
   - IoT デバイスを つくります。
   - 我製作 IoT 裝置。
6. **しる** / 知る / shiru — 知道、了解
   - あの ことを 知っていますか。
   - 你知道那件事嗎？
7. **まいにち** / 毎日 / mainichi — 每天
   - 毎日 コーヒーを 飲みます。
   - 我每天喝咖啡。
8. **むずかしい** / 難しい / muzukashii — 困難的
   - この プロジェクトは 難しいです。

9. **おもしろい** / 面白い / omoshiroi — 有趣的

10. **わかる** / 分かる / wakaru — 懂、明白
   - 日本語が わかりますか。
   - 你懂日文嗎？

## 🗾 日文文法（N5）
### 名詞 + は + 名詞 + です (基本句型)
**結構**：名詞 A + は + 名詞 B + です
用於表示「A 是 B」的肯定句，其中「は」讀作「wa」，是提示主語的助詞。
- わたしは エンジニアです。(我是工程師。)
- これは IoT デバイスです。(這是 IoT 裝置。)
### 動詞ます形 + たいです (想做...)
**結構**：動詞ます形 + たいです
表示說話者「想做某事」的願望或意願，將動詞的ます形後面的ます去掉，加上たいです。
- 日本語を 勉強したいです。(我想學習日文。)
- 新しい 技術を 習いたいです。(我想學習新技術。)
