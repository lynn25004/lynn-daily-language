# 2026-09-25（週五）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 實施、執行計畫
   - *We need to implement this new feature by next week.*
   - 我們需要在下週前實施這個新功能。
2. **optimize** (v.) — 優化、最佳化
   - *Let's optimize the code for better performance and speed.*
   - 我們來優化程式碼以提升效能和速度吧。
3. **troubleshoot** (v.) — 故障排除、解決問題
   - *Can you help me troubleshoot this network issue quickly?*
   - 你能幫我快速排除這個網路問題嗎？
4. **deadline** (n.) — 截止日期、最後期限
   - *The deadline for this report is super tight, unfortunately.*
   - 這份報告的截止日期超級趕，真可惜。
5. **prototype** (n.) — 原型、樣本
   - *The team is building a prototype for the new IoT device.*
   - 團隊正在為新的物聯網設備製作原型。
6. **feature** (n.) — 功能、特色
   - *This new app has a cool AI feature for productivity.*
   - 這個新應用程式有一個很酷的AI生產力功能。
7. **commute** (v.) — 通勤、上下班
   - *My commute to work usually takes about an hour each way.*
   - 我上班通勤通常單程要花大約一個小時。
8. **sustainable** (adj.) — 永續的、可持續的
   - *Renewable energy is key for a more sustainable future.*
   - 再生能源是實現更永續未來的關鍵。
9. **integrate** (v.) — 整合、合併
   - *We need to integrate this module into the main system soon.*
   - 我們需要很快把這個模組整合到主系統裡。
10. **recharge** (v.) — 充電、恢復精力
   - *I really need to recharge my batteries this long weekend.*
   - 這個長週末我真的需要好好休息充電。

## 📘 英文文法
### Used to (過去習慣) vs. Be used to (習慣於)
'Used to' 指過去的習慣或狀態，現在已不同；'be used to' 指習慣某事，不再感到陌生。
- I used to work late every night, but not anymore. (我以前習慣每天工作到很晚，但現在不了。)
- I am used to working with AI tools now, they're super handy. (我現在已經習慣使用AI工具了，它們超級好用。)
- He is still getting used to the new embedded system. (他還在適應新的嵌入式系統。)
### First Conditional (If + 現在簡單式, will + 原形動詞)
用來描述未來可能發生且結果可預期的情況，表示條件與結果之間有高度關聯。
- If I finish my project early, I will go hiking this weekend. (如果我提早完成專案，這個週末我就去健行。)
- If the embedded system works, we will launch it next month. (如果嵌入式系統能運作，我們下個月就會發布它。)
- If you study hard, you will pass the JLPT N5 exam easily! (如果你努力學習，你會輕易通過日文N5考試的！)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - きょう、しごとがおわります。
   - 今天工作會結束。
2. **おわります** / 終わります / owarimasu — 結束
   - いつしごとがおわりますか。
   - 工作什麼時候會結束呢？
3. **やすみ** / 休み / yasumi — 休息、假日
   - しゅうまつはやすみです。
   - 週末是假日。
4. **しゅうまつ** / 週末 / shuumatsu — 週末
   - しゅうまつ、なにをしますか。
   - 週末要做什麼呢？
5. **どこか** / dokoka — 某處、哪裡
   - しゅうまつにどこかいきますか。
   - 週末要去哪裡嗎？
6. **いきます** / 行きます / ikimasu — 去
   - としょかんにいきます。
   - 我去圖書館。
7. **たべます** / 食べます / tabemasu — 吃
   - ひるごはんをたべます。
   - 我吃午餐。
8. **べんきょう** / 勉強 / benkyou — 學習
   - まいにち、にほんごをべんきょうします。
   - 我每天學習日文。
9. **とても** / totemo — 非常
   - このえいがはとてもたのしいです。
   - 這部電影非常有趣。
10. **たのしい** / 楽しい / tanoshii — 快樂的、有趣的
   - しゅうまつはたのしいです。
   - 週末很開心。

## 🗾 日文文法（N5）
### 動詞 ~ます / ~ません (基本肯定與否定)
**結構**：動詞ます形 / 動詞ません形
動詞ます形表示肯定現在或未來行為；動詞ません形表示否定現在或未來行為。
- わたしはしごとをします。 (我會工作。)
- わたしはきょう、えいがをみません。 (我今天不看電影。)
### 名詞 + を + 動詞(ます形)
**結構**：名詞 + を + 動詞(ます形)
助詞「を」表示動詞的直接受詞，標明動詞作用的對象。
- わたしはパンをたべます。 (我吃麵包。)
- かれはしごとをします。 (他工作。)
