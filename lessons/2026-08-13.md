## 🇬🇧 英文單字（TOEIC 600-800）
1. **optimize** (v.) — 最佳化，優化
   - *We need to optimize the code for better performance.*
   - 我們需要優化程式碼以獲得更好的效能。
2. **integrate** (v.) — 整合，融入
   - *This new module integrates well with the existing system.*
   - 這個新模組與現有系統整合得很好。
3. **troubleshoot** (v.) — 排除故障，解決問題
   - *I spent all morning trying to troubleshoot this network issue.*
   - 我花了一整個早上試圖排除這個網路問題。
4. **scenario** (n.) — 情境，局面
   - *Let's consider a few different scenarios for this project.*
   - 讓我們為這個專案考慮幾種不同的情境。
5. **efficiency** (n.) — 效率
   - *We should always look for ways to improve efficiency.*
   - 我們應該總是尋找提高效率的方法。
6. **prototype** (n.) — 原型，樣品
   - *We're building a prototype to test our new design.*
   - 我們正在製作一個原型來測試我們的新設計。
7. **algorithm** (n.) — 演算法
   - *The new AI algorithm is super powerful.*
   - 這個新的 AI 演算法超級強大。
8. **sustainable** (adj.) — 可持續的，永續的
   - *Renewable energy is key to a sustainable future.*
   - 再生能源是永續未來的關鍵。
9. **feedback** (n.) — 回饋，意見
   - *We always welcome feedback from our users.*
   - 我們總是歡迎使用者的回饋。
10. **deploy** (v.) — 部署，配置
   - *We're planning to deploy the new software next week.*
   - 我們計畫下週部署新軟體。

## 📘 英文文法
### 情態助動詞 "should" 的用法
"should" 用來表示建議、義務或預期會發生的事，語氣比 "must" 柔和。
- You should try to get some rest after work. (你下班後應該好好休息一下。)
- We should check the data before presenting it. (我們在展示前應該先檢查數據。)
- The system should be up and running by noon. (系統應該會在中午前啟動並運行。)
### 現在完成式 (Present Perfect)
用於描述從過去開始，持續到現在的動作或經驗，或對現在有影響的過去事件。
- I have worked on several IoT projects. (我曾參與過幾個物聯網專案。)
- She has learned a lot about AI tools recently. (她最近學了很多關於 AI 工具的知識。)
- Have you ever optimized embedded systems? (你曾優化過嵌入式系統嗎？)

## 🗾 日文文法（N5）
### 動詞ます形 + たいです (想做某事)
**結構**：動詞ます形 + たいです
表示說話者「想要做」某個動作，用於表達願望或希望。
- 日本で働きたいです。 (我想在日本工作。)
- 新しいAIツールを使いたいです。 (我想使用新的 AI 工具。)
### 名詞 + を + 動詞 (受格助詞「を」)
**結構**：名詞 + を + 動詞(ます)
助詞「を」放在動詞的直接受詞之後，表示動作的對象。
- 水を飲みます。 (喝水。)
- 本を読みます。 (讀書。)
