# 2026-09-18（週五）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **prototype** (n.) — 早期模型或原型
   - *We're building a prototype for the new IoT device.*
   - 我們正在為新的物聯網裝置打造一個原型。
2. **deploy** (v.) — 部署、佈局
   - *It's time to deploy the new software update.*
   - 是時候部署這個新的軟體更新了。
3. **efficient** (adj.) — 有效率的、高效的
   - *This new solar panel design is super efficient.*
   - 這個新的太陽能板設計非常有效率。
4. **integrate** (v.) — 整合、合併
   - *We need to integrate the AI tool into our workflow.*
   - 我們需要將 AI 工具整合到我們的日常工作中。
5. **reliability** (n.) — 可靠性
   - *The reliability of renewable energy is crucial.*
   - 再生能源的可靠性至關重要。
6. **innovative** (adj.) — 創新的
   - *Their approach to energy security is really innovative.*
   - 他們處理能源安全的方法非常創新。
7. **streamline** (v.) — 簡化流程
   - *Let's streamline this development process, okay?*
   - 我們來簡化這個開發流程，好嗎？
8. **optimize** (v.) — 優化
   - *We should optimize the code for better performance.*
   - 我們應該優化程式碼以獲得更好的效能。
9. **flexible** (adj.) — 靈活的、可調整的
   - *The system needs to be flexible enough to adapt.*
   - 這個系統需要足夠靈活才能適應。
10. **collaborate** (v.) — 合作
   - *I like to collaborate with my team on new ideas.*
   - 我喜歡和我的團隊合作發想新點子。

## 📘 英文文法
### 現在完成進行式
強調動作從過去開始一直持續到現在，並可能繼續下去。
- I have been working on this project for weeks. (我已經在這個專案上工作好幾個星期了。)
- She has been learning Japanese since last year. (她從去年就開始學日文了。)
- They have been developing a new energy solution. (他們一直在開發新的能源解決方案。)
### 頻率副詞的位置
頻率副詞（如 always, often, usually, sometimes, never）通常放在主要動詞前，be 動詞後。
- I usually work on embedded systems. (我通常在做嵌入式系統。)
- He is always interested in new technology. (他總是對新技術感興趣。)
- We sometimes discuss renewable energy. (我們有時候會討論再生能源。)

## 🇯🇵 日文單字（N5）
1. **ちょう** / 超 / chou — 非常、超級
   - これ、超便利ですよ。
   - 這個，超級方便喔。
2. **じ** / 事 / koto — 事情、事務
   - 大事な仕事があります。
   - 有重要的事情。
3. **か** / か / ka — 或是、還是
   - コーヒーにしますか、紅茶にしますか。
   - 要咖啡還是紅茶呢？
4. **よ** / よ / yo — 語氣助詞，表示告知、強調
   - それはいい考えですよ。
   - 那個是個好主意喔。
5. **て** / て / te — 助詞，用於連接動詞或形容詞
   - 資料を見て、勉強します。
   - 看了資料，然後學習。
6. **つく** / 作る / tsukuru — 製作、製造
   - 新しいシステムを作っています。
   - 正在製作新的系統。
7. **かん** / 感 / kan — 感覺、感受
   - すごいと感じます。
   - 感覺很厲害。
8. **い** / 位 / i — 量詞，用於人
   - 何人いらっしゃいますか。
   - 有多少位呢？
9. **で** / で / de — 助詞，表示場所、手段
   - 会社で働いています。
   - 在公司工作。
10. **ね** / ね / ne — 語氣助詞，表示確認、附和
   - 今日はいい天気ですね。
   - 今天天氣真好呢。

## 🗾 日文文法（N5）
### 〜ている (te iru)
**結構**：動詞て形 + いる
表示正在進行的動作、狀態或習慣。
- 今、何をしていますか。(Ima, nani o shite imasu ka.) (現在在做什麼？)
- 日本語を勉強しています。(Nihongo o benkyou shite imasu.) (我正在學日文。)
### 〜たい (tai)
**結構**：動詞ます形去掉ます + たい
表示「想要做某事」的願望。
- 日本に行きたいです。(Nihon ni ikitai desu.) (我想要去日本。)
- 新しい技術を学びたいです。(Atarashii gijutsu o manabitai desu.) (我想要學習新技術。)
