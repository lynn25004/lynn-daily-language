# 2026-10-20（週二）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **debug** (v.) — 找出並修正程式錯誤
   - *I need to debug this code before the demo.*
   - 我需要在演示前把這段程式碼的錯誤找出來。
2. **prototype** (n.) — 產品或模型的初步原型
   - *We're building a prototype for our new IoT device.*
   - 我們正在為新的物聯網設備製作原型。
3. **implement** (v.) — 執行、實施（計畫或系統）
   - *Let's implement this new feature next week.*
   - 我們下週來實施這個新功能吧。
4. **efficient** (adj.) — 效率高的、有效的
   - *This new algorithm is very efficient.*
   - 這個新演算法非常有效率。
5. **challenge** (n.) — 挑戰、艱鉅的任務
   - *Learning Japanese is a fun challenge for me.*
   - 學習日文對我來說是個有趣的挑戰。
6. **collaborate** (v.) — 合作、協同工作
   - *We should collaborate on this project for better results.*
   - 我們應該在這個專案上合作，以取得更好的成果。
7. **deadline** (n.) — 截止日期、最後期限
   - *I'm trying to meet the deadline for this report.*
   - 我正在努力趕這份報告的截止日期。
8. **solution** (n.) — 解決方案、答案
   - *We need to find a good solution to this problem.*
   - 我們需要找到一個好的解決方案來解決這個問題。
9. **feedback** (n.) — 回饋、意見反應
   - *Can you give me some feedback on my presentation?*
   - 你能給我一些關於我簡報的回饋嗎？
10. **device** (n.) — 裝置、設備
   - *My smart home device is not connecting to Wi-Fi.*
   - 我的智慧家庭裝置無法連接到Wi-Fi。

## 📘 英文文法
### 現在完成式 (Present Perfect)
描述從過去至今持續的動作、狀態或已完成但對現在有影響的經驗，常用於表達經歷。
- I have worked on IoT projects for five years. (我已經做了五年物聯網專案了。)
- She has never debugged a system like this before. (她以前從未除錯過這樣的系統。)
- We have finished the first prototype of the new AI tool. (我們已經完成了新AI工具的第一個原型。)
### 動名詞 (Gerunds)
動詞加上 -ing 後形成動名詞，可以當作名詞使用，在句中擔任主詞、受詞或介系詞後。
- Debugging embedded systems can be challenging. (除錯嵌入式系統可能很有挑戰性。)
- I enjoy learning about renewable energy safety. (我喜歡學習再生能源安全。)
- He is good at programming in Python. (他擅長用Python程式設計。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - 毎日、仕事をします。
   - 我每天工作。
2. **まいにち** / 毎日 / mainichi — 每天
   - 毎日、日本語を勉強します。
   - 我每天學習日文。
3. **たのしい** / 楽しい / tanoshii — 愉快的、快樂的
   - 日本語の勉強は楽しいです。
   - 學習日文很有趣。
4. **べんきょう** / 勉強 / benkyou — 學習、讀書
   - 私は日本語を勉強しています。
   - 我正在學習日文。
5. **じかん** / 時間 / jikan — 時間
   - 勉強する時間がありません。
   - 我沒有時間學習。
6. **あたらしい** / 新しい / atarashii — 新的
   - 新しいAIツールを使います。
   - 我會使用新的AI工具。
7. **つかう** / 使う / tsukau — 使用
   - パソコンを使いますか。
   - 你會使用電腦嗎？
8. **わかる** / 分かる / wakaru — 明白、理解
   - 日本語が少し分かります。
   - 我會一點日文。
9. **ともだち** / 友達 / tomodachi — 朋友
   - 友達と会います。
   - 我會和朋友見面。
10. **たいへん** / 大変 / taihen — 辛苦的、困難的
   - 仕事は大変ですが、楽しいです。
   - 工作很辛苦，但是很快樂。

## 🗾 日文文法（N5）
### 動詞て形 + ください
**結構**：動詞て形 + ください
用於禮貌地請對方做某事，或給予指示。是日常生活中很常用到的句型。
- ちょっと待ってください。 (請等一下。)
- この書類を読んでください。 (請讀一下這份文件。)
### 名詞 + が + あります / います
**結構**：名詞 + が + あります / います
「います」用於表示人或動物等有生命物體的存在；「あります」則用於無生命物體。
- 私の部屋にパソコンがあります。 (我的房間有電腦。)
- 会議室に田中さんがいます。 (會議室裡有田中先生。)
