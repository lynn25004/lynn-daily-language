# 2026-11-07（週六）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **optimize** (v.) — 優化，讓效能更好
   - *We need to optimize the code for better speed.*
   - 我們需要優化程式碼來提升速度。
2. **debug** (v.) — 除錯，找出並修復錯誤
   - *I spent all morning trying to debug this issue.*
   - 我花了整個早上在處理這個問題。
3. **implement** (v.) — 執行，將計畫付諸實行
   - *Let's implement the new feature next week.*
   - 我們下週來實作這個新功能吧。
4. **prototype** (n.) — 原型，初步的模型或樣品
   - *The team is building a new IoT prototype.*
   - 團隊正在建立一個新的物聯網原型。
5. **reliable** (adj.) — 可靠的，值得信任的
   - *This embedded system is very reliable.*
   - 這個嵌入式系統非常可靠。
6. **efficient** (adj.) — 高效率的，省時省力的
   - *We're looking for more efficient ways to work.*
   - 我們正在尋找更有效率的工作方式。
7. **leisure** (n.) — 閒暇，空閒時間
   - *What do you usually do in your leisure time?*
   - 你閒暇時間通常做什麼？
8. **recharge** (v.) — 充電，恢復精力
   - *I usually recharge myself by playing games.*
   - 我通常透過玩遊戲來恢復精力。
9. **deadline** (n.) — 截止日期，完成工作的期限
   - *Don't worry, the project deadline is still far away.*
   - 別擔心，專案截止日期還很遠。
10. **feedback** (n.) — 回饋，對表現的意見
   - *We got some positive feedback on our new product.*
   - 我們收到了新產品的一些正面回饋。

## 📘 英文文法
### 現在完成式
用來表達從過去某時開始，持續到現在的動作或經驗，或與現在相關的事件。
- I have been working on this project for three months. (我已經在這個專案上工作三個月了。)
- She has already finished debugging the code. (她已經完成程式碼的除錯了。)
- Have you ever tried developing an IoT device? (你曾經開發過物聯網裝置嗎？)
### 動名詞作主詞
動詞加上-ing變成動名詞，可以當作名詞使用，放在句首作為句子的主詞。
- Debugging takes a lot of time and patience. (除錯需要很多時間和耐心。)
- Learning new AI tools is always exciting for engineers. (學習新的AI工具對工程師來說總是令人興奮。)
- Optimizing energy consumption is crucial for embedded systems. (優化能源消耗對嵌入式系統至關重要。)

## 🇯🇵 日文單字（N5）
1. **おやすみ** / 休み / yasumi — 假日，休息
   - 明日はおやすみです。
   - 明天是假日。
2. **どこ** / どこ / doko — 哪裡
   - 週末、どこへ行きますか。
   - 週末，你要去哪裡？
3. **〜ます** / ~ます / ~masu — 動詞禮貌形詞尾
   - 毎日日本語を勉強します。
   - 我每天學習日文。
4. **すき** / 好き / suki — 喜歡
   - 私はAIツールが好きです。
   - 我喜歡AI工具。
5. **たべます** / 食べます / tabemasu — 吃
   - お昼ごはん、もう食べましたか。
   - 午餐，你已經吃過了嗎？
6. **のみます** / 飲みます / nomimasu — 喝
   - コーヒーを飲みます。
   - 我喝咖啡。
7. **みます** / 見ます / mimasu — 看
   - 週末、映画を見ます。
   - 週末，我看電影。
8. **しごと** / 仕事 / shigoto — 工作
   - 私の仕事はエンジニアです。
   - 我的工作是工程師。
9. **べんきょう** / 勉強 / benkyou — 學習，讀書
   - 日本語の勉強は楽しいです。
   - 學習日文很有趣。
10. **とても** / とても / totemo — 非常
   - このシステムはとても便利です。
   - 這個系統非常方便。

## 🗾 日文文法（N5）
### 名詞 + は + 名詞 + です
**結構**：名詞１ + は + 名詞２ + です
用來表示「名詞1是名詞2」，用於介紹或描述事物，是日文最基本的肯定句型。
- 私はエンジニアです。(我是工程師。)
- これは私のIoTデバイスです。(這是我的IoT裝置。)
### 動詞ます形
**結構**：動詞 + ます
動詞ます形是日文中最基本的禮貌形動詞，用於一般對話中表達禮貌和肯定。
- 毎日、日本語を勉強します。(我每天學習日文。)
- 明日、友達と映画を見ます。(明天我會和朋友看電影。)
