# 2026-11-09（週一）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **firmware** (n.) — 控制硬體運作的軟體
   - *We need to update the device's firmware for better performance.*
   - 我們需要更新設備的韌體以獲得更好的性能。
2. **optimize** (v.) — 使達到最佳狀態或效率
   - *I'm trying to optimize this code to run faster.*
   - 我正試著優化這段程式碼讓它跑更快。
3. **deploy** (v.) — 部署、配置（軟體或系統）
   - *We plan to deploy the new system by Friday.*
   - 我們計畫在星期五前部署新系統。
4. **scenario** (n.) — 可能發生的情境或情況
   - *Let's consider a worst-case scenario for this project.*
   - 我們來考慮這個專案最壞的情境吧。
5. **troubleshoot** (v.) — 排除故障、解決問題
   - *I spent all morning troubleshooting the network issue.*
   - 我花了一整個早上排除網路問題。
6. **prototype** (n.) — 產品或設計的初步原型
   - *The team built a prototype for the new IoT device.*
   - 團隊為新的物聯網設備製作了原型。
7. **commute** (v./n.) — 通勤、上下班的路程
   - *My morning commute usually takes about 30 minutes.*
   - 我早上的通勤時間通常大約 30 分鐘。
8. **deadline** (n.) — 完成工作的截止日期
   - *We're working hard to meet the project deadline.*
   - 我們正努力工作以趕上專案截止日期。
9. **integrate** (v.) — 整合、結合不同部分
   - *We need to integrate this module into the existing system.*
   - 我們需要將這個模組整合到現有系統中。
10. **sync** (v.) — 同步、使兩者一致
   - *I need to sync my files before leaving the office.*
   - 我離開辦公室前需要同步我的檔案。

## 📘 英文文法
### 現在完成式 (Present Perfect)
描述從過去持續到現在的動作或經驗，或對現在有影響的過去事件，強調完成或結果。
- I've already finished my morning coffee. (我已經喝完早上的咖啡了。)
- She hasn't deployed the new feature yet. (她還沒部署新功能。)
- Have you ever worked on a renewable energy project? (你曾參與過再生能源專案嗎？)
### 動名詞 (Gerunds) 作為主詞或受詞
動名詞是動詞加上-ing的形式，可以在句中作為名詞使用，充當句子的主詞或動詞、介系詞的受詞。
- Troubleshooting is a big part of my job. (故障排除是我工作很大一部分。)
- I enjoy learning about new AI tools. (我喜歡學習新的 AI 工具。)
- Avoiding distractions helps me focus on coding. (避免分心有助於我專注於寫程式。)

## 🇯🇵 日文單字（N5）
1. **はたらく** / 働く / hataraku — 工作
   - わたしは まいにち かいしゃで はたらきます。
   - 我每天在公司工作。
2. **かいしゃ** / 会社 / kaisha — 公司
   - あの かいしゃは おおきいです。
   - 那間公司很大。
3. **まいにち** / 毎日 / mainichi — 每天
   - わたしは まいにち にほんごを べんきょうします。
   - 我每天學習日文。
4. **いそがしい** / 忙しい / isogashii — 忙碌的
   - きょうは とても いそがしいです。
   - 今天非常忙。
5. **かいぎ** / 会議 / kaigi — 會議
   - ごぜんちゅうに かいぎが あります。
   - 上午有會議。
6. **あたらしい** / 新しい / atarashii — 新的
   - これは あたらしい パソコンです。
   - 這是新的電腦。
7. **ぷろじぇくと** / プロジェクト / purojekuto — 專案
   - あたらしい プロジェクトが はじまります。
   - 新的專案要開始了。
8. **たのしい** / 楽しい / tanoshii — 愉快的、快樂的
   - しごとは とても たのしいです。
   - 工作非常愉快。
9. **きゅうけい** / 休憩 / kyuukei — 休息
   - ひるごはんの あとで きゅうけいします。
   - 午飯後休息。
10. **べんきょう** / 勉強 / benkyou — 學習
   - にほんごの べんきょうが すきです。
   - 我喜歡學日文。

## 🗾 日文文法（N5）
### 〜ます / 〜ません (肯定/否定)
**結構**：動詞ます形 / 動詞ません形
用於表示現在或將來的習慣性動作，以及請求或邀請，是日語中禮貌的動詞基本表達形式。
- 毎日会社に行きます。(我每天去公司。)
- 今日は働きません。(我今天不工作。)
### 名詞 + は + 名詞 + です (主題句)
**結構**：名詞 A + は + 名詞 B + です
用於介紹或說明名詞A是什麼，表示A就是B，是日語最基礎的判斷句型，其中「は」讀作「wa」。
- これは 私の プロジェクトです。(這是我的專案。)
- 私は エンジニアです。(我是工程師。)
