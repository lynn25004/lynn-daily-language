## 📘 英文文法
### 情態助動詞：Should, Ought to, Had better
這些詞都用於給予建議或提出看法，語氣由弱到強。Should 最常見，Had better 帶有警告意味。
- You should back up your data regularly. (你應該定期備份你的資料。)
- We ought to check the system logs. (我們應該檢查系統日誌。)
- You had better finish this report by Friday. (你最好在週五前完成這份報告。)
### 動詞片語與 'up'
動詞與介係詞或副詞組合成新的意義，常用於日常對話和職場情境，掌握能讓表達更自然。
- Could you help me set up this new device? (你能幫我設定這個新裝置嗎？)
- I need to follow up on that email. (我需要追蹤那封電子郵件。)
- Let's pick up some coffee before the meeting. (我們開會前去買些咖啡吧。)

## 🇯🇵 日文單字（N5）
1. **おはようございます** / おはようございます / ohayou gozaimasu — 早上好
   - おはようございます！今日もがんばりましょう。
   - 早上好！今天也一起努力吧。
2. **おやすみなさい** / おやすみなさい / oyasuminasai — 晚安
   - もう遅いから、おやすみなさい。
   - 已經很晚了，晚安。

   - このIoTプロジェクトはとても面白いですね。

5. **しごと** / 仕事 / shigoto — 工作
   - エンジニアの仕事は楽しいです。

   - 工作很辛苦，但很有意義。

## 🗾 日文文法（N5）
### 名詞は名詞です (N1 wa N2 desu)
**結構**：名詞1 + は + 名詞2 + です
用於表示「N1是N2」，是最基本的肯定句型，介紹自己或事物時常用，語氣禮貌。
- 私はエンジニアです。(我是工程師。)
- これはわたしのパソコンです。(這是我的筆記型電腦。)
### 動詞のます形 (Doushi no masu-kei)
**結構**：動詞ます形 (例：行きます、食べます)
動詞的禮貌體，用於日常對話和正式場合，表達未來的動作、習慣性動作或請求。
- 毎日日本語を勉強します。(我每天學習日語。)
- 週末はよくアニメを見ます。(週末我經常看動漫。)
