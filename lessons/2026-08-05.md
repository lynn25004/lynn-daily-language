## 🇬🇧 英文單字（TOEIC 600-800）
1. **prototype** (n.) — 原型、初型（產品或系統）
   - *We need to build a prototype to test this new feature.*
   - 我們需要建一個原型來測試這個新功能。
2. **debug** (v.) — 除錯、找出並修正程式錯誤
   - *Ugh, I spent hours trying to debug this tricky code.*
   - 天啊，我花了好幾個小時在除這個難搞的程式錯誤。
3. **optimize** (v.) — 優化、使性能達到最佳
   - *We should optimize this algorithm for better performance, right?*
   - 我們應該優化這個演算法以獲得更好的性能，對吧？
4. **implement** (v.) — 實施、執行（計畫或系統）
   - *Let's implement this solution by next week's meeting, okay?*
   - 我們下週會議前把這個解決方案實施吧，好嗎？
5. **interface** (n.) — 界面、介面（用戶或程式）
   - *The user interface of this new app is super intuitive!*
   - 這個新App的使用者界面超級直觀！
6. **schedule** (n./v.) — 行程表、安排時間
   - *My schedule is packed, but I can squeeze you in for a quick chat.*
   - 我的行程很滿，但我可以撥點時間和你快速聊聊。
7. **feedback** (n.) — 回饋、意見
   - *Could you give me some quick feedback on my presentation slides?*
   - 你可以給我一些關於我簡報投影片的快速回饋嗎？
8. **deadline** (n.) — 截止日期、最後期限
   - *The deadline for this project is really tight, but we can do it!*
   - 這個專案的截止日期真的很趕，但我們可以做到！
9. **innovative** (adj.) — 創新的、革新的
   - *Their new smart home gadget has such an innovative design, very cool!*
   - 他們的新智慧家庭小工具設計得真有創新性，太酷了！
10. **collaborate** (v.) — 合作、協作
   - *I love to collaborate with smart people on exciting projects.*
   - 我喜歡和聰明的人一起在令人興奮的專案上合作。

## 📘 英文文法
### Used to (過去習慣)
用來描述過去經常發生但現在不再發生的動作或狀態，強調與現在的不同。
- I used to stay up late debugging code every night. (我以前常每晚熬夜除錯。)
- There used to be a small coffee shop here, but it's a bubble tea store now. (這裡以前有間小咖啡店，但現在是手搖飲店了。)
- Did you use to play video games a lot when you were younger? (你小時候是不是很常玩電玩？)
### Modal verbs for advice/suggestions (情態動詞表建議)
使用 'should', 'could', 'might' 等情態動詞來給予建議、提出可能性或表達非強制性的義務。
- You should back up your important files regularly to avoid data loss. (你應該定期備份重要檔案，以避免資料遺失。)
- We could try a different approach if this one doesn't work out. (如果這個方法行不通，我們可以嘗試不同的途徑。)
- It might be a good idea to take a short break after working for hours. (工作好幾個小時後，短暫休息一下可能是個好主意。)

## 🗾 日文文法（N5）
### 動詞ます形（肯定/否定）
**結構**：動詞詞幹 + ます / 動詞詞幹 + ません
表示動詞的禮貌肯定或否定形式，常用於日常對話和陳述事實。
- わたしは ほとんど まいにち コーヒーを のみます。(我幾乎每天都喝咖啡。)
- きょうは テレビを みません。ほかのことを します。(我今天不看電視。我要做別的事。)
### ~ましょう / ~ませんか (建議/邀請)
**結構**：動詞ます形詞幹 + ましょう / 動詞ます形詞幹 + ませんか
「〜ましょう」表示提議或邀請對方一起做某事；「〜ませんか」則更為委婉，用於建議或徵詢對方意願。
- お昼ごはん、いっしょに 食べましょうか。(午餐我們一起吃吧？)
- 新しいAIツールについて、少し 話しませんか。(關於新的AI工具，要不要稍微聊一下？)
