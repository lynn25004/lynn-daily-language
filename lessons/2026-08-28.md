# 2026-08-28（週五）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行，實施計畫或系統
   - *We need to implement the new security features next week.*
   - 我們下週需要實施新的安全功能。
2. **integrate** (v.) — 整合，將不同部分結合
   - *It's tricky to integrate all these devices into one system.*
   - 將所有這些設備整合到一個系統中很棘手。
3. **troubleshoot** (v.) — 排除故障，解決問題
   - *I spent hours trying to troubleshoot this network issue.*
   - 我花了數小時試圖排除這個網路問題。
4. **prototype** (n.) — 原型，初步模型或樣本
   - *The team is building a prototype for the new IoT device.*
   - 團隊正在為新的物聯網設備建造一個原型。
5. **optimize** (v.) — 優化，使效率達到最佳
   - *We should optimize the code for better performance.*
   - 我們應該優化程式碼以獲得更好的性能。
6. **efficient** (adj.) — 高效率的，節省時間的
   - *This new AI tool makes our workflow much more efficient.*
   - 這個新的AI工具讓我們的工作流程效率更高。
7. **reliable** (adj.) — 可靠的，值得信賴的
   - *We need a reliable power supply for this critical system.*
   - 這個關鍵系統需要一個可靠的電源供應。
8. **collaborate** (v.) — 合作，共同完成任務
   - *Let's collaborate on this project to finish it faster.*
   - 我們合作完成這個專案，會更快。
9. **feedback** (n.) — 反饋，對表現的意見
   - *Could you give me some feedback on my presentation?*
   - 你能給我一些關於我簡報的反饋嗎？
10. **deadline** (n.) — 截止日期，完成任務的期限
   - *The deadline for the report is end of day tomorrow.*
   - 報告的截止日期是明天工作結束前。

## 📘 英文文法
### 未來式：will 與 be going to
will 表當下決定、預測或承諾；be going to 表已計畫好的事或有跡可循的預測。
- I will help you troubleshoot that bug later. (我稍後會幫你解決那個程式錯誤。)
- We are going to implement the new system next month. (我們下個月將會實施新系統。)
- Look at those dark clouds! It's going to rain soon. (看那些烏雲！很快就要下雨了。)
### 現在完成式：For 與 Since
用於描述從過去開始持續到現在的動作或經驗，for 接時間長度，since 接起始時間點。
- I have worked on embedded systems for five years. (我從事嵌入式系統工作已經五年了。)
- She has been interested in IoT since college. (她從大學時期就對物聯網很感興趣。)
- Have you ever collaborated with an international team? (你曾經和國際團隊合作過嗎？)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - わたしはエンジニアのしごとがしたいです。
   - 我想要做工程師的工作。
2. **まいにち** / 毎日 / mainichi — 每天
   - まいにち、にほんごをべんきょうします。
   - 我每天都學習日文。
3. **べんきょう** / 勉強 / benkyou — 學習
   - にほんごのべんきょうはたのしいです。
   - 學習日文很有趣。
4. **たのしい** / 楽しい / tanoshii — 快樂的，有趣的
   - このゲームはとてもたのしいです。
   - 這個遊戲非常有趣。
5. **むずかしい** / 難しい / muzukashii — 困難的
   - このもんだいはすこしむずかしいです。
   - 這個問題有點難。
6. **できます** / できます / dekimasu — 會，能夠
   - わたしはロボットをつくることができます。
   - 我會製作機器人。
7. **わかります** / 分かります / wakarimasu — 懂，明白
   - AIのぎじゅつがすこしわかります。
   - 我懂一點AI技術。
8. **すき** / 好き / suki — 喜歡
   - わたしはIoTがきらいじゃなくて、すきです。
   - 我不討厭物聯網，我很喜歡它。
9. **じかん** / 時間 / jikan — 時間
   - べんきょうのじかんがたりません。
   - 學習的時間不夠。
10. **つかう** / 使う / tsukau — 使用
   - あたらしいAIツールをつかいたいです。
   - 我想要使用新的AI工具。

## 🗾 日文文法（N5）
### 〜たいです (想做...)
**結構**：動詞(ます形) + たいです
表達說話者想做某事或某個願望，ます形動詞去掉ます加上たいです即可。
- 日本でしごとをしたいです。(我想到日本工作。)
- あたらしいぎじゅつをべんきょうしたいです。(我想學習新技術。)
### 〜が 好きです / 分かります (喜歡... / 懂...)
**結構**：名詞 + が + 好きです / 分かります
用於表達喜歡某事物（好きです）或理解/知道某事物（分かります），助詞使用が。
- わたしはプログラミングがすきです。(我喜歡程式設計。)
- えいごがすこしわかります。(我懂一點英文。)
