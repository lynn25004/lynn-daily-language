## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施
   - *We need to implement this new feature quickly.*
   - 我們需要快點實施這個新功能。
2. **optimize** (v.) — 優化、最佳化
   - *Can we optimize the code for better performance?*
   - 我們能優化程式碼以提高效能嗎？
3. **troubleshoot** (v.) — 排除故障

4. **deadline** (n.) — 截止日期
   - *The project deadline is next Friday.*
   - 專案的截止日期是下週五。
5. **schedule** (n./v.) — 行程、安排
   - *What's your schedule like tomorrow?*
   - 你明天的行程怎麼樣？
6. **prioritize** (v.) — 優先處理
   - *Let's prioritize the most urgent tasks first.*

7. **feedback** (n.) — 回饋意見
   - *Your feedback helps us improve the product.*
   - 你的回饋幫助我們改進產品。
8. **collaborate** (v.) — 合作、協作

   - 我們經常和其他團隊協作。
9. **prototype** (n.) — 原型
   - *We're building a prototype for the new device.*
   - 我們正在為新設備建造一個原型。
10. **monitor** (v.) — 監控、監測

   - 我們需要監控系統的效能。

## 📘 英文文法
### 動名詞 (Gerunds) 作為主詞或受詞
動名詞 (-ing 形式) 可以在句中扮演名詞的角色，作為主詞或受詞使用，表達一個動作或活動。
- Debugging code can be really challenging. (除錯程式碼可能真的很有挑戰性。)
- I enjoy learning new programming languages. (我喜歡學習新的程式語言。)
- Working from home saves a lot of commute time. (在家工作省下很多通勤時間。)
### 情態助動詞 (Modal Verbs) 表建議或可能性 (should, might)
Should 用於給予建議，might 用於表示可能性較低或不確定性。兩者讓語氣更委婉。
- You should back up your files regularly. (你應該定期備份你的檔案。)
- The system might crash if we don't fix it. (如果我們不修好，系統可能會當機。)
- We should probably take a short break now. (我們現在或許該休息一下了。)

## 🇯🇵 日文單字（N5）
1. **きょう** / 今日 / kyou — 今天
   - きょう、しごとはおわりましたか。
   - 今天工作結束了嗎？
2. **あした** / 明日 / ashita — 明天
   - あした、かいぎがあります。
   - 明天有會議。
3. **じかん** / 時間 / jikan — 時間
   - どのくらいじかんがかかりますか。
   - 大約要花多少時間呢？
4. **しごと** / 仕事 / shigoto — 工作
   - わたしのしごとはエンジニアです。
   - 我的工作是工程師。
5. **べんきょう** / 勉強 / benkyou — 學習
   - まいにち、にほんごをべんきょうします。
   - 每天都學習日文。
6. **やすみ** / 休み / yasumi — 休息、假日
   - きょうはやすみですか。
   - 今天是假日嗎？
7. **かいぎ** / 会議 / kaigi — 會議
   - かいぎはなんじからですか。
   - 會議是幾點開始？
8. **つかう** / 使う / tsukau — 使用
   - このツールをつかいますか。
   - 你會使用這個工具嗎？
9. **おわる** / 終わる / owaru — 結束
   - しごとはごじにおわります。
   - 工作在五點結束。
10. **はじめる** / 始める / hajimeru — 開始
   - プロジェクトはらいしゅうはじめます。
   - 專案下週開始。

## 🗾 日文文法（N5）
### 動詞ます形 + ましょう/ませんか
**結構**：動詞ます形 + ましょう / ませんか
「ましょう」表示「一起做…吧！」的提議；「ませんか」表示「…好嗎？」的邀請，語氣更為委婉。
- いっしょにべんきょうしましょう。(我們一起學習吧。)
- コーヒーをのみませんか。(要不要喝杯咖啡呢？)
### 〜たいです (希望做某事)
**結構**：動詞ます形 + たいです
用於表達說話者想做某事的願望或希望。將動詞的ます形後加上「たいです」。
- あたらしいパソコンをかいたいです。(我想買一台新電腦。)
- しごとにせいこうしたいです。(我希望在工作上成功。)
