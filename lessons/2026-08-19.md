## 📘 英文文法
### Used to do vs. Be used to doing
"Used to do" 指過去常做但現在已不再的習慣；"be used to doing" 則指習慣於某事。
- I used to play video games a lot. (我以前很常玩電動。)
- He is used to working long hours. (他習慣長時間工作。)
- Are you used to the new system yet? (你已經習慣新系統了嗎？)
### 條件句 Type 1 (If + 現在簡單式, will + 原形動詞)
用來表達未來可能發生的情況及其結果，通常是基於現實且有機會實現的。
- If it rains, we will stay home. (如果下雨，我們就待在家。)
- If you finish early, we can go grab coffee. (如果你早點完成，我們可以去喝咖啡。)
- The project will succeed if we collaborate well. (如果我們合作得好，專案會成功。)

## 🗾 日文文法（N5）
### ~ましょう / ~ましょうか
**結構**：動詞(ます形) + ましょう / ましょうか
「ましょう」表示邀請或提議大家一起做某事；「ましょうか」則帶有詢問對方意願的語氣。
- 一緒にコーヒーを飲みましょう。 (我們一起喝咖啡吧。)
- 手伝いましょうか。 (我來幫忙好嗎？)
### 場所 + に/へ + 行きます/来ます/帰ります
**結構**：名詞 (場所) + に/へ + 動詞 (行きます/来ます/帰ります)
這個句型用來表示移動的方向或目的地，說明要去、來或回到哪個地方。
- 会社へ行きます。 (我去公司。)
- 家に帰ります。 (我回家。)
