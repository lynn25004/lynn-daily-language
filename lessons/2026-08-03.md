# 2026-08-03（週一）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 實施、執行計畫
   - *Let's implement this new feature next week.*
   - 我們下週實施這新功能。
2. **optimize** (v.) — 優化、最佳化
   - *We need to optimize the code for speed.*
   - 我們需優化程式碼求速度。
3. **integrate** (v.) — 整合、結合
   - *Can we integrate this module easily?*
   - 這模組可輕鬆整合嗎？
4. **prototype** (n.) — 原型、樣品
   - *The team built a working prototype.*
   - 團隊做了個可動原型。
5. **feedback** (n.) — 回饋意見
   - *Your feedback is really helpful for us.*
   - 你的回饋對我們很有用。
6. **collaborate** (v.) — 合作、協作
   - *Engineers often collaborate on projects.*
   - 工程師常在專案上合作。
7. **troubleshoot** (v.) — 解決問題
   - *I spent hours troubleshooting the bug.*
   - 我花數小時解決錯誤。
8. **sustainable** (adj.) — 可持續的
   - *Renewable energy is more sustainable.*
   - 再生能源更具永續性。
9. **efficient** (adj.) — 有效率的
   - *This new algorithm is very efficient.*
   - 這個新演算法很有效率。
10. **innovate** (v.) — 創新、革新
   - *We need to innovate to stay competitive.*
   - 我們需創新保持競爭力。

## 📘 英文文法
### Present Perfect Tense (現在完成式)
表達從過去某時開始並持續到現在的動作或經驗，或已完成但影響仍存在的動作。
- I have worked on several IoT projects. (我曾參與過幾個物聯網專案。)
- She has learned a lot about AI tools. (她學了很多關於AI工具的知識。)
- We haven't met the new manager yet. (我們還沒見過新經理。)
### Using "Would like to" (想/願意)
用來禮貌地表達願望、請求或意圖，比 "want to" 更客氣。
- I would like to explore renewable energy safety. (我想探索再生能源安全。)
- Would you like to join our study group? (你願意加入我們的讀書會嗎？)
- He would like to improve his English skills. (他想提升他的英文能力。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - 私は毎日仕事をします。
   - 我每天都工作。
2. **かいしゃ** / 会社 / kaisha — 公司
   - 彼は大きな会社で働いています。
   - 他在大公司上班。
3. **べんきょう** / 勉強 / benkyou — 學習
   - 毎日日本語を勉強します。
   - 我每天學習日文。
4. **つかう** / 使う / tsukau — 使用
   - このツールを使いましょう。
   - 我們來使用這個工具吧。
5. **でんき** / 電気 / denki — 電、電力
   - 電気は私たちの生活に必要です。
   - 電力對我們生活很重要。
6. **べんり** / 便利 / benri — 方便的
   - スマートフォンはとても便利です。
   - 智慧型手機很方便。
7. **システム** / システム / shisutemu — 系統
   - 新しいシステムを開発しています。
   - 正在開發新系統。
8. **まなぶ** / 学ぶ / manabu — 學習、學會
   - 私はAIについて学びたいです。
   - 我想學習關於AI。
9. **ぎじゅつ** / 技術 / gijutsu — 技術
   - 彼は高い技術を持っています。
   - 他擁有高超的技術。
10. **まいにち** / 毎日 / mainichi — 每天
   - 毎日コーヒーを飲みます。
   - 我每天都喝咖啡。

## 🗾 日文文法（N5）
### 名詞 + を + 動詞(ます)
**結構**：名詞 + を + 動詞(ます)
表示動詞的受詞。動詞直接作用於名詞，為日文最基本的句子結構。
- 日本語を勉強します。（學習日文。）
- コーヒーを飲みます。（喝咖啡。）
### 〜たいです (want to do something)
**結構**：動詞(ます形去ます) + たいです
表達說話者想要做某事的願望或意圖，是非常直接且常用的表達方式。
- 新しい技術を学びたいです。（我想學習新技術。）
- 日本へ行きたいです。（我想去日本。）
