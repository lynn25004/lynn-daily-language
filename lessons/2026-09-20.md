# 2026-09-20（週日）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 實施；執行
   - *We need to implement this new feature soon.*
   - 我們需要盡快實施這個新功能。
2. **optimize** (v.) — 優化；最佳化
   - *Can we optimize this code for better performance?*
   - 我們可以優化這段程式碼以提升效能嗎？
3. **troubleshoot** (v.) — 解決問題；故障排除
   - *I spent hours trying to troubleshoot this error.*
   - 我花了數小時嘗試解決這個錯誤。
4. **prototype** (n.) — 原型；樣品
   - *Let's build a quick prototype for this idea.*
   - 我們為這個想法快速建立一個原型吧。
5. **debug** (v.) — 除錯；偵錯
   - *It's always fun to debug complex systems.*
   - 除錯複雜系統總是很有趣。
6. **feature** (n.) — 功能；特色
   - *This new feature will make our product unique.*
   - 這項新功能將讓我們的產品獨特。
7. **reliable** (adj.) — 可靠的；穩定的
   - *We need a reliable power supply for the IoT device.*
   - 我們需要可靠的電源供應給物聯網設備。
8. **integration** (n.) — 整合；集成
   - *The integration process was smoother than expected.*
   - 這次整合過程比預期順利。
9. **feedback** (n.) — 回饋；意見
   - *Your feedback is crucial for our project.*
   - 你的回饋對我們的專案至關重要。
10. **sync** (v.) — 同步
   - *Don't forget to sync your files before leaving.*
   - 離開前別忘了同步你的檔案。

## 📘 英文文法
### 第一類條件句 (If... will...)
用於表達未來可能發生且結果也可能實現的狀況，常用於計畫或預測。
- If the sensor works, we will collect more data. (如果感測器能運作，我們將會收集更多數據。)
- If you finish the debug, we can deploy it tomorrow. (如果你完成除錯，我們明天就能部署。)
- If it rains, I'll stay home and code my project. (如果下雨，我就會待在家寫我的專案程式。)
### 動詞片語「set」的用法
「set」搭配不同介系詞或副詞可形成多種動詞片語，表達建立、分配或開始等意義。
- Let's set up the new development environment. (我們來建立新的開發環境吧。)
- I need to set aside some time for system testing. (我需要撥出一些時間進行系統測試。)
- We should set out our goals for this sprint. (我們應該為這次衝刺訂定目標。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - わたしはしごとがすきです。
   - 我喜歡工作。
2. **べんきょう** / 勉強 / benkyou — 學習
   - まいにち日本語をべんきょうします。
   - 我每天學習日文。
3. **しゅう** / 週 / shuu — 週
   - らいしゅう、かいぎがあります。
   - 下週有會議。
4. **まいにち** / 毎日 / mainichi — 每天
   - 毎日コーヒーをのみます。
   - 我每天喝咖啡。
5. **わかる** / わかる / wakaru — 懂；理解
   - このもんだいがわかりますか。
   - 你懂這個問題嗎？
6. **かく** / 書く / kaku — 寫
   - メールをかきます。
   - 我寫電子郵件。
7. **よむ** / 読む / yomu — 讀
   - ほんをよみます。

## 🗾 日文文法（N5）
### 動詞「〜ます / 〜ません」
**結構**：動詞ます形 / 動詞ません形
用於禮貌地表達現在或未來的肯定或否定行為，是日文基礎動詞變化。
- わたしはまいにちしごとをします。(我每天工作。)
- あしたはしごとをしません。(我明天不工作。)
### 「名詞は名詞です」句型
**結構**：名詞 + は + 名詞 + です
用來介紹事物或說明其屬性，是日語最基本的判斷句，表示「A是B」。
- これはわたしのコンピュータです。(這是我的電腦。)
- わたしのしゅみは日本語のべんきょうです。(我的興趣是學習日文。)
