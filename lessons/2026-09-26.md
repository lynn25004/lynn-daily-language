# 2026-09-26（週六）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **configure** (v.) — 配置、設定（設備或系統）
   - *Can you help me configure this new router?*
   - 你可以幫我設定這台新路由器嗎？
2. **debug** (v.) — 偵錯、除錯（程式或系統）
   - *I spent hours to debug this code yesterday.*
   - 我昨天花了數小時來偵錯這段程式碼。
3. **prototype** (n.) — 原型、樣品、雛形
   - *We need to build a prototype first for testing.*
   - 我們需要先建立一個原型來測試。
4. **efficient** (adj.) — 效率高的、省力的
   - *This new algorithm is very efficient for data processing.*
   - 這個新演算法在資料處理上非常有效率。
5. **reliable** (adj.) — 可靠的、值得信賴的
   - *We need a reliable power supply for the IoT device.*
   - 我們的物聯網設備需要可靠的電源供應。
6. **innovative** (adj.) — 創新的、革新的
   - *Our team is working on an innovative AI solution.*
   - 我們的團隊正在開發創新的 AI 解決方案。
7. **deadline** (n.) — 截止日期、最後期限
   - *The project deadline is next Friday, let's hurry!*
   - 專案截止日是下週五，我們快點吧！
8. **collaborate** (v.) — 合作、協作、共同工作
   - *We often collaborate with different teams on projects.*
   - 我們常與不同團隊在專案上合作。
9. **casual** (adj.) — 隨意的、非正式的、休閒的
   - *Let's have a casual chat about your weekend plans.*
   - 我們輕鬆聊一下你週末的計畫吧。
10. **recharge** (v.) — 充電、恢復精力
   - *I usually recharge my energy by reading books.*
   - 我通常透過閱讀來恢復精力。

## 📘 英文文法
### 未來真實條件句 (Conditional Sentences Type 1)
當你談論未來可能發生且結果真實的事情時使用此句型，結構為「If + 現在簡單式, S + will/can/may + 原形動詞」。
- If I finish this task early, I will go for a run. (如果我提早完成這個任務，我就會去跑步。)
- If the system works, we will launch it next month. (如果系統運作正常，我們下個月就會發布它。)
- If you have any questions, feel free to ask me anytime. (如果你有任何問題，隨時都可以問我喔。)
### 動名詞與不定詞 (Gerunds and Infinitives)
有些動詞後面習慣接動名詞 (-ing)，有些則接不定詞 (to + 原形動詞)，需熟悉其搭配用法。
- I enjoy developing embedded systems in my free time. (我喜歡在空閒時間開發嵌入式系統。)
- He decided to learn Japanese for his career goal. (他決定為了他的職涯目標學習日文。)
- We need to avoid making similar mistakes in the future. (我們需要避免未來犯類似的錯誤。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - わたしのしごとはエンジニアです。
   - 我的工作是工程師。
2. **やすみ** / 休み / yasumi — 休息、假日
   - きょうはやすみです。
   - 今天是休息日。
3. **べんきょう** / 勉強 / benkyou — 學習
   - わたしはまいにち日本語を勉強します。
   - 我每天學習日文。
4. **でんき** / 電気 / denki — 電、電力、電燈
   - このへやのでんきはくらいです。
   - 這個房間的電燈很暗。
5. **つくる** / 作る / tsukuru — 製作、創造
   - わたしはIoTデバイスを作ります。
   - 我製作IoT設備。
6. **よむ** / 読む / yomu — 閱讀、讀書
   - わたしはほんをよみます。
   - 我讀書。
7. **しゅみ** / 趣味 / shumi — 興趣
   - わたしのしゅみはえいがをみることです。
   - 我的興趣是看電影。
8. **まいにち** / 毎日 / mainichi — 每天
   - まいにちコーヒーをのみます。
   - 我每天喝咖啡。
9. **むずかしい** / 難しい / muzukashii — 困難的
   - このもんだいはとてもむずかしいです。
   - 這個問題非常困難。
10. **かんたん** / 簡単 / kantan — 簡單的
   - これはかんたんなしごとです。
   - 這是簡單的工作。

## 🗾 日文文法（N5）
### 名詞 + は + 名詞 + です
**結構**：名詞1 + は + 名詞2 + です
此為日文最基本的肯定句型，用於介紹或說明事物，表示「名詞1是名詞2」的意思。
- わたしはエンジニアです。(我是工程師。)
- これはわたしのほんではありません。(這不是我的書。)
### 動詞(ます形) + ましょう
**結構**：動詞ます形 + ましょう
表示提議或邀請對方一起做某事，語氣較為輕鬆，也可用於表示自己的決心或意圖。
- いっしょに日本語を勉強しましょう。(我們一起學習日文吧。)
- こんど、カフェでお茶を飲みましょう。(下次我們在咖啡廳喝茶吧。)
