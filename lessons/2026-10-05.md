# 2026-10-05（週一）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施計畫
   - *We need to implement this new feature quickly.*
   - 我們需要快速實施這個新功能。
2. **debug** (v.) — 偵錯、修正錯誤
   - *It took hours to debug that tricky software bug!*
   - 花了數小時才偵測出那個棘手的軟體錯誤！
3. **prototype** (n.) — 原型、初步模型
   - *Let's build a prototype to test the concept.*
   - 我們來做個原型測試這個概念。
4. **optimize** (v.) — 優化、使效率更高
   - *Can we optimize this code for better performance?*
   - 我們能優化這段程式碼以提升效能嗎？
5. **solution** (n.) — 解決方案、答案
   - *I think I found a good solution for this problem.*
   - 我想我找到這個問題的好解決方案了。
6. **feature** (n.) — 特色、功能
   - *This new device has some really cool features.*
   - 這個新裝置有一些很酷的功能。
7. **deadline** (n.) — 截止日期、最後期限
   - *The project deadline is next Friday, let's hurry!*
   - 專案截止日是下週五，我們快點！
8. **collaborate** (v.) — 合作、協同工作
   - *We should collaborate more often on these tasks.*
   - 我們在這些任務上應該更常合作。
9. **feedback** (n.) — 回饋、意見反應
   - *Your feedback on the design is much appreciated.*
   - 非常感謝你對設計的回饋意見。
10. **recharge** (v.) — 充電、恢復精力
   - *I need to recharge with some coffee after this meeting.*
   - 開完會我需要喝咖啡充個電。

## 📘 英文文法
### Used to V (過去習慣)
用來描述過去經常發生但現在已停止的習慣或狀態，或過去的事實。
- I used to work late every day.
- 我以前每天都工作到很晚。
- She used to develop games.
- 她以前是開發遊戲的。
- There used to be an old factory here.
- 這裡以前有間舊工廠。
### Phrasal verbs with 'up'
動詞加上 'up' 可以表達完成、增加、建立或整理等意思，具體語境而定。
- Let's wrap up this meeting soon.
- 我們快點結束這個會議吧。
- Can you look up that information for me?
- 你能幫我查一下那個資訊嗎？
- We need to set up the new server.
- 我們需要設定好新的伺服器。

## 🇯🇵 日文單字（N5）
1. **きょう** / 今日 / kyou — 今天
   - きょうはげつようびです。
   - 今天是星期一。
2. **しごと** / 仕事 / shigoto — 工作
   - わたしのしごとはエンジニアです。
   - 我的工作是工程師。
3. **かいしゃ** / 会社 / kaisha — 公司
   - かいしゃへいきます。
   - 去公司。
4. **べんきょう** / 勉強 / benkyou — 學習、讀書
   - にほんごをべんきょうします。
   - 學習日文。
5. **ききます** / 聞きます / kikimasu — 聽、問
   - おんがくをききます。
   - 聽音樂。
6. **よみます** / 読みます / yomimasu — 讀
   - ほんをよみます。
   - 讀書。
7. **いきます** / 行きます / ikimasu — 去
   - えきへいきます。
   - 去車站。
8. **なに** / 何 / nani — 什麼
   - これはなんですか。
   - 這是什麼？
9. **～じ** / ～時 / ~ji — ～點 (時間)
   - いまごじです。
   - 現在五點。
10. **わかります** / 分かります / wakarimasu — 明白、懂
   - にほんごがわかりますか。
   - 你懂日文嗎？

## 🗾 日文文法（N5）
### 動詞(ます形) + ましょうか (我幫你…好嗎？)
**結構**：動詞(ます形) + ましょうか
用於主動提出為對方做某事，語氣禮貌且帶有詢問對方意願。
- てつだいましょうか。（我幫你嗎？）
- まどをあけましょうか。（我開窗戶好嗎？）
### ～はどこですか (～在哪裡？)
**結構**：名詞 + は + どこ + ですか
用來詢問某個地點或物品的確切位置，非常實用。
- トイレはどこですか。（洗手間在哪裡？）
- あなたの会社はどこですか。（你的公司在哪裡？）
