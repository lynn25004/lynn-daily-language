## 🇬🇧 英文單字（TOEIC 600-800）
1. **firmware** (n.) — 韌體，裝置的內建程式
   - *Updating the firmware can fix some bugs.*
   - 更新韌體可以修復一些錯誤。
2. **integrate** (v.) — 整合，將不同部分結合
   - *We need to integrate this module into the system.*
   - 我們需要將這個模組整合到系統中。
3. **optimize** (v.) — 優化，使效率或性能最佳
   - *Let's optimize the code for better performance.*
   - 我們來優化程式碼以獲得更好的效能。
4. **renewable** (adj.) — 可再生的，能補充的
   - *Solar power is a great renewable energy source.*
   - 太陽能是很棒的再生能源。
5. **device** (n.) — 裝置，設備，儀器
   - *My smart home devices make life easier.*
   - 我的智慧家庭裝置讓生活更輕鬆。
6. **curious** (adj.) — 好奇的，有求知慾的
   - *I'm curious about the new AI tool.*
   - 我對新的 AI 工具很好奇。
7. **approach** (n.) — 方法，處理方式，途徑
   - *What's your approach to learning Japanese?*
   - 你學日文的方法是什麼？
8. **debug** (v.) — 除錯，找出並修復錯誤
   - *It took me hours to debug this program.*
   - 我花了數小時來為這個程式除錯。
9. **solution** (n.) — 解決方案，解答
   - *We need a creative solution for this problem.*
   - 我們需要一個創意的解決方案來解決這個問題。
10. **feedback** (n.) — 回饋，意見，反應
   - *Can you give me some feedback on my resume?*
   - 你能給我一些關於我履歷的回饋嗎？

## 📘 英文文法
### 現在完成式 (Present Perfect)
表示從過去某個時間點開始，一直持續到現在的動作或經驗，或已完成但影響持續到現在的動作。
- I have worked on IoT projects for five years. (我已經在物聯網專案上工作五年了。)
- She has learned a lot about renewable energy. (她學到了很多關於再生能源的知識。)
- Have you ever used an AI tool for coding? (你曾經用 AI 工具來寫程式嗎？)
### 動名詞 (Gerunds) 作為主詞或受詞
動名詞（動詞-ing 形式）可以像名詞一樣在句子中作主詞或受詞，表示某個動作或活動。
- Debugging takes a lot of patience. (除錯需要很多耐心。)
- I enjoy learning new programming languages. (我喜歡學習新的程式語言。)
- Using AI tools can boost productivity. (使用 AI 工具可以提升生產力。)

## 🇯🇵 日文單字（N5）
1. **べんきょう** / 勉強 / benkyou — 學習
   - 毎日日本語を勉強します。
   - 我每天學習日文。
2. **しごと** / 仕事 / shigoto — 工作
   - 私の仕事はエンジニアです。
   - 我的工作是工程師。
3. **おもしろい** / 面白い / omoshiroi — 有趣的
   - この本はとても面白いです。
   - 這本書很有趣。
4. **つかう** / 使う / tsukau — 使用
   - 私はパソコンをよく使います。
   - 我經常使用電腦。
5. **わかる** / 分かる / wakaru — 明白、懂
   - 英語が少し分かりますか。
   - 你懂一點英文嗎？
6. **あたらしい** / 新しい / atarashii — 新的
   - 新しい AI ツールが欲しいです。
   - 我想要一個新的 AI 工具。
7. **まいにち** / 毎日 / mainichi — 每天
   - 毎日コーヒーを飲みます。
   - 我每天喝咖啡。
8. **すき** / 好き / suki — 喜歡
   - 私は組み込みシステムが好きです。
   - 我喜歡嵌入式系統。
9. **じかん** / 時間 / jikan — 時間
   - 日本語の勉強に時間を使います。
   - 我花時間學習日文。
10. **たいへん** / 大変 / taihen — 辛苦的、嚴峻的
   - エンジニアの仕事は大変ですが、楽しいです。
   - 工程師的工作很辛苦，但很有趣。

## 🗾 日文文法（N5）
### 名詞 + は + 名詞 + です
**結構**：名詞１ + は + 名詞２ + です
用來介紹人事物，表示「名詞１就是名詞２」或「名詞１是名詞２」，是日文最基本的肯定句型。
- 私はエンジニアです。(我是工程師。)
- これは私のパソコンです。(這是我的電腦。)
### 動詞(ます形) + たいです
**結構**：動詞ます形 + たいです
表示說話者想要做某個動作或事情，是非常常用來表達願望的句型。
- 日本へ行きたいです。(我想去日本。)
- 新しい技術を学びたいです。(我想學習新技術。)
