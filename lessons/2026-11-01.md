## 📘 英文文法
### 不定詞 (To-infinitive) 表目的
用 "to + 動詞原形" 來表達某行為的目的或原因，相當於「為了…」，讓句子更清楚。
- I study hard to pass the exam. (我努力學習以通過考試。)
- She went to the market to buy some fruit. (她去市場買水果。)
- We need to optimize the code to improve performance. (我們需要優化程式碼來提升效能。)
### 現在完成式 (Present Perfect) 表經驗與持續
用 "have/has + 過去分詞" 來表達過去發生且持續到現在的動作，或過去累積的經驗。
- I have worked on several IoT projects. (我參與過好幾個物聯網專案。)
- He has studied Japanese for six months. (他學日文已經六個月了。)
- Have you ever visited a renewable energy plant? (你參觀過再生能源廠嗎？)

## 🇯🇵 日文單字（N5）
1. **おやすみ** / 休み / oyasumi — 休息、假日
   - きょうは にちようび です。おやすみ です。
   - 今天是星期日。是假日。
2. **しゅみ** / 趣味 / shumi — 興趣
   - わたしの しゅみは えいがを みること です。
   - 我的興趣是看電影。
3. **べんきょう** / 勉強 / benkyou — 學習、讀書
   - わたしは にほんごを べんきょうします。
   - 我學習日文。
4. **つかれる** / 疲れる / tsukareru — 疲倦
   - しごとが おわって、とても つかれました。
   - 工作結束後，很累。
5. **すき** / 好き / suki — 喜歡
   - わたしは AI ツールが すき です。
   - 我喜歡 AI 工具。
6. **わかる** / 分かる / wakaru — 懂、明白
   - にほんごが すこし わかります。
   - 我懂一點日文。
7. **あたらし** / 新しい / atarashii — 新的
   - あたらしい コンピューターを かいました。
   - 我買了一台新電腦。
8. **まち** / 町 / machi — 城鎮、街道
   - この まちは しずか です。
   - 這個城鎮很安靜。
9. **いそがしい** / 忙しい / isogashii — 忙碌的
   - きんようびは とても いそがしかったです。
   - 星期五非常忙碌。
10. **どこ** / どこ / doko — 哪裡
   - あなたの へやは どこ ですか。
   - 你的房間在哪裡？

## 🗾 日文文法（N5）
### 「名詞 は 名詞 です」
**結構**：名詞1 + は + 名詞2 + です
這個句型用於介紹或說明某物是什麼，構成基本的肯定句，其中「は」讀作「wa」。
- これは わたしの パソコン です。(這是我的電腦。)
- わたしは エンジニア です。(我是工程師。)
### 「名詞 + を + 動詞(ます)」
**結構**：名詞 + を + 動詞(ます形)
「を」助詞表示動詞的受詞，說明動詞所作用的對象，動詞要用ます形，是很常用句型。
- ごはんを たべます。(吃飯。)
- にほんごを べんきょうします。(學習日文。)
