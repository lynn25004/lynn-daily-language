   - *Let's optimize the code to make it run faster.*

3. **collaborate** (v.) — 合作、協作
   - *We often collaborate with the hardware team on projects.*
   - 我們經常與硬體團隊在專案上合作。

   - *The team built a quick prototype for the IoT device.*

6. **reliable** (adj.) — 可靠的、穩定的
   - *We need a reliable power source for our embedded system.*
   - 我們的嵌入式系統需要一個可靠的電源。
7. **innovative** (adj.) — 創新的、革新的

   - *Our work schedule is pretty flexible, which is nice.*

## 📘 英文文法
### 條件句 (Conditional Sentences Type 1)
表達未來可能發生的情況及其結果，結構是 "If + 主詞 + 現在簡單式, 主詞 + will + 原形動詞"。
- If it rains tomorrow, we will just work from home. (如果明天會下雨，我們就待在家工作。)
- If you finish the project early, we can grab some coffee. (如果你早點完成專案，我們可以去喝咖啡。)
- If the system crashes again, we will need to restart it. (如果系統又當機了，我們就需要重啟它。)
### 使用 "Would rather" (寧願...)
表達在兩種選擇中更偏好其中一種，後面通常接動詞原形，或 "would rather do A than do B"。
- I'd rather work on IoT projects than traditional ones. (我寧願做物聯網專案，而不是傳統專案。)
- Would you rather have a meeting now or later this afternoon? (你現在開會，還是今天下午晚一點？)
- He would rather stay home and relax than go out tonight. (他寧願今晚待在家休息，也不想出門。)

## 🗾 日文文法（N5）
### 「名詞 + は + 名詞 + です」
**結構**：名詞 + は + 名詞 + です
用來介紹或說明主詞是什麼，表達「A是B」的基本肯定句型，常用於自我介紹或事物描述。
- わたしは エンジニア です。(我是工程師。)
- これは わたしの パソコン です。(這是我的電腦。)
### 「～ます」形式動詞
**結構**：動詞ます形
表達現在或未來會做的動作，以及習慣性動作，是日語動詞最基本的禮貌體。
- 毎日 日本語を 勉強します。(我每天學習日語。)
- 明日、仕事に 行きます。(明天我要去上班。)
