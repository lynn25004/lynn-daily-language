## 📘 英文文法
### 第一類型條件句 (If + 現在簡單式, will + 原形動詞)
當你討論未來可能發生的真實情況和其結果時，就會使用這種句型喔。
- If it rains, we will stay inside. (如果下雨，我們就待在室內。)
- If you finish your work, you can go home early. (如果你完成工作，就可以提早回家。)
- If the system crashes, we will restart it. (如果系統當機，我們會重啟它。)
### 片語動詞：Work on 和 Figure out
"Work on" 指從事某事；"Figure out" 則是用來理解或找出解決方案。
- I'm currently working on a new project. (我目前正在處理一個新專案。)
- Let's figure out how to fix this bug. (我們來想想辦法解決這個錯誤。)
- Can you help me work on this problem? (你能幫我處理這個問題嗎？)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - まいにちしごとをします。
   - 我每天都工作。
2. **かいしゃ** / 会社 / kaisha — 公司
   - かいしゃへいきます。
   - 我去公司。

## 🗾 日文文法（N5）
### 動詞て形 + ください (te-form + kudasai)
**結構**：動詞て形 + ください
當你想禮貌地請對方做某事，或者發出一個請求時，就可以用這個句型喔。
- ちょっとまってください。(請等一下。)
- このしりょうをよんでください。(請閱讀這份資料。)
### 名詞 + が + 好きです / 嫌いです (ga suki desu / kirai desu)
**結構**：名詞 + が + 好きです / 嫌いです
這個句型用來表達你對某事物的好惡，是日文日常對話很常用到的喔。
- わたしはコーヒーがすきです。(我喜歡咖啡。)
- わたしはなっとうがきらいです。(我不喜歡納豆。)
