## 📘 英文文法
### 條件句 (第一型)
用來描述未來可能發生的事情，如果某條件成立，就會有某結果。表達真實的可能性。
- If the system crashes, we will lose all data. (如果系統當機，我們將丟失所有資料。)
- If you finish your tasks early, you can leave. (如果你早點完成任務，你就可以離開。)
- If we optimize this, it will run much faster. (如果我們優化這個，它會跑得快很多。)
### 動詞片語：set 系列
set 這個動詞可以和不同介系詞搭配，產生多種意思，例如建立、儲存、啟動等。
- I need to set up my new smart thermostat. (我需要設定我的新智慧恆溫器。)
- Let's set aside some time for debugging. (我們撥出一些時間來除錯吧。)
- The alarm will set off if there's smoke. (如果偵測到煙霧，警報就會響起。)

## 🗾 日文文法（N5）
### 動詞的「ます」形變化
**結構**：動詞連用形 + ます / ません / ました / ませんでした
這是日語動詞最基礎的禮貌體變化，用來表達現在、過去的肯定與否定行為。
- 毎日、日本語を勉強します。 (我每天學習日語。)
- 昨日、会議に参加しませんでした。 (我昨天沒有參加會議。)
### ～たいです (想做...)
**結構**：動詞ます形去ます + たいです
用來表達自己想要做某件事情的願望或意圖，是日常對話中很常用到的句型。
- 新しいIoTデバイスを作りたいです。 (我想製作新的物聯網設備。)
- もっと再生エネルギーについて学びたいです。 (我想學習更多關於再生能源的知識。)
