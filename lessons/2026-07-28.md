# 2026-07-28（週二）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施（計畫或工具）
   - *We need to implement this new feature by next month.*
   - 我們下個月前需要實施這個新功能。
2. **optimize** (v.) — 優化、使最佳化
   - *I'm trying to optimize the code for better performance.*
   - 我正在努力優化程式碼以提高性能。
3. **troubleshoot** (v.) — 排除故障、解決問題
   - *Can you help me troubleshoot this network issue?*
   - 你能幫我排除這個網路問題嗎？
4. **prototype** (n.) — 原型、樣本
   - *We're building a new prototype for the IoT device.*
   - 我們正在為這個物聯網設備製作一個新原型。
5. **collaborate** (v.) — 合作、協作
   - *Let's collaborate on this project to finish it faster.*
   - 我們在這個專案上合作，更快完成吧。
6. **efficient** (adj.) — 高效的、有效率的
   - *Our new algorithm is designed to be much more efficient.*
   - 我們的新演算法設計得更有效率。
7. **commute** (n.) — 通勤（的路程或時間）
   - *My daily commute is about 30 minutes by scooter.*
   - 我每天的通勤大概是騎機車三十分鐘。
8. **deadline** (n.) — 截止日期
   - *We have a tight deadline for this new product launch.*
   - 我們這個新產品發布的截止日期很趕。
9. **innovative** (adj.) — 創新的、革新的
   - *I like exploring innovative ideas in renewable energy.*
   - 我喜歡探索再生能源領域的創新想法。
10. **update** (v.) — 更新、告知最新情況
   - *Could you update me on the project status?*
   - 你能告訴我專案的最新進度嗎？

## 📘 英文文法
### 被動語態 (Passive Voice)
當動作執行者不重要或未知，或想強調承受者時，使用「be 動詞 + 過去分詞」來表達。
- The software was developed by a small team. (這套軟體是由一個小團隊開發的。)
- New IoT sensors are being installed next week. (新的物聯網感測器將於下週安裝。)
- The problem has been solved already. (問題已經解決了。)
### 情態助動詞：表達可能性 (could, might, may)
這些助動詞表達可能性。could表較低推測；might/may表現在或未來不確定性。
- The bug might be in the database connection. (這個錯誤可能是在資料庫連線。)
- We could try a different approach next time. (我們下次或許可以嘗試不同的方法。)
- It may be raining later, so bring an umbrella. (稍後可能會下雨，所以帶把傘吧。)

## 🇯🇵 日文單字（N5）

   - まいにちしごとをします。
   - 我每天都工作。
2. **かいしゃ** / 会社 / kaisha — 公司
   - わたしのかいしゃはとてもおおきいです。
   - 我的公司非常大。

   - わたしはにほんごをべんきょうします。

## 🗾 日文文法（N5）
### 助詞「を」
**結構**：名詞 + を + 動詞(ます形)
助詞「を」用來標示動詞的直接受詞，表示動作作用的對象。
- ごはんを食べます。 (吃飯。)
- ジュースを飲みます。 (喝果汁。)
### 助詞「で」（場所）
**結構**：場所 + で + 動詞(ます形)
助詞「で」用來表示動作發生的場所，強調「在某處進行某動作」。
- かいしゃではたらきます。 (在公司工作。)
- カフェでコーヒーを飲みます。 (在咖啡廳喝咖啡。)
