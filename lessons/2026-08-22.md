## 📘 英文文法
### Phrasal Verbs with "on"
動詞搭配介系詞 "on" 形成新意義，常用於表達持續、依賴或開始某事。
- Let's work on this project after lunch. (午餐後我們來處理這個專案吧。)
- I rely on my smart home system quite a lot. (我蠻依賴我的智慧家庭系統的。)
- We're always on the lookout for new tech trends. (我們總是在尋找新的科技趨勢。)
### Using "would like to" vs. "want to"
"would like to" 比 "want to" 更客氣，常用於表達願望、邀請或提出要求。
- I would like to learn more about embedded systems. (我想要多學一些關於嵌入式系統的知識。)
- Would you like to join us for coffee this afternoon? (你下午想和我們一起喝咖啡嗎？)
- I would like to try that new AI tool everyone is talking about. (我想要試試大家都在說的那個新的 AI 工具。)

## 🇯🇵 日文單字（N5）

## 🗾 日文文法（N5）
### 動詞(ます形) + たいです
**結構**：動詞(ます形) + たいです
表示說話者「想要做某事」的願望或願望，是一種常用且直接的表達方式。
- 日本語をもっと勉強したいです。(我想要多學一點日文。)
- 週末は映画を見たいです。(週末我想看電影。)
### 場所 + で
**結構**：場所 + で + 動詞
助詞「で」用來表示動作發生的地點，說明在哪裡進行了某項活動。
- 喫茶店でコーヒーを飲みます。(在咖啡廳喝咖啡。)
- 家でIoTデバイスを作ります。(在家裡製作 IoT 設備。)
