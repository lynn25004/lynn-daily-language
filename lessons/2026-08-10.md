# 2026-08-10（週一）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **deploy** (v.) — 部署，配置，展開
   - *We need to deploy the new system by next week.*
   - 我們下週要部署新系統。
2. **optimize** (v.) — 優化，改善，使最佳化
   - *Let's optimize the code for better performance.*
   - 我們來優化程式碼以提升效能。
3. **prototype** (n.) — 原型，初型，樣本
   - *The team is building a new prototype.*
   - 團隊正在打造一個新原型。
4. **integrate** (v.) — 整合，結合，併入
   - *Can we integrate this feature into our app?*
   - 我們能把這功能整合到應用程式嗎？
5. **debug** (v.) — 除錯，偵錯，排障
   - *I spent hours debugging this tricky bug.*
   - 我花了數小時才把這個棘手的錯誤除掉。
6. **deadline** (n.) — 截止日期，最後期限
   - *The project deadline is Friday, remember?*
   - 專案截止日是週五，記得嗎？
7. **feedback** (n.) — 回饋，意見，反應
   - *Your feedback helps us improve a lot!*
   - 你的回饋對我們改進很有幫助！
8. **prioritize** (v.) — 優先處理，排列優先次序
   - *We should prioritize urgent tasks first.*
   - 我們應該先優先處理緊急任務。
9. **collaborate** (v.) — 合作，協作，共同工作
   - *Let's collaborate on this new IoT project.*
   - 我們一起合作這個新的物聯網專案吧。
10. **innovative** (adj.) — 創新的，革新的，有新意的
   - *That's an innovative solution for renewable energy.*
   - 那是再生能源的一個創新解決方案。

## 📘 英文文法
### 被動語態 (Passive Voice)
當動作的執行者不重要或未知，或想強調動作的承受者時使用，使語氣更客觀。
- The new IoT device was developed by our team. (這個新的物聯網裝置是由我們團隊開發的。)
- Many bugs were found in the recent software update. (最近的軟體更新中發現了許多錯誤。)
- Renewable energy solutions are being explored globally. (全球正在探索再生能源解決方案。)
### 條件句 (Conditional Sentences)
Type 1 討論真實或可能發生的情況，Type 2 討論假設或不太可能發生的情況，用於預測或建議。
- If the system works, we will launch it next month. (如果系統運作正常，我們下個月就會推出。)
- If I had more time, I would learn a new programming language. (如果我有更多時間，我會學習一種新的程式語言。)
- What if we try this approach? It might optimize performance. (如果我們嘗試這個方法呢？它或許能優化效能。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - 今日（きょう）は仕事（しごと）が忙（いそが）しいです。
   - 今天工作很忙。
2. **かいしゃ** / 会社 / kaisha — 公司
   - 私（わたし）の会社（かいしゃ）は東京（とうきょう）にあります。
   - 我的公司在東京。
3. **コンピューター** / コンピューター / konpyuutaa — 電腦
   - 新（あたら）しいコンピューターが欲（ほ）しいです。
   - 我想要一台新電腦。
4. **でんき** / 電気 / denki — 電，電器
   - 電気（でんき）を消（け）してください。
   - 請關燈。
5. **つくる** / 作る / tsukuru — 製作，製造
   - 私（わたし）はロボットを作（つく）りたいです。
   - 我想做一個機器人。
6. **まなぶ** / 学ぶ / manabu — 學習
   - 日本語（にほんご）を学（まな）ぶのは楽（たの）しいです。
   - 學習日文很有趣。
7. **つかう** / 使う / tsukau — 使用
   - このツールは使（つか）いやすいです。
   - 這個工具很好用。
8. **むずかしい** / 難しい / muzukashii — 困難的
   - この問題（もんだい）は少（すこ）し難（むずか）しいです。
   - 這個問題有點難。
9. **おもしろい** / 面白い / omoshiroi — 有趣的
   - そのゲームはとても面白（おもしろ）いです。
   - 那個遊戲非常有趣。
10. **きゅうけい** / 休憩 / kyuukei — 休息
   - ちょっと休憩（きゅうけい）しませんか。
   - 要不要稍微休息一下？

## 🗾 日文文法（N5）
### 動詞(ます形) + たいです
**結構**：動詞(ます形) + たいです
用來表達說話者想做某事的願望或慾望，非常直接，常用於日常生活對話中。
- 私（わたし）は日本（にほん）で働（はたら）きたいです。 (我想到日本工作。)
- 新（あたら）しい技術（ぎじゅつ）を勉強（べんきょう）したいです。 (我想學習新技術。)
### 場所 + で + 動詞
**結構**：場所名詞 + で + 動詞
表示某個動作或行為發生的地點，助詞「で」強調行為進行的場所，是日語中常用的地點助詞。
- 会社（かいしゃ）で日本語（にほんご）を勉強（べんきょう）します。 (我在公司學習日文。)
- カフェでコーヒーを飲（の）みます。 (我在咖啡廳喝咖啡。)
