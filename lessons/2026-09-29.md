# 2026-09-29（週二）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 實施、執行計畫或功能
   - *We need to implement this new feature quickly.*
   - 我們需要快速實施這項新功能。
2. **optimize** (v.) — 優化、改善效能或效率
   - *Can we optimize the code for better performance?*
   - 我們可以優化程式碼以提高效能嗎？
3. **troubleshoot** (v.) — 排除故障、解決問題
   - *I spent hours trying to troubleshoot the network issue.*
   - 我花了幾個小時嘗試排除網路問題。
4. **scenario** (n.) — 情境、設想、可能發生的情況
   - *Let's think about the worst-case scenario for this project.*
   - 讓我們思考一下這個專案最壞的情況。
5. **prototype** (n.) — 原型、樣本，初步的模型
   - *The team is building a prototype for the new IoT device.*
   - 團隊正在為新的物聯網設備製作原型。
6. **integrate** (v.) — 整合、結合不同部分
   - *We plan to integrate AI into our renewable energy system.*
   - 我們計劃將人工智慧整合到再生能源系統中。
7. **efficient** (adj.) — 效率高的、有效率的
   - *Using AI tools makes our workflow more efficient.*
   - 使用人工智慧工具讓我們的工作流程更有效率。
8. **collaborate** (v.) — 合作、協作完成任務
   - *We need to collaborate closely with the software team.*
   - 我們需要與軟體團隊密切合作。
9. **feedback** (n.) — 回饋、意見、反應
   - *Please give me some feedback on my presentation.*
   - 請給我一些關於我簡報的回饋意見。
10. **monitor** (v.) — 監控、監測、觀察
   - *We need to monitor the system performance constantly.*
   - 我們需要持續監控系統性能。

## 📘 英文文法
### Conditional Sentences (Type 1)
用於表達如果某條件發生，未來就會產生某結果的預測，強調可能性較高。
- If we optimize the code, the app will run faster. (如果我們優化程式碼，應用程式會跑得更快。)
- If you finish debugging, we can go home early. (如果你調試完畢，我們就能早點回家。)
- If the sensor fails, we will get an error message. (如果感測器故障，我們會收到錯誤訊息。)
### Phrasal Verbs with "set"
動詞 "set" 加上不同介系詞或副詞，構成新的意義，常用於日常或工作情境。
- Let's set up the new server this afternoon. (我們今天下午來設定新的伺服器吧。)
- We need to set out clear goals for this project. (我們需要為這個專案訂定明確的目標。)
- I always set aside some time for learning new tech. (我總會撥出一些時間學習新技術。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - 明日、仕事があります。
   - 我明天有工作。
2. **かいしゃ** / 会社 / kaisha — 公司
   - 私の会社は台北にあります。
   - 我的公司在台北。
3. **かいぎ** / 会議 / kaigi — 會議
   - 午後に会議があります。
   - 下午有會議。
4. **しりょう** / 資料 / shiryou — 資料
   - この資料を読んでください。
   - 請閱讀這份資料。
5. **パソコン** / パソコン / pasokon — 電腦
   - 新しいパソコンが欲しいです。
   - 我想要一台新電腦。
6. **メール** / メール / meeru — 電子郵件
   - 彼にメールを送りました。
   - 我寄了一封電子郵件給他。
7. **じかん** / 時間 / jikan — 時間
   - もう時間がないです。
   - 已經沒時間了。
8. **むずかしい** / 難しい / muzukashii — 困難的
   - 日本語は難しいですが、面白いです。
   - 日文很難，但很有趣。
9. **わかる** / 分かる / wakaru — 明白、懂
   - この問題が分かりません。
   - 我不懂這個問題。
10. **つかう** / 使う / tsukau — 使用
   - AIツールを使います。
   - 我使用AI工具。

## 🗾 日文文法（N5）
### ~ます / ~ません / ~ました / ~ませんでした
**結構**：動詞 + ます / ません / ました / ませんでした
用於表達現在、未來動作或過去動作的肯定與否定，是日語最基本的禮貌體動詞變化。
- 私は毎日会社に行きます。(我每天去公司。)
- 昨日、会議に行きませんでした。(昨天我沒去會議。)
### 名詞 + を + 動詞
**結構**：名詞 + を + 動詞(ます)
助詞「を」用於標示動詞的直接受詞，說明動詞動作的對象，表示「做〇〇」。
- 資料を読みます。(我讀資料。)
- コーヒーを飲みます。(我喝咖啡。)
