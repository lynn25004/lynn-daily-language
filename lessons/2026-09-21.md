## 🇬🇧 英文單字（TOEIC 600-800）
1. **firmware** (n.) — 控制硬體運作的軟體
   - *We need to update the firmware for this IoT device.*
   - 我們需要更新這個物聯網裝置的韌體。
2. **integrate** (v.) — 將不同部分整合在一起
   - *Can we integrate this new sensor into our system?*
   - 我們能把這個新感測器整合到我們的系統嗎？
3. **prototype** (n.) — 產品的第一個實體模型
   - *The prototype worked well in the lab.*
   - 這個原型在實驗室運作得不錯。
4. **debug** (v.) — 找出並修正程式錯誤
   - *It took me hours to debug this tricky code.*
   - 我花了數小時來偵錯這段難搞的程式碼。
5. **optimize** (v.) — 使某事物達到最佳狀態
   - *We need to optimize the code for better performance.*
   - 我們需要優化程式碼以提升效能。
6. **deadline** (n.) — 完成某事的最終期限
   - *The deadline for this project is next Friday.*
   - 這個專案的截止日期是下週五。
7. **commute** (v.) — 往返於家和工作地點
   - *My commute to work usually takes about 30 minutes.*
   - 我通勤上班通常大約需要三十分鐘。
8. **innovative** (adj.) — 引入新方法或新思想
   - *That's an innovative solution for renewable energy.*
   - 那是再生能源的一個創新解決方案。
9. **collaborate** (v.) — 與他人一起工作或合作
   - *Let's collaborate on this new AI tool project.*
   - 我們來合作這個新的 AI 工具專案吧。
10. **feedback** (n.) — 對表現或產品的意見
   - *We received good feedback on our new safety system.*
   - 我們的新安全系統收到了不錯的回饋。

## 📘 英文文法
### Used to / Be used to / Get used to
「Used to」表過去習慣或狀態；「be used to」表習慣某事；「get used to」表逐漸習慣。
- I used to play video games every night.（我以前每天晚上都玩電玩。）
- He is used to working with embedded systems.（他習慣於處理嵌入式系統。）
- It took me a while to get used to the new AI interface.（我花了一些時間才習慣新的 AI 介面。）
### Conditional Sentences (If 句型)
If 句型表達條件與結果。Type 1 說可能發生的事；Type 2 說與現實相反或不太可能的事。
- If you finish the code today, we will test it tomorrow.（如果你今天完成程式碼，我們明天就測試它。）
- If I had more time, I would learn more about renewable energy.（如果我有更多時間，我會學習更多關於再生能源的知識。）
- If the sensor works, the IoT device will be perfect.（如果感測器能運作，這個物聯網裝置就完美了。）

## 🗾 日文文法（N5）
### 〜ましょう / 〜ませんか (邀請/提議)
**結構**：動詞ます形 + ましょう / 動詞ます形 + ませんか
「〜ましょう」表示一起做或提議做某事；「〜ませんか」更委婉地邀請或建議對方。
- 一緒にAIツールを勉強しましょう。 （我們一起學習 AI 工具吧。）
- 明日、新しいプロジェクトを始めませんか。 （明天不一起開始新專案嗎？）
### 名詞 + が + あります / います (存在句)
**結構**：場所 + に + 名詞 + が + あります/います
「あります」用於非生物（物品、抽象概念）；「います」用於生物（人、動物）。
- わたしの部屋にパソコンがあります。 （我的房間有電腦。）
- 会社にエンジニアがたくさんいます。 （公司裡有很多工程師。）
