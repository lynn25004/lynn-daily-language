# 2026-10-30（週五）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施（計畫或功能）
   - *We need to implement this new feature by next month.*
   - 我們需要在下個月前實施這個新功能。
2. **optimize** (v.) — 優化、最佳化（效能或效率）
   - *Can you help me optimize this code for better performance?*
   - 你能幫我優化這段程式碼，讓它表現更好嗎？
3. **troubleshoot** (v.) — 排除故障、解決問題
   - *I spent hours trying to troubleshoot the network issue yesterday.*
   - 我昨天花了數小時嘗試排除網路問題。
4. **deadline** (n.) — 截止日期、最後期限
   - *The deadline for this project is really tight, unfortunately.*
   - 很不幸，這個專案的截止日期真的很趕。
5. **feedback** (n.) — 回饋、意見（對表現或產品）
   - *We got some positive feedback on the new user interface.*
   - 我們收到了關於新使用者介面的一些正面回饋。
6. **prototype** (n.) — 原型、樣本（產品或系統）
   - *Let's build a quick prototype to test the concept first.*
   - 我們快速製作一個原型來測試這個概念吧。
7. **commute** (n./v.) — 通勤（上下班的路程）
   - *My commute to work is usually about 30 minutes by scooter.*
   - 我通勤上班通常騎機車約 30 分鐘。
8. **sustainable** (adj.) — 永續的、可持續的（發展或資源）
   - *More companies are focusing on sustainable energy solutions now.*
   - 現在越來越多公司專注於永續能源解決方案。
9. **integrate** (v.) — 整合、結合（不同部分）
   - *We need to integrate the new module with the existing system.*
   - 我們需要將新模組與現有系統整合。
10. **recharge** (v.) — 充電、休息（補充體力或精力）
   - *I really need the weekend to recharge and relax a bit.*
   - 我真的很需要週末來充電休息一下。

## 📘 英文文法
### Phrasal verbs with "look" (look forward to, look into, look up)
這些是動詞和介系詞組成的片語，意思會和原動詞不同，讓口語表達更自然，也能表達期待、調查或查找。
- I'm really looking forward to the long weekend! (我真的很期待這個長週末！)
- I'll look into that bug report right after lunch. (我午餐後會馬上調查那個錯誤報告。)
- I need to look up some technical terms for my presentation. (我需要查一些技術術語來做我的簡報。)
### Using "would like to" vs. "want to"
"Would like to" 比 "want to" 更有禮貌，常用於表達願望、請求或提供幫助，讓語氣更委婉，適合各種情境。
- I would like to discuss the project timeline with you. (我想與您討論一下專案時間表。)
- Would you like to join us for a quick coffee break? (您想和我們一起去喝杯咖啡小憩一下嗎？)
- I would like to learn more about embedded systems. (我希望能多學習一些關於嵌入式系統的知識。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - 明日、仕事がありますか？
   - 你明天有工作嗎？
2. **しゅうまつ** / 週末 / shuumatsu — 週末
   - 週末は何をしますか？
   - 週末你要做什麼？
3. **べんきょう** / 勉強 / benkyou — 學習
   - 日本語を毎日勉強します。
   - 我每天學習日文。
4. **しゅみ** / 趣味 / shumi — 興趣
   - あなたの趣味は何ですか？
   - 你的興趣是什麼？
5. **やすみ** / 休み / yasumi — 休息、假日
   - 週末はゆっくり休みます。
   - 週末我要好好休息。
6. **あたらしい** / 新しい / atarashii — 新的
   - 新しいIoTデバイスを買いたいです。
   - 我想買新的 IoT 裝置。
7. **つかう** / 使う / tsukau — 使用
   - このAIツールを使いますか？
   - 你會使用這個 AI 工具嗎？
8. **じかん** / 時間 / jikan — 時間
   - 時間の計画は大切です。
   - 時間規劃很重要。
9. **たのしい** / 楽しい / tanoshii — 快樂的、有趣的
   - 日本語の勉強は楽しいです。
   - 學習日文很有趣。
10. **いく** / 行く / iku — 去
   - 週末、カフェに行きます。
   - 週末我去咖啡廳。

## 🗾 日文文法（N5）
### ～たいです (tai desu)
**結構**：動詞(ます形) + たいです
用來表達自己想要做某件事情的願望，將動詞的ます形去掉「ます」後加上「たいです」。這是 N5 常用來表達個人願望的句型。
- 週末、映画を見たいです。(週末我想看電影。)
- 新しい技術を勉強したいです。(我想學習新技術。)
### ～に行きます (ni ikimasu)
**結構**：場所名詞 + へ/に + 動詞(ます形) + に行きます
表示去某個地方做某個活動或目的，動詞通常是ます形去掉「ます」後再接「に」。這個句型強調移動的目的。
- 図書館に本を借りに行きます。(我去圖書館借書。)
- カフェにコーヒーを飲みに行きます。(我去咖啡廳喝咖啡。)
