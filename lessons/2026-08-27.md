## 📘 英文文法
### Phrasal Verbs with "up"
這些動詞片語常與 "up" 結合，表達完成、增加、準備或出現等意思，讓對話更自然喔！
- Let's set up a meeting for next week. (我們下週來安排一個會議吧。)
- I need to speed up my learning process. (我需要加快我的學習進度。)
- A new problem just came up during testing. (測試時剛好出現一個新問題。)
### Using "would" for polite requests and hypothetical situations
"Would" 可以用於禮貌地提出請求，或描述非現實的假設情況，讓語氣更委婉。
- Would you mind helping me with this report? (你介意幫我處理這份報告嗎？)
- If I had more time, I would learn another language. (如果我有更多時間，我會學習另一種語言。)
- I would like to know more about IoT security. (我想要多了解物聯網安全。)

## 🗾 日文文法（N5）
### ～は～です / ではありません
**結構**：名詞 + は + 名詞 + です / ではありません
用於陳述事實或表明身分，"は" 標示主題，"です" 表示肯定，"ではありません" 表示否定。
- わたしは エンジニアです。(我是工程師。)
- これは わたしの パソコンではありません。(這不是我的電腦。)
### 動詞(ます形) + たいです
**結構**：動詞(ます形) + たいです
表示說話者想要做某事，用於表達願望或意圖，是非常實用的句型喔。
- あたらしい ぎじゅつを べんきょうしたいです。(我想學習新技術。)
- にほんごで はなしたいです。(我想用日語說話。)
