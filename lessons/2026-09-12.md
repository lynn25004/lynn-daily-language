## 📘 英文文法
### 第一類條件句 (If... will...)
描述未來可能發生的真實情況，或在某條件滿足下會發生的結果。
- If you finish early, we will grab coffee. (如果你早點結束，我們就去喝咖啡。)
- If it rains tomorrow, I will stay home and read. (如果明天下雨，我就待在家裡看書。)
- If the sensor works, we will collect a lot of data. (如果感測器能運作，我們將會收集到很多資料。)
### 片語動詞 with 'up'
學習不同 'up' 結尾的動詞片語，例如 'set up' (建立) 和 'come up with' (想出)。
- Can you help me set up this new device? (你能幫我設定這個新設備嗎？)
- I need to come up with a solution by Friday. (我需要在週五前想出一個解決方案。)
- Let's speed up the process to meet the deadline. (我們加快進度以趕上截止日期吧。)

## 🗾 日文文法（N5）
### 想做某事 (たいです)
**結構**：動詞(ます形) + たいです
表達自己想要做某件事情的願望或願望，非常常用於日常對話。
- 週末、ゲームをしたいです。 (週末我想玩遊戲。)
- 新しいIoTデバイスを作りたいです。 (我想製作一個新的IoT設備。)
### 在某地做某事 (場所 + で + 動詞)
**結構**：場所 + で + 動詞
表示動作發生的地點，助詞「で」標示了進行該動作的場所。
- 図書館で本を読みます。 (我在圖書館讀書。)
- 家で日本語を勉強します。 (我在家裡學習日文。)
