## 📘 英文文法
### 動名詞作主詞/受詞
動名詞 (-ing 形式) 可以像名詞一樣當作句子的主詞或受詞，表示一個動作或活動。
- Coding is my favorite hobby. (寫程式是我最喜歡的嗜好。)
- I enjoy learning new programming languages. (我喜歡學習新的程式語言。)
- Monitoring system logs is crucial for stability. (監控系統日誌對穩定性至關重要。)
### 不定詞表目的
使用 "to + 動詞原形" 來表達目的，說明為什麼要做某事。
- I study English to improve my career prospects. (我學英文是為了提升我的職涯前景。)
- Engineers use AI tools to solve complex problems. (工程師使用AI工具來解決複雜問題。)
- He went to the lab to test the new device. (他去實驗室測試新裝置。)

## 🇯🇵 日文單字（N5）
1. **おやすみ** / お休み / oyasumi — 休假，休息
   - 週末はお休みです。
   - 週末是我的休假日。
2. **すき** / 好き / suki — 喜歡
   - わたしはにほんごのべんきょうがすきです。
   - 我喜歡學日文。
3. **べんきょう** / 勉強 / benkyou — 學習
   - まいにち、にほんごをべんきょうします。
   - 我每天學習日文。
4. **しごと** / 仕事 / shigoto — 工作
   - かれはエンジニアのしごとがすきです。
   - 他喜歡工程師的工作。
5. **あたらしい** / 新しい / atarashii — 新的
   - あたらしいスマートフォンがほしいです。
   - 我想要一支新智慧型手機。
6. **じかん** / 時間 / jikan — 時間
   - しゅうまつはじゆうなじかんがおおいです。
   - 週末有很多自由時間。
7. **たのしい** / 楽しい / tanoshii — 快樂的，有趣的
   - プログラミングはとてもたのしいです。
   - 寫程式非常有趣。
8. **みる** / 見る / miru — 看
   - わたしはYouTubeでぎじゅつのどうがをみます。
   - 我在YouTube上看技術影片。
9. **なに** / 何 / nani — 什麼
   - しゅうまつになにをしますか。
   - 週末你會做什麼？
10. **いつも** / いつも / itsumo — 總是，一直
   - かれはいつもあたらしいぎじゅつをまなびます。
   - 他總是學習新技術。

## 🗾 日文文法（N5）
### 名詞 + は + 名詞 + です
**結構**：名詞1 + は + 名詞2 + です
這是日文最基本的肯定句型，用來表示「N1是N2」，「は」是主題助詞。
- わたしはエンジニアです。(我是工程師。)
- これはわたしのしゅみです。(這是我的興趣。)
### 動詞(ます形) + たいです
**結構**：動詞(ます形) + たいです
這個句型用來表達說話者想做某事的願望或希望。
- あたらしいIoTデバイスをつくりたいです。(我想製作新的IoT裝置。)
- もっとにほんごをべんきょうしたいです。(我想更努力學習日文。)
