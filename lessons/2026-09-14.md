## 📘 英文文法
### Phrasal Verbs (動詞片語)
動詞與介係詞/副詞結合，創造新意義，常用於日常對話，讓表達更自然。
- Let's look into this issue later. (我們稍後再調查這個問題。)
- I need to figure out how this embedded system works. (我需要弄清楚這個嵌入式系統是如何運作的。)
- Don't give up on your job search yet! (不要這麼快就放棄你的求職！)
### Conditional Sentences Type 1 (條件句 Type 1)
表達未來可能發生且結果也可能實現的狀況，結構為 "If + S + V (現在式), S + will + V (原形)"。
- If you study hard, you will improve your English. (如果你努力學習，你的英文會進步。)
- If the IoT device connects to the network, we will get the data. (如果 IoT 設備連接到網路，我們就會收到數據。)
- If I pass the interview, I will celebrate with hotpot. (如果我通過面試，我就會用火鍋慶祝。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - しごとは たのしいです。
   - 工作很有趣。
2. **べんきょう** / 勉強 / benkyou — 學習
   - まいにち にほんごを べんきょうします。
   - 我每天學習日語。
3. **きく** / 聞く / kiku — 聽，問
   - おんがくを ききます。
   - 我聽音樂。
4. **はなす** / 話す / hanasu — 說，講
   - にほんごを はなしましょう。
   - 我們說日語吧。
5. **わかる** / 分かる / wakaru — 懂，明白
   - いみが わかりますか。
   - 你明白意思嗎？
6. **しゅみ** / 趣味 / shumi — 興趣，嗜好
   - わたしの しゅみは プログラミングです。
   - 我的興趣是編程。
7. **むずかしい** / 難しい / muzukashii — 難的，困難的
   - この もんだいは むずかしいです。
   - 這個問題很難。
8. **まいにち** / 毎日 / mainichi — 每天
   - まいにち コーヒーを のみます。
   - 我每天喝咖啡。
9. **れんしゅう** / 練習 / renshuu — 練習
   - めんせつの れんしゅうを しましょう。
   - 我們來練習面試吧。
10. **たいへん** / 大変 / taihen — 辛苦的，嚴重的
   - しごとは たいへんですが、たのしいです。
   - 工作很辛苦，但很有趣。

## 🗾 日文文法（N5）
### ～は～です (wa...desu)
**結構**：名詞 + は + 名詞/形容詞 + です
用來表示「A是B」或「A是～的」的基本句型，用は提示主題，です表示肯定。
- わたしは エンジニアです。 (我是工程師。)
- これは わたしの しゅみです。 (這是我的興趣。)
### 動詞のます形 (Doushi no masu-kei)
**結構**：動詞 + ます (去掉「ます」就是ます形)
動詞的禮貌體，用於一般日常對話，表示現在或未來動作，也可以用於邀請或建議。
- にほんごを べんきょうします。 (我學習日語。)
- あした、かいしゃに いきます。 (我明天要去公司。)
