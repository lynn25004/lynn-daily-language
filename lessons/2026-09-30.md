# 2026-09-30（週三）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施計畫
   - *Let's implement this new feature soon!*
   - 我們快點實施這個新功能吧！
2. **optimize** (v.) — 優化、最佳化處理
   - *We need to optimize the system performance.*
   - 我們需要優化系統的效能。
3. **troubleshoot** (v.) — 排除故障、解決問題
   - *Can you help me troubleshoot this bug?*
   - 你可以幫我排除這個程式錯誤嗎？
4. **prototype** (n.) — 原型、樣品模型
   - *The prototype works pretty well already!*
   - 這個原型已經運作得相當好了！
5. **integrate** (v.) — 整合、結合應用
   - *Let's integrate this module into the main project.*
   - 我們來把這個模組整合到主專案中吧。
6. **efficient** (adj.) — 高效率的、效能好的
   - *This new algorithm is super efficient.*
   - 這個新演算法超級有效率。
7. **deadline** (n.) — 截止日期、最後期限
   - *The deadline for this task is tomorrow.*
   - 這項任務的截止日期是明天。
8. **feedback** (n.) — 反饋、意見回饋
   - *Thanks for your valuable feedback!*
   - 謝謝你寶貴的意見回饋！
9. **collaborate** (v.) — 合作、協同工作
   - *We should collaborate on this exciting project.*
   - 我們應該在這個令人興奮的專案上合作。
10. **device** (n.) — 裝置、設備機具
   - *This new IoT device is really cool.*
   - 這個新的物聯網裝置真的很酷。

## 📘 英文文法
### 未來式：will vs. be going to
「will」用於即興決定或一般預測；「be going to」用於事先計劃好的行動或有證據的預測。
- I will start working on that task after lunch. (我午餐後會開始處理那項任務。)
- We are going to have a team meeting tomorrow morning. (我們明天早上將要開團隊會議。)
- Look at the dark clouds; it's going to rain soon! (看看那些烏雲；很快就要下雨了！)
### 情態助動詞：should (給予建議)
「should」用來給予建議、提出義務或表達預期，語氣比「must」輕，表示「應該」做某事。
- You should double-check your code before committing it. (你提交程式碼前應該再檢查一次。)
- Engineers should always keep learning new technologies. (工程師們應該要不斷學習新技術。)
- Maybe we should take a short break now. (或許我們現在應該休息一下。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作、職務
   - あなたのしごとはなんですか。
   - 你的工作是什麼？
2. **かいしゃ** / 会社 / kaisha — 公司、企業
   - わたしはかいしゃへいきます。
   - 我去公司。
3. **でんき** / 電気 / denki — 電、電力
   - でんきをつけます。
   - 打開電燈。
4. **つかう** / 使う / tsukau — 使用、利用
   - このツールをつかいますか。
   - 你使用這個工具嗎？
5. **むずかしい** / 難しい / muzukashii — 困難的、不易的
   - このもんだいはむずかしいです。
   - 這個問題很難。
6. **かんたん** / 簡単 / kantan — 簡單的、容易的
   - それはかんたんです。
   - 那很簡單。
7. **まいにち** / 毎日 / mainichi — 每天、日常
   - まいにち、にほんごをべんきょうします。
   - 我每天學習日語。
8. **きょう** / 今日 / kyou — 今天、本日
   - きょうはすいようびです。
   - 今天是星期三。
9. **べんきょう** / 勉強 / benkyou — 學習、用功
   - にほんごのべんきょうはたのしいです。
   - 學習日語很有趣。
10. **たのしい** / 楽しい / tanoshii — 快樂的、有趣的
   - このしごとはとてもたのしいです。
   - 這份工作非常有趣。

## 🗾 日文文法（N5）
### 動詞ます形 / ません形
**結構**：動詞(ます形) / 動詞(ません形)
用於表達禮貌的肯定或否定動詞。ます形表示肯定，ません形表示否定，常用於日常對話或職場情境。
- わたしは毎日日本語を勉強します。 (我每天學習日語。)
- このシステムはまだ使いません。 (這個系統還不使用。)
### 名詞 + は + 名詞 + です / ではありません
**結構**：名詞１ + は + 名詞２ + です / ではありません
這是日語最基礎的判斷句型，用來表達「名詞1 是 名詞2」或「名詞1 不是 名詞2」。
- これはわたしのパソコンです。 (這是我的電腦。)
- あの人はエンジニアではありません。 (那個人不是工程師。)
