## 📘 英文文法
### 第一型條件句 (Conditional Type 1)
表達未來可能發生的事情及其結果，結構是「If + 主詞 + 現在簡單式, 主詞 + will + 原形動詞」。
- If it rains tomorrow, I will work from home. (如果明天下雨，我就在家工作。)
- If you finish the report, we will discuss it. (如果你完成報告，我們就會討論它。)
- If the system works, we will launch it next week. (如果系統運作正常，我們下週就會推出。)
### 動詞片語 (Phrasal Verbs) - "set up" & "figure out"
動詞加上介系詞或副詞，形成新意思。這次專注於「設置/安排」(set up) 和「弄清楚/理解」(figure out)。
- Can you help me set up the new IoT device? (你能幫我設定這個新的物聯網設備嗎？)
- I need to figure out why the code isn't working. (我需要弄清楚為什麼程式碼無法運作。)
- Let's set up a meeting to figure out the issue. (我們安排一個會議來弄清楚這個問題吧。)

## 🗾 日文文法（N5）
### 動詞「ます」形 (Verb Masu Form)
**結構**：動詞ます形 (ます/ません)
「ます」表示肯定，使句子禮貌且用於現在或未來。「ません」表示否定，用來表達不做某事。
- 毎日日本語を勉強します。(我每天學習日語。)
- 明日、会社に行きません。(我明天不去公司。)
### 名詞 + の + 名詞 (Noun + no + Noun)
**結構**：名詞１ + の + 名詞２
「の」用來連接兩個名詞，表示名詞１是名詞２的修飾語、所有者或所屬關係。
- 私のパソコンは新しいです。(我的電腦是新的。)
- これはエンジニアの本です。(這是工程師的書。)
