## 📘 英文文法
### Conditional Sentences Type 1 (if + present, will + base form)
表達未來可能發生的狀況及其結果，條件句用現在式，結果句用未來式，表示可能性高。
- If it rains tomorrow, we will stay home. (如果明天下雨，我們會待在家裡。)
- If you study hard, you will definitely pass the exam. (如果你努力學習，你一定會通過考試。)
- If I have time this weekend, I'll check that IoT device. (如果這個週末我有時間，我會檢查那個物聯網設備。)
### Phrasal Verbs with "look" (look up, look forward to, look into)
動詞 "look" 搭配不同介系詞時，其意思會完全改變，這些片語動詞常用於日常對話。
- I'll look up that new vocabulary word later. (我稍後會查那個新單字。)
- I'm really looking forward to the long weekend. (我真的很期待這個長週末。)
- Let's look into this bug report more carefully tomorrow. (我們明天再仔細調查這個錯誤報告吧。)

## 🇯🇵 日文單字（N5）
1. **にちようび** / 日曜日 / nichiyoubi — 星期日
   - 今日は日曜日です。
   - 今天是星期日。
2. **しゅみ** / 趣味 / shumi — 興趣、嗜好
   - あなたの趣味は何ですか。
   - 你的興趣是什麼？
3. **べんきょう** / 勉強 / benkyou — 學習、讀書
   - 毎日日本語を勉強します。
   - 我每天學習日語。
4. **すき** / 好き / suki — 喜歡
   - 私はAIツールが好きです。
   - 我喜歡AI工具。
5. **ときどき** / 時々 / tokidoki — 有時、偶爾
   - 時々ゲームをします。
   - 我偶爾玩遊戲。
6. **よむ** / 読む / yomu — 讀、閱讀
   - 週末に本を読みます。
   - 週末我會讀書。
7. **きく** / 聞く / kiku — 聽、問
   - 音楽を聞くのが好きです。
   - 我喜歡聽音樂。
8. **いっしょ** / 一緒 / issho — 一起
   - 一緒にコーヒーを飲みませんか。
   - 要不要一起喝咖啡？
9. **しゅうまつ** / 週末 / shuumatsu — 週末
   - 週末は何をしますか。
   - 週末要做什麼？
10. **たのしい** / 楽しい / tanoshii — 快樂的、有趣的
   - とても楽しい一日でした。
   - 這是非常愉快的一天。

## 🗾 日文文法（N5）
### 名詞 + が + 好きです (suki desu)
**結構**：名詞 + が + 好きです
表示喜歡某個事物，通常用於表達個人的喜好、興趣，主語通常是「私」。
- 私は日本語の勉強が好きです。(我喜歡學習日語。)
- 彼は再生エネルギーが好きです。(他喜歡再生能源。)
### 動詞(ます形) + ませんか (masen ka)
**結構**：動詞(ます形) + ませんか
用於禮貌地邀請對方做某事，或提出建議，語氣比「〜ましょう」更客氣、委婉。
- 一緒に映画を見に行きませんか。(要不要一起去看電影？)
- 週末にIoTプロジェクトについて話しませんか。(週末要不要談談IoT專案？)
