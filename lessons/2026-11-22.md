## 📘 英文文法
### 現在完成式 (Present Perfect)
用於表達從過去某時開始一直持續到現在的經驗或動作，或已完成但影響持續到現在的動作。
- I have visited many tech conferences. (我參加過很多科技研討會。)
- She has worked on several embedded projects. (她參與過好幾個嵌入式專案。)
- We haven't tried that new AI tool yet. (我們還沒試過那個新的AI工具。)
### 條件句 (Conditional Sentences Type 1)
用於描述未來可能發生的真實情況，結構為「If + 現在簡單式, will + 動詞原形」。
- If it rains tomorrow, we will stay home and code. (如果明天會下雨，我們就待在家裡寫程式。)
- If you finish the report, you can chill out. (如果你完成報告，就可以放鬆一下。)
- If I learn more Python, I'll build a new IoT device. (如果我學更多Python，我就會做一個新的物聯網裝置。)

## 🗾 日文文法（N5）
### 動詞ます形 (Verb ます form)
**結構**：動詞(ます形) / 動詞(ません形) / 動詞(ました形) / 動詞(ませんでした形)
動詞的禮貌形，表示現在、未來或過去的肯定與否定動作，用於日常正式或禮貌對話。
- わたしはにほんごをべんきょうします。 (我學習日文。)
- きょうはしごとをしませんでした。 (我今天沒有工作。)
### 名詞 + を + 動詞 (Noun + を + Verb)
**結構**：名詞 + を + 動詞(ます)
助詞「を」用來標示動詞的直接受詞，表示動詞作用的對象。
- わたしはコーヒーをのみます。 (我喝咖啡。)
- しゅうまつは本をよみます。 (週末我讀書。)
