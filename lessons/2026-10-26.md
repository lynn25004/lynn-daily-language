# 2026-10-26（週一）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施計畫
   - *Let's implement this new feature soon.*
   - 我們快點實施這個新功能吧。
2. **optimize** (v.) — 優化、使效率最高
   - *We need to optimize our code for speed.*
   - 我們需要優化程式碼以提高速度。
3. **troubleshoot** (v.) — 排除故障、解決問題
   - *Can you help me troubleshoot this error?*
   - 你能幫我排除這個錯誤嗎？
4. **scenario** (n.) — 情境、設想狀況
   - *Consider the worst-case scenario here.*
   - 考慮一下這裡最壞的情況。
5. **collaborate** (v.) — 合作、共同完成
   - *Let's collaborate on this IoT project.*
   - 我們一起合作這個物聯網專案吧。
6. **efficient** (adj.) — 高效的、有效率的
   - *This new AI tool is very efficient.*
   - 這個新的AI工具非常高效。
7. **prototype** (n.) — 原型、初步樣本
   - *We built a prototype last week.*
   - 我們上週做了一個原型。
8. **integrate** (v.) — 整合、結合到一起
   - *We need to integrate these modules.*
   - 我們需要整合這些模組。
9. **feedback** (n.) — 回饋、意見
   - *Please give me some feedback on this.*
   - 請給我一些關於這個的回饋。
10. **deadline** (n.) — 截止日期、最後期限
   - *The deadline for this task is tight.*
   - 這項任務的截止日期很緊。

## 📘 英文文法
### Conditional Sentences (Type 1)
用於描述真實或極可能發生的未來情境，結構為「If + 現在式, will + 動詞原形」。
- If the code compiles, we'll deploy it. (如果程式碼編譯成功，我們就部署它。)
- If you finish early, let's grab coffee. (如果你早點忙完，我們去喝咖啡吧。)
- If they need help, I will assist them. (如果他們需要協助，我會幫他們。)
### 常用片語動詞 (Phrasal Verbs)
動詞與介詞或副詞組成的片語，其意義往往與單字本身不同，常在口語中使用。
- We need to set up the new server. (我們需要設定新的伺服器。)
- I ran into an old colleague today. (我今天巧遇一位老同事。)
- Can you look over this report for me? (你可以幫我瀏覽一下這份報告嗎？)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - わたしのしごとはエンジニアです。
   - 我的工作是工程師。
2. **かいしゃ** / 会社 / kaisha — 公司
   - まいにち、かいしゃへいきます。
   - 我每天去公司。
3. **でんき** / 電気 / denki — 電、電力
   - このへやはでんきがありますか。
   - 這個房間有電嗎？
4. **べんきょう** / 勉強 / benkyou — 學習
   - わたしはにほんごをべんきょうします。
   - 我學習日文。
5. **まいにち** / 毎日 / mainichi — 每天
   - まいにち、コーヒーをのみます。
   - 我每天喝咖啡。
6. **いそがしい** / 忙しい / isogashii — 忙碌的
   - きょうはとてもいそがしいです。
   - 今天非常忙碌。
7. **つくる** / 作る / tsukuru — 製作、創造
   - あたらしいシステムをつくります。
   - 我製作新的系統。
8. **つかう** / 使う / tsukau — 使用
   - このツールをよくつかいます。
   - 我經常使用這個工具。
9. **わかる** / 分かる / wakaru — 懂、明白
   - にほんごがすこしわかります。
   - 我懂一點日文。
10. **きゅうけい** / 休憩 / kyuukei — 休息
   - いまからきゅうけいします。
   - 我現在要休息了。

## 🗾 日文文法（N5）
### 動詞(ます形) + たいです
**結構**：動詞(ます形) + たいです
表示說話者想做某事的願望，將動詞的ます形去掉ます，加上たいです。
- 日本語を勉強したいです。(我想要學習日文。)
- コーヒーを飲みたいです。(我想要喝咖啡。)
### 場所 + に/へ + 行きます/来ます/帰ります
**結構**：場所 + に/へ + 行きます/来ます/帰ります
表示移動的目的地，に是明確指點，へ則強調方向，兩者在很多情況下可互換。
- 会社へ行きます。(我去公司。)
- 日本へ行きたいです。(我想要去日本。)
