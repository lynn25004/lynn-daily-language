# 2026-08-31（週一）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **integrate** (v.) — 整合，將不同部分結合
   - *We need to integrate this new feature into the system quickly.*
   - 我們需要快速將這個新功能整合到系統中。
2. **optimize** (v.) — 優化，使其達到最佳狀態
   - *Let's optimize the code for better performance and speed.*
   - 我們來優化程式碼以獲得更好的效能和速度。
3. **implement** (v.) — 實施，執行某個計畫
   - *We plan to implement the new security protocol next month.*
   - 我們計畫下個月實施新的安全協定。
4. **debug** (v.) — 除錯，修復程式錯誤
   - *I spent all morning trying to debug this tricky issue.*
   - 我花了整個上午試圖除錯這個棘手的問題。
5. **reliable** (adj.) — 可靠的，值得信賴的
   - *We need a reliable network connection for this important project.*
   - 我們這個重要專案需要可靠的網路連線。
6. **collaborate** (v.) — 合作，共同完成任務
   - *It's great to collaborate with such a talented team on this project.*
   - 能與這麼有才華的團隊合作這個專案真是太棒了。
7. **deadline** (n.) — 截止日期，任務最終期限
   - *The deadline for this task is end of day Friday.*
   - 這項任務的截止日期是週五下班前。
8. **prioritize** (v.) — 優先處理，決定輕重緩急
   - *I always try to prioritize my tasks each morning effectively.*
   - 我每天早上都努力有效地安排我的任務優先順序。
9. **feedback** (n.) — 回饋，對某事物的意見
   - *We welcome any feedback on the new software update.*
   - 我們歡迎對新軟體更新的任何回饋意見。
10. **solution** (n.) — 解決方案，問題的答案
   - *I think I found a great solution to this challenging problem!*
   - 我想我找到解決這個挑戰性問題的好方法了！

## 📘 英文文法
### Conditional Sentences (Type 1)
表示未來可能發生且結果可預期的狀況，通常用於假設條件成立。
- If you finish the report, we will go for coffee.（如果你完成報告，我們就去喝咖啡。）
- If the code compiles, we'll deploy it by noon.（如果程式碼編譯成功，我們中午前就會部署。）
- If it rains tomorrow, I'll work from home.（如果明天會下雨，我就在家工作。）
### Phrasal Verbs with 'Look'
動詞搭配介系詞或副詞，形成不同意思的片語動詞，表達更具體動作。
- I'll look up that new AI tool you mentioned.（我會去查你提到那個新的AI工具。）
- I'm looking forward to our team meeting next week.（我很期待我們下週的團隊會議。）
- We need to look into why the system crashed.（我們需要調查系統當機的原因。）

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - 毎日、仕事をします。
   - 我每天工作。
2. **かいぎ** / 会議 / kaigi — 會議
   - 午後から会議があります。
   - 下午有會議。
3. **でんき** / 電気 / denki — 電、電力
   - このへやはでんきがあかるいです。
   - 這房間的電燈很亮。
4. **パソコン** / パソコン / pasokon — 電腦
   - 毎日パソコンをつかいます。
   - 我每天使用電腦。
5. **じかん** / 時間 / jikan — 時間
   - じかんがありません。
   - 沒有時間。
6. **もんだい** / 問題 / mondai — 問題
   - これ、ちょっと問題があります。
   - 這個，有點問題。
7. **わかる** / わかる / wakaru — 懂、明白
   - 日本語がわかりますか。
   - 你懂日文嗎？
8. **いそがしい** / 忙しい / isogashii — 忙碌的
   - きょうはとてもいそがしいです。
   - 我今天非常忙碌。
9. **きゅうけい** / 休憩 / kyuukei — 休息
   - ちょっときゅうけいしましょう。
   - 我們稍微休息一下吧。
10. **はじめる** / 始める / hajimeru — 開始
   - 10じにかいぎを始めます。
   - 10點開始會議。

## 🗾 日文文法（N5）
### 動詞(ます形) + ましょう
**結構**：動詞(ます形) + ましょう
用來邀請或提議大家一起做某事，語氣輕鬆友好，是很實用的表達。
- コーヒーを飲みましょう。（我們喝咖啡吧。）
- いっしょにべんきょうしましょう。（我們一起學習吧。）
### 名詞 + を + 動詞(ます)
**結構**：名詞 + を + 動詞(ます)
助詞「を」表示動詞的直接受詞，指出動作的對象，是基礎且重要的用法。
- 水を飲みます。（我喝水。）
- 本を読みます。（我讀書。）
