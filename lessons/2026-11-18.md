## 📘 英文文法
### 未來真實條件句 (If + 現在簡單式, will + 原形動詞)
用於描述未來可能發生，且結果很可能實現的情況。
- If it rains tomorrow, I will stay home. (如果明天下雨，我會待在家。)
- If you finish early, we can grab coffee. (如果你早點完成，我們可以去喝咖啡。)
- If the system works, we will deploy it. (如果系統運作正常，我們就會部署。)
### 常見動詞片語 (Phrasal Verbs)
動詞加介系詞或副詞，形成新意思，在日常對話中很常用。
- I need to set up the new device. (我需要設定新設備。)
- Can you figure out this problem? (你能搞懂這個問題嗎？)
- Let's break down the task. (我們來分解一下這項任務。)

## 🗾 日文文法（N5）
### 動詞て形 + ください (請做...)
**結構**：動詞て形 + ください
用於禮貌地請求對方做某事，是很實用的日常指令。
- ちょっと待ってください。(請稍等一下。)
- 資料を読んでください。(請閱讀資料。)
### 名詞 + で (動作場所)
**結構**：場所名詞 + で + 動詞
表示動作或事件發生的地點，例如在公司或咖啡廳。
- 会社で働きます。(在公司工作。)
- カフェでコーヒーを飲みます。(在咖啡廳喝咖啡。)
