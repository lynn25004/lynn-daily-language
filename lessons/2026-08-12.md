# 2026-08-12（週三）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **optimize** (v.) — 改善效率或效能
   - *We need to optimize the code for speed.*
   - 我們需要優化程式碼以提高速度。
2. **integrate** (v.) — 整合或結合
   - *Let's integrate this module into the main system.*
   - 我們把這個模組整合到主系統吧。
3. **deploy** (v.) — 部署或啟用
   - *The new feature will deploy next week.*
   - 新功能下週會部署。
4. **monitor** (v./n.) — 監控或監視
   - *We need to monitor the server performance closely.*
   - 我們需要密切監控伺服器性能。
5. **feedback** (n.) — 回饋意見
   - *Can you give me some feedback on this design?*
   - 你能給我一些關於這個設計的回饋嗎？
6. **deadline** (n.) — 截止日期
   - *The deadline for this project is Friday.*
   - 這個專案的截止日期是週五。
7. **prioritize** (v.) — 優先處理
   - *I need to prioritize my tasks for today.*
   - 我今天需要優先處理我的任務。
8. **debug** (v.) — 除錯
   - *I spent all morning debugging this issue.*
   - 我花了整個早上在除錯這個問題。
9. **prototype** (n.) — 原型或樣品
   - *We're building a prototype for the new device.*
   - 我們正在為新設備製作原型。
10. **scalable** (adj.) — 可擴展的
   - *Is this architecture scalable for future growth?*
   - 這個架構對未來成長來說可擴展嗎？

## 📘 英文文法
### 條件句 (Conditional Sentences Type 1)
用來描述未來可能發生的情況及其結果，通常與事實相關，表達可能性。
- If you finish this task, we can go home early. (如果你完成這個任務，我們可以早點回家。)
- If the power goes out, the IoT devices won't work. (如果停電，物聯網設備就不會運作。)
- We'll launch the product if the test results are good. (如果測試結果良好，我們就會發布產品。)
### 被動語態 (Passive Voice - 現在簡單式)
強調動作的承受者而非執行者，常用於描述事實、過程或客觀資訊，主詞+be動詞+Vpp。
- The new software is developed by our team. (新軟體是由我們團隊開發的。)
- This sensor is used to detect temperature changes. (這個感測器用於偵測溫度變化。)
- Reports are submitted every Friday. (報告每週五提交。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - 今日は仕事が多いです。
   - 今天工作很多。
2. **かいしゃ** / 会社 / kaisha — 公司
   - 私は会社で働きます。
   - 我在公司上班。
3. **かいぎ** / 会議 / kaigi — 會議
   - 午後から会議があります。
   - 下午有會議。
4. **パソコン** / パソコン / pasokon — 個人電腦
   - パソコンを使っています。
   - 我正在使用電腦。
5. **じかん** / 時間 / jikan — 時間
   - 時間がありますか？

   - 毎日日本語を勉強します。

## 🗾 日文文法（N5）
### 動詞(ます形) + ましょうか
**結構**：動詞(ます形) + ましょうか
表示提議為對方做某事或一起做某事，語氣禮貌且帶有詢問的意圖。
- 手伝いましょうか？ (我來幫忙好嗎？)
- 始めましょうか？ (我們開始吧？)
### 〜てください
**結構**：動詞(て形) + ください
用來請求或命令對方做某事，語氣比「〜なさい」委婉，是非常常用的表達方式。
- ここに座ってください。 (請坐在這裡。)
- この資料を読んでください。 (請閱讀這份資料。)
