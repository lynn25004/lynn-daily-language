# 2026-11-20（週五）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **optimize** (v.) — 最佳化，讓系統效能更好
   - *We need to optimize our code for faster performance.*
   - 我們需要最佳化程式碼以提高執行速度。
2. **debug** (v.) — 除錯，找出並修復程式錯誤
   - *I spent all morning trying to debug this tricky issue.*
   - 我整個早上都在努力處理這個棘手的問題。
3. **interface** (n.) — 介面，人與軟硬體互動的橋樑
   - *The user interface of this app is super intuitive.*
   - 這個應用程式的使用者介面非常直觀。
4. **integrate** (v.) — 整合，將不同系統或元件結合
   - *We need to integrate this new module into the existing system.*
   - 我們需要將這個新模組整合到現有系統中。
5. **deploy** (v.) — 部署，將應用程式上線使用
   - *We plan to deploy the new version next week.*
   - 我們計畫下週部署新版本。
6. **algorithm** (n.) — 演算法，解決特定問題的步驟
   - *The AI uses a complex algorithm to analyze data.*
   - 這個AI使用一個複雜的演算法來分析數據。
7. **prototype** (n.) — 原型，初步的產品模型或樣本
   - *Let's build a simple prototype to test the concept.*
   - 我們來建立一個簡單的原型來測試這個概念。
8. **feedback** (n.) — 回饋，對工作或產品的意見
   - *Any feedback on my presentation would be great.*
   - 關於我的簡報，任何回饋都會很棒。
9. **deadline** (n.) — 截止日期，完成任務的最後期限
   - *The project deadline is next Friday, so let's hurry.*
   - 專案截止日期是下週五，所以我們快點吧。
10. **collaborate** (v.) — 合作，與團隊成員一起工作
   - *We often collaborate with other teams on big projects.*
   - 我們經常與其他團隊合作進行大型專案。

## 📘 英文文法
### 第一類條件句 (If... will...)
表達未來可能發生的情況及其結果，條件句用現在簡單式，主句用未來簡單式。
- If we finish this task early, we'll grab some coffee. (如果我們早點完成這項任務，我們就去喝咖啡。)
- If the server goes down, I will restart it right away. (如果伺服器當機，我會立刻重啟它。)
- She will join the demo if her schedule permits. (如果她的行程允許，她會參加演示。)
### 常用片語動詞
動詞與介系詞或副詞結合產生新意義，讓英文對話更自然。
- I need to look into this bug report further. (我需要進一步調查這個錯誤報告。)
- Can you help me figure out how this IoT device works? (你能幫我弄清楚這個物聯網設備怎麼運作嗎？)
- Let's catch up over lunch next week. (我們下週午餐時再好好聊聊吧。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - 明日、仕事がありますか。
   - 你明天有工作嗎？
2. **かいぎ** / 会議 / kaigi — 會議
   - 午後から会議があります。
   - 下午有會議。
3. **きゅうけい** / 休憩 / kyuukei — 休息
   - 少し休憩しましょうか。
   - 我們休息一下好嗎？
4. **じかん** / 時間 / jikan — 時間
   - 時間がありません。
   - 我沒有時間。
5. **もんだい** / 問題 / mondai — 問題
   - この問題は難しいです。
   - 這個問題很難。
6. **きょう** / 今日 / kyou — 今天
   - 今日は金曜日です。
   - 今天是星期五。
7. **あした** / 明日 / ashita — 明天
   - 明日は何をしますか。
   - 你明天要做什麼？
8. **しゅうまつ** / 週末 / shuumatsu — 週末
   - 週末は家で休みます。
   - 週末我會在家休息。
9. **べんきょう** / 勉強 / benkyou — 學習
   - 毎日日本語を勉強します。
   - 我每天學習日文。
10. **わかる** / 分かる / wakaru — 懂，明白
   - 先生、よく分かりました。
   - 老師，我懂了。

## 🗾 日文文法（N5）
### 動詞禮貌體 (肯定/否定)
**結構**：動詞(ます形) + ます / ません
用來表示現在或未來的肯定或否定行為，是日文最基本的禮貌體動詞形式。
- 毎日日本語を勉強します。 (我每天學習日文。)
- 今日は会議に行きません。 (我今天不去開會。)
### 「是/不是」的句型
**結構**：名詞1 + は + 名詞2 + です / ではありません
用於說明「名詞1是名詞2」或「名詞1不是名詞2」，是日文最基礎的判斷句型。
- これは私のパソコンです。 (這是我的電腦。)
- あの人はエンジニアではありません。 (那個人不是工程師。)
