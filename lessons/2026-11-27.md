## 📘 英文文法
### 現在完成式 (Present Perfect Tense)
用於表達過去發生的動作或狀態，持續到現在或對現在有影響，或表示經驗。
- I have worked on this IoT project for three months already. (我已經在這個物聯網專案上工作三個月了。)
- She has never tried building an embedded system before. (她以前從未嘗試過製作嵌入式系統。)
- Have you ever updated your AI tool's firmware? (你曾經更新過你的AI工具韌體嗎？)
### 片語動詞 (Phrasal Verbs)
由動詞加上介系詞或副詞組成，意思通常與原動詞不同，廣泛用於日常口語。
- I need to look up how to fix this coding error. (我需要查詢如何修復這個程式錯誤。)
- Let's set up the new server this afternoon before the weekend. (我們今天下午來設定新的伺服器吧。)
- Can you help me figure out this complex circuit diagram? (你能幫我搞懂這個複雜的電路圖嗎？)

## 🗾 日文文法（N5）
### 名詞 + は + 名詞 + です
**結構**：名詞 + は + 名詞 + です
這是一個基礎的日語肯定句型，用於表達「A是B」或「A是某物/某人」，介紹事物或人的身份。
- 私はエンジニアです。(我是工程師。)
- これは私のコンピュータです。(這是我的電腦。)
### 動詞(ます形) + ましょうか
**結構**：動詞(ます形) + ましょうか
這個句型用於提議「我來做...好嗎？」或邀請對方「我們一起做...吧？」，表示建議或詢問對方意願。
- コーヒーを入れましょうか。(我來泡咖啡好嗎？)
- 資料を作りましょうか。(我來製作資料好嗎？)
