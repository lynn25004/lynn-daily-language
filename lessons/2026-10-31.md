# 2026-10-31（週六）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **optimize** (v.) — 讓效能更好，最佳化
   - *Let's optimize this code for faster speed.*
   - 我們來優化這段程式碼，讓速度更快。
2. **debug** (v.) — 找出並修復程式錯誤
   - *I spent hours trying to debug this circuit.*
   - 我花了數小時試圖除錯這個電路。
3. **implement** (v.) — 執行並實現某計畫
   - *We need to implement this new feature soon.*
   - 我們需要盡快實作這個新功能。
4. **scenario** (n.) — 可能發生的一種情況
   - *What's the worst-case scenario for this project?*
   - 這個專案最壞的情況會是怎樣？
5. **feedback** (n.) — 對某事提出的意見
   - *Your feedback helps us improve a lot!*
   - 你的回饋對我們改進很有幫助！
6. **reliable** (adj.) — 穩定且值得信賴的
   - *We need a reliable power supply for IoT devices.*
   - 我們的IoT設備需要可靠的電源。
7. **commute** (n./v.) — 每天上下班的行程
   - *My commute to work usually takes an hour.*
   - 我通勤上班通常需要一小時。
8. **prototype** (n.) — 初步測試用的模型
   - *The team is building a new prototype this week.*
   - 團隊這週正在製作一個新原型。
9. **integrate** (v.) — 將不同系統結合
   - *We should integrate these two modules easily.*
   - 我們應該能輕鬆整合這兩個模組。
10. **hobby** (n.) — 閒暇時的興趣活動
   - *What's your favorite hobby outside of work?*
   - 工作之餘你最喜歡的嗜好是什麼？

## 📘 英文文法
### 未來式：Be going to vs. Will
「Be going to」表計畫或預測，而「will」表即時決定或一般性預測。
- I'm going to work on my IoT project this weekend. (我這個週末打算做我的IoT專案。)
- The system will crash if we don't fix it. (如果我們不修好，系統會當機。)
- Oh, I'll help you debug that code now! (喔，我現在就幫你除錯！)
### 動詞片語：Set up & Look into
動詞與介係詞組合，形成新意思，常用於日常或工作溝通。
- Can you help me set up this new sensor? (你能幫我設定這個新感測器嗎？)
- We need to look into this security vulnerability. (我們需要調查這個安全漏洞。)
- I'm setting up my home lab this afternoon. (我今天下午要建立我的家庭實驗室。)

## 🗾 日文文法（N5）
### 動詞肯定/否定/過去式 (-ます / -ません / -ました / -ませんでした)
**結構**：動詞ます形
用來表示現在或未來會做的動作，以及過去的動作或習慣。
- 週末、映画を見ます。(週末要看電影。)
- 先週は働きませんでした。(上週沒有工作。)
### 想做某事 (-たいです)
**結構**：動詞ます形去ます + たいです
表達說話者想要做某事的願望或意圖，動詞ます形去ます後接「たいです」。
- 新しいプロジェクトを始めたいです。(想開始一個新專案。)
- 日本へ行きたいです。(想去日本。)
