## 📘 英文文法
### "Used to" vs. "Be used to"
Used to 表示過去習慣或事實，be used to 表示習慣於某事。
- I used to play video games every night. (我以前常玩電動。)
- I am used to working late now. (我現在習慣晚下班了。)
- It took time, but he got used to the new system. (花了一些時間，但他習慣了新系統。)
### First Conditional (If + present simple, will + base verb)
用於表達未來可能發生的真實情況及其結果。
- If it rains tomorrow, we will stay indoors. (如果明天會下雨，我們就待在室內。)
- If I finish my tasks early, I'll go for a run. (如果我提早完成工作，我就去跑步。)
- If the system works, we will launch it next month. (如果系統運作正常，我們下個月就會推出。)

## 🗾 日文文法（N5）
### ~ます / ~ません (動詞肯定否定)
**結構**：動詞ます形 / 動詞ません形
表示現在或未來習慣性動作的肯定與否定，是日語動詞最基礎的變化形式。
- まいにちコーヒーをのみます。 (我每天喝咖啡。)
- きょう、テレビをみません。 (我今天不看電視。)
### 名詞 + は + 名詞 + です (基本肯定句)
**結構**：名詞1 + は + 名詞2 + です
用於描述事物、身份或狀態，強調句子的主題，是日語中最基本的肯定句型。
- わたしはエンジニアです。 (我是工程師。)
- これはわたしのほんですよ。 (這是我的書喔。)
