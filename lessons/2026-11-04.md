# 2026-11-04（週三）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施
   - *We need to implement this new feature by next week.*
   - 我們需要在下週前實施這個新功能。
2. **optimize** (v.) — 優化、最佳化
   - *Can you help optimize this code for better performance?*
   - 你能幫忙優化這段程式碼以提升效能嗎？
3. **troubleshoot** (v.) — 故障排除
   - *I spent hours trying to troubleshoot the network issue.*
   - 我花了數小時試圖排除網路問題。
4. **prototype** (n.) — 原型、樣品
   - *Let's build a quick prototype to test the idea.*
   - 我們來快速建一個原型測試這個想法。
5. **integrate** (v.) — 整合、結合
   - *Our team is working to integrate the new module.*
   - 我們的團隊正在努力整合這個新模組。
6. **deadline** (n.) — 截止日期
   - *The project deadline is approaching fast, let's hurry.*
   - 專案截止日期快到了，我們快點吧。
7. **collaborate** (v.) — 合作、協作
   - *We often collaborate with other teams on big projects.*
   - 我們經常與其他團隊合作大型專案。
8. **feedback** (n.) — 回饋、意見
   - *Please give me some feedback on my presentation.*
   - 請給我一些關於我報告的回饋。
9. **innovation** (n.) — 創新
   - *Innovation is key to staying competitive in this field.*
   - 創新是在這個領域保持競爭力的關鍵。
10. **efficient** (adj.) — 有效率的
   - *We need to find a more efficient way to do this task.*
   - 我們需要找到更有效率的方法來完成這項任務。

## 📘 英文文法
### 被動語態 (Passive Voice)
當動作的執行者不重要或未知，或想強調動作的承受者時，我們使用被動語態，結構是「be動詞 + 過去分詞」。
- The new system was launched yesterday. (新系統昨天上線了。)
- This bug needs to be fixed urgently. (這個錯誤需要緊急修復。)
- Many IoT devices are powered by renewable energy. (許多物聯網設備都由再生能源供電。)
### 間接引述 (Reported Speech)
用來轉述別人說過的話，通常需要改變動詞時態、代名詞和時間副詞，以反映說話時的觀點。
- He said he was working on a new embedded project. (他說他正在研究一個新的嵌入式專案。)
- She asked if I could help troubleshoot the issue. (她問我是否能幫忙排除問題。)
- They mentioned the deadline was moved to Friday. (他們提到截止日期已延到星期五。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - わたしのしごとはえんじにあです。
   - 我的工作是工程師。
2. **かいしゃ** / 会社 / kaisha — 公司
   - まいにちかいしゃへいきます。
   - 我每天去公司。
3. **ぎじゅつ** / 技術 / gijutsu — 技術
   - あたらしいぎじゅつにきょうみがあります。
   - 我對新技術很感興趣。
4. **べんきょう** / 勉強 / benkyou — 學習
   - にほんごをべんきょうします。
   - 我學習日文。
5. **たいへん** / 大変 / taihen — 辛苦的；嚴重的
   - しごとはたいへんですが、たのしいです。
   - 工作雖然辛苦，但很有趣。
6. **きゅうけい** / 休憩 / kyuukei — 休息
   - ちょっときゅうけいしましょうか。
   - 我們休息一下好嗎？
7. **じかん** / 時間 / jikan — 時間
   - いま、なんじかんありますか。
   - 現在，你有多少時間？
8. **つくる** / 作る / tsukuru — 製作、製造
   - IoTデバイスをよくつくります。
   - 我經常製作物聯網設備。
9. **わかる** / 分かる / wakaru — 明白、懂
   - このコード、わかりますか。
   - 你懂這段程式碼嗎？
10. **まいにち** / 毎日 / mainichi — 每天
   - まいにちコーヒーをのみます。
   - 我每天喝咖啡。

## 🗾 日文文法（N5）
### 「〜たいです」 (想做某事)
**結構**：動詞ます形 + たいです
表達說話者想要做某件事情的願望，將動詞的ます形後面的「ます」去掉，加上「たいです」即可。
- にほんごをもっとべんきょうしたいです。(我想學更多日文。)
- あたらしいAIツールをつかってみたいです。(我想試用新的AI工具。)
### 「〜ながら」 (一邊...一邊...)
**結構**：動詞ます形 + ながら + 動詞
表示同時進行兩項動作，主要動作放在後半句，前半句的動詞ます形後去掉「ます」加上「ながら」。
- おんがくをききながらしごとをします。(我一邊聽音樂一邊工作。)
- コーヒーをのみながらニュースをみます。(我一邊喝咖啡一邊看新聞。)
