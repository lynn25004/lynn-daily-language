## 📘 英文文法
### 未來式與意圖 (Future Tense and Intentions)
使用 "be going to" 表示事先計畫好的意圖或即將發生的事，"will" 則多用於臨時決定或預測。
- I'm going to work on my IoT project this weekend. (我這個週末會做我的IoT專案。)
- Maybe I will check out that new AI tool tonight. (也許我今晚會看看那個新的AI工具。)
- Our team is going to present the prototype next week. (我們團隊下週將展示原型。)
### 條件句 Type 1 (First Conditional)
用於表示在未來很可能發生的情況及其結果，結構為 "If + S + V (現在簡單式), S + will + V (原形)"。
- If the code compiles, we will deploy it right away. (如果程式碼編譯成功，我們就會立刻部署它。)
- If you finish your tasks early, we can grab a coffee. (如果你早點完成任務，我們可以去喝杯咖啡。)
- If we use renewable energy, we will help the planet. (如果我們使用再生能源，我們就會幫助地球。)

## 🗾 日文文法（N5）
### ~ましょう / ~ませんか (邀請/提議)
**結構**：動詞ます形 + ましょう / 動詞ます形 + ませんか
「~ましょう」表示提議一起做某事，語氣肯定；「~ませんか」則是用於邀請，語氣較為委婉。
- 一緒にAIについて話しましょう！ (我們一起聊聊AI吧！)
- 今度、再生エネルギーの展示会に行きませんか。 (下次，要不要一起去再生能源展？)
### ~たいです (表達願望)
**結構**：動詞ます形 + たいです
將動詞的「ます」形替換成「たいです」，用於表達說話者想做某事的願望或希望。
- 新しいIoTデバイスを開発したいです。 (我想開發新的IoT裝置。)
- もっと日本語を勉強したいです。 (我想學更多日語。)
