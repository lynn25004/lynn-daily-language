## 🇬🇧 英文單字（TOEIC 600-800）
1. **firmware** (n.) — 裝置韌體或軟體
   - *Updating the device's firmware can fix many bugs.*
   - 更新裝置韌體可以修復許多錯誤。
2. **integrate** (v.) — 整合、結合
   - *We need to integrate this new feature smoothly.*

   - *I spent hours trying to troubleshoot this network issue.*

4. **prototype** (n.) — 原型、雛形
   - *Let's build a quick prototype to test the concept.*
   - 我們來快速做個原型測試概念吧。
5. **efficiency** (n.) — 效率、效能
   - *How can we improve the team's work efficiency?*
   - 我們該如何提升團隊的工作效率呢？
6. **allocate** (v.) — 分配、撥給
   - *We need to allocate more resources to this project.*
   - 我們需要為這個專案分配更多資源。

8. **collaborate** (v.) — 合作、協作

9. **feedback** (n.) — 回饋、意見

   - 我們需要優化程式碼以獲得更好的效能。

## 📘 英文文法
### Conditional Sentences (Type 1)
用 If + 現在簡單式, will + 原形動詞，描述現實或很可能發生的假設情況。
- If it rains tomorrow, we will stay home. (如果明天下雨，我們就待在家。)
- If you finish your work early, you can join us. (如果你早點完成工作，就可以加入我們。)
- If the system crashes, we will lose all data. (如果系統當機，我們會失去所有資料。)
### Passive Voice
當想強調動作的承受者而非執行者時使用，結構是 be 動詞 + 動詞過去分詞。
- The report was written by Sarah. (這份報告是莎拉寫的。)
- New features will be added next month. (新功能將在下個月加入。)
- The device is powered by a renewable energy source. (這設備由再生能源供電。)

## 🇯🇵 日文單字（N5）

## 🗾 日文文法（N5）
### 「〜たいです」
**結構**：動詞ます形 + たいです
表示說話者想做某事，用在動詞的「ます」形後面，去掉「ます」再接「たいです」。
- にほんへ いきたいです。(我想去日本。)
- あたらしい ぎじゅつを まなびたいです。(我想學習新技術。)
### 「〜があります/います」
**結構**：名詞 + が + あります (非生物) / います (生物)
表示某處存在某物（非生物用あります）或某人（生物用います）。名詞後接「が」。
- つくえの うえに ほんが あります。(桌子上有書。)
- この システムには もんだいが あります。(這個系統有問題。)
