## 🇬🇧 英文單字（TOEIC 600-800）

   - *We need to update the firmware for this IoT device.*

   - *It's crucial to integrate all these sensors smoothly.*

   - *Can you help me optimize this code for better performance?*
   - 你能幫我優化這段程式碼以提升效能嗎？
4. **scenario** (n.) — 情境、情況

   - 我花了幾個小時試圖排除那個網路問題。

   - *The team is excited about building the first prototype.*

8. **interface** (n.) — 介面

## 📘 英文文法
### 條件句 Type 1 (First Conditional)
用來描述未來可能發生且結果也可能實現的狀況，結構是「If + S + V(現在式), S + will + V(原形)」。
- If we fix this bug, the system will run smoothly.（如果我們修復這個錯誤，系統將會順利運行。）
- If you finish the report early, we can grab some coffee.（如果你提早完成報告，我們可以去喝杯咖啡。）
- If it rains tomorrow, I will just work from home.（如果明天會下雨，我就在家工作。）
### 動名詞 (Gerunds) 作為主詞或受詞
動詞加上-ing變成動名詞，可以當作名詞使用，在句中作主詞或受詞。
- Developing new features is always exciting for engineers.（開發新功能對工程師來說總是令人興奮的。）
- I enjoy learning about the latest AI tools.（我喜歡學習最新的 AI 工具。）
- Troubleshooting complex problems takes a lot of patience.（排除複雜的問題需要很多耐心。）

## 🇯🇵 日文單字（N5）
1. **わかります** / 分かります / wakarimasu — 懂、明白
   - 日本語が分かりますか？
   - 你懂日文嗎？
2. **おもしろい** / 面白い / omoshiroi — 有趣的
   - この本は面白いです。
   - 這本書很有趣。
3. **べんきょう** / 勉強 / benkyou — 學習、讀書
   - 毎日日本語を勉強します。
   - 我每天學日文。
4. **すき** / 好き / suki — 喜歡
   - 私はコーヒーが好きです。
   - 我喜歡咖啡。
5. **しごと** / 仕事 / shigoto — 工作
   - 今日の仕事は大変でした。
   - 今天的工作很辛苦。
6. **かえります** / 帰ります / kaerimasu — 回家、回去
   - 私は家に帰ります。
   - 我回家。
7. **どこ** / 何処 / doko — 哪裡
   - トイレはどこですか？
   - 廁所在哪裡？
8. **いつ** / 何時 / itsu — 什麼時候
   - いつ日本へ行きますか？
   - 你什麼時候去日本？
9. **つくります** / 作ります / tsukurimasu — 製作、製造
   - 私はIoTデバイスを作ります。
   - 我製作 IoT 設備。
10. **とても** / とても / totemo — 非常
   - これはとても美味しいです。
   - 這個非常好吃。

## 🗾 日文文法（N5）
### 名詞 + は + 名詞 + です (N1 wa N2 desu)
**結構**：名詞1 + は + 名詞2 + です
用來陳述「N1就是N2」或「N1是N2」，「は」讀作「wa」，表示前面是主題。
- 私はエンジニアです。（我是工程師。）
- これは私のペンです。（這是我的筆。）
### 動詞(ます形) + ましょう (V(ます) + mashou)
**結構**：動詞(ます形) + ましょう
用來建議或提議做某事，也表示「一起做...吧」或「我們來做...吧」。
- 帰りましょう。（我們回去吧。）
- 日本語を勉強しましょう。（我們來學日文吧。）
