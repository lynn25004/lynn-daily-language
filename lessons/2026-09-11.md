# 2026-09-11（週五）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **commute** (v./n.) — 通勤，上下班路程
   - *My morning commute to work usually takes about 30 minutes.*
   - 我早上通勤上班通常需要大約 30 分鐘。
2. **efficient** (adj.) — 有效率的，高效率的
   - *We need to find a more efficient way to test this software.*
   - 我們需要找到更有效率的方法來測試這個軟體。
3. **troubleshoot** (v.) — 排除故障，解決問題
   - *I spent an hour trying to troubleshoot the network issue this morning.*
   - 我今天早上花了一個小時試圖排除網路問題。
4. **integrate** (v.) — 整合，結合
   - *It's challenging to integrate the new system with the old one.*
   - 將新系統與舊系統整合起來很有挑戰性。
5. **reliable** (adj.) — 可靠的，可信賴的
   - *We need a reliable power source for our IoT devices.*
   - 我們的物聯網設備需要一個可靠的電源。
6. **optimize** (v.) — 最佳化，使達到最佳效果
   - *I'm trying to optimize the code for better performance.*
   - 我正在努力優化程式碼以提高性能。
7. **deadline** (n.) — 截止日期，最後期限
   - *The deadline for this project is next Friday, so let's hurry!*
   - 這個專案的截止日期是下週五，我們快點吧！
8. **feedback** (n.) — 回饋，意見
   - *Can you give me some feedback on my presentation slides?*
   - 你可以給我一些關於我的簡報投影片的回饋嗎？
9. **feature** (n.) — 特色，功能，特徵
   - *This new phone has some really cool AI features.*
   - 這款新手機有一些非常酷的 AI 功能。
10. **device** (n.) — 設備，裝置
   - *I always carry a portable charging device for my phone.*
   - 我總是隨身攜帶一個便攜式充電設備給我的手機。

## 📘 英文文法
### Present Perfect (現在完成式)
描述從過去某個時間點開始的動作或狀態，並持續到現在，或是過去發生但影響到現在的動作。
- I have worked on several embedded system projects.
- She has just finished debugging the new module.
- Have you ever used an AI tool for coding assistance?
### Phrasal Verbs (動詞片語)
動詞與介系詞或副詞結合，形成新的意思，常用於口語中，讓表達更自然生動。
- I need to figure out how to fix this bug.
- Let's speed up the development process.
- Could you check out the new renewable energy report?

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - まいにち、しごとがあります。
   - 我每天都有工作。
2. **まいにち** / 毎日 / mainichi — 每天
   - まいにち、でんしゃでかいしゃへいきます。
   - 我每天搭電車去公司。
3. **えき** / 駅 / eki — 車站
   - かいしゃのちかくに、おおきいえきがあります。
   - 公司附近有一個大車站。
4. **でんしゃ** / 電車 / densha — 電車
   - でんしゃはとてもべんりです。
   - 電車非常方便。
5. **かいしゃ** / 会社 / kaisha — 公司
   - わたしはかいしゃでエンジニアです。
   - 我在公司是一名工程師。
6. **じかん** / 時間 / jikan — 時間
   - しごとがおわるじかんはいつもおそいです。
   - 工作結束的時間總是很晚。
7. **あたらしい** / 新しい / atarashii — 新的
   - あたらしいプロジェクトはたのしいです。

8. **つかう** / 使う / tsukau — 使用

   - 我想要使用AI工具。
9. **べんり** / 便利 / benri — 方便的
   - スマートホームのでバイスはべんりです。

10. **プロジェクト** / プロジェクト / purojekuto — 專案
   - このプロジェクトはおもしろいです。
   - 這個專案很有趣。

## 🗾 日文文法（N5）
### ～は～です (wa...desu)
**結構**：名詞 + は + 名詞/形容詞 + です
用來表示主語是什麼、是誰、或狀態如何，是日語最基本的判斷句型。
- これはわたしのパソコンです。(這是我的電腦。)
- しごとはたのしいです。(工作是快樂的。)
### ～ます形 (Masu form)
**結構**：動詞ます形
動詞ます形用於禮貌的肯定句，常用於日常對話中，表達現在或未來的動作或習慣。
- わたしはまいにち、AIツールをつかいます。(我每天都使用AI工具。)
- あたらしいシステムをかいはつします。(我會開發新的系統。)
