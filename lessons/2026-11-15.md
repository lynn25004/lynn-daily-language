# 2026-11-15（週日）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **optimize** (v.) — 優化、最佳化
   - *We need to optimize the code for better performance.*
   - 我們需要優化程式碼以獲得更好的效能。
2. **debug** (v.) — 除錯、找出問題
   - *I spent hours debugging this tricky bug in the system.*
   - 我花了數小時在這個系統中除錯一個棘手的錯誤。
3. **implement** (v.) — 執行、實施
   - *Let's implement this new feature next week.*
   - 我們下週來實施這項新功能吧。
4. **component** (n.) — 零件、元件
   - *This small component is crucial for the circuit board.*
   - 這個小零件對電路板來說至關重要。
5. **configure** (v.) — 配置、設定
   - *I need to configure the Wi-Fi settings for this device.*
   - 我需要為這個裝置設定Wi-Fi。
6. **prototype** (n.) — 原型、樣品
   - *We are building a new prototype for our IoT device.*
   - 我們正在為我們的物聯網裝置打造一個新原型。
7. **algorithm** (n.) — 演算法
   - *AI tools often use complex algorithms to learn.*
   - AI工具常使用複雜的演算法來學習。
8. **sustainable** (adj.) — 永續的、可持續的
   - *Renewable energy is key to a more sustainable future.*
   - 再生能源是邁向更永續未來的關鍵。
9. **gadget** (n.) — 小工具、裝置
   - *This new smart home gadget is super useful!*
   - 這個新的智慧家庭小工具超級好用！
10. **recharge** (v.) — 充電、恢復精力
   - *After a long week, I need to recharge my batteries.*
   - 辛苦一週後，我需要好好充電、恢復精力。

## 📘 英文文法
### Conditional Sentences Type 1 (If + present, will + base form)
當你談論未來可能發生且結果也可能實現的事情時使用，表示條件和結果。
- If I finish debugging early, I will go for a hike.（如果我提早除錯完畢，我就會去健行。）
- If we optimize the code, the app will run much faster.（如果我們優化程式碼，應用程式會跑快很多。）
- If you configure the IoT device correctly, it will connect to the network.（如果你正確設定物聯網裝置，它就會連上網路。）
### Phrasal Verbs with "up"
動詞與介係詞 "up" 結合，形成一個新意義的片語，常用於日常對話和技術情境。
- Could you help me set up this new server?（你能幫我設定這台新伺服器嗎？）
- I need to look up some documentation for this component.（我需要查閱這個零件的一些文件。）
- Let's clean up the lab before we leave today.（我們今天離開前把實驗室整理一下吧。）

## 🗾 日文文法（N5）
### ~ます / ~ません / ~ました / ~ませんでした
**結構**：動詞ます形 / 動詞ません / 動詞ました / 動詞ませんでした
用來表達動詞的肯定或否定，以及發生在現在或過去。是日文中最基礎的禮貌體動詞變化。
- わたしは まいにち にほんごを べんきょうします。（我每天學習日文。）
- きのうは しごとを しませんでした。（我昨天沒有工作。）
### ~が 好きです (~ga suki desu)
**結構**：名詞 + が + 好きです
用來表達你喜歡某個事物。助詞「が」用於標示你喜歡的對象，是日文中很常用的句型。
- わたしは IoT デバイスが すきです。（我喜歡物聯網裝置。）
- アニメが すきですか？（你喜歡動漫嗎？）
