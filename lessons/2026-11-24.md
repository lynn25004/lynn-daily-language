# 2026-11-24（週二）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **commute** (v./n.) — 通勤（移動上下班）
   - *My commute to work is usually pretty smooth.*
   - 我上班的通勤通常蠻順利的。
2. **deadline** (n.) — 截止日期
   - *We have a tight deadline for this project.*
   - 我們這個專案的截止日期很趕。
3. **troubleshoot** (v.) — 排除故障；解決問題
   - *Can you help me troubleshoot this network issue?*
   - 你能幫我排除這個網路問題嗎？
4. **prototype** (n.) — 原型；樣品
   - *We're building a prototype for the new IoT device.*
   - 我們正在為新的 IoT 裝置打造原型。
5. **efficient** (adj.) — 效率高的
   - *This new algorithm is much more efficient.*
   - 這個新演算法效率高很多。
6. **briefing** (n.) — 簡報；情況說明會
   - *We have a morning briefing at 9 AM.*
   - 我們早上九點有個晨會簡報。
7. **optimize** (v.) — 優化；最佳化
   - *We need to optimize the code for better performance.*
   - 我們需要優化程式碼以提高效能。
8. **sustainable** (adj.) — 可持續的；永續的
   - *Renewable energy is key to a sustainable future.*
   - 再生能源是永續未來的關鍵。
9. **dashboard** (n.) — 儀表板
   - *The new dashboard provides real-time data.*
   - 新的儀表板提供即時數據。
10. **sync** (v.) — 同步
   - *Let's sync our calendars for next week.*
   - 我們同步一下下週的行程吧。

## 📘 英文文法
### 現在完成式 (Present Perfect Tense)
用來描述從過去開始，持續到現在或對現在有影響的動作、經驗或狀態。
- I have already finished my morning report. (我已經完成我的早晨報告了。)
- He has been working on this embedded project for months. (他已經在這個嵌入式專案上工作好幾個月了。)
- Have you ever used this AI tool before? (你以前用過這個 AI 工具嗎？)
### 帶有 "up" 的片語動詞 (Phrasal Verbs with "up")
"Up" 常帶有「完成、增加、準備、建立」等意思，與動詞結合可表達多種情境。
- I need to catch up on my emails. (我需要趕一下我的電子郵件。)
- Let's set up the new IoT sensor. (我們來安裝這個新的 IoT 感測器吧。)
- Can you back up your files regularly? (你可以定期備份你的檔案嗎？)

## 🇯🇵 日文單字（N5）
1. **おはようございます** / ohayou gozaimasu — 早安
   - おはようございます。今日も一日頑張りましょう！
   - 早安。今天一天也一起加油吧！
2. **しごと** / 仕事 / shigoto — 工作
   - わたしのしごとはエンジニアです。
   - 我的工作是工程師。
3. **かいしゃ** / 会社 / kaisha — 公司
   - わたしはかいしゃへいきます。
   - 我去公司。
4. **まいにち** / 毎日 / mainichi — 每天
   - まいにち、にほんごをべんきょうします。
   - 我每天學習日文。
5. **じかん** / 時間 / jikan — 時間
   - いま、なんじですか。
   - 現在幾點了？
6. **かいぎ** / 会議 / kaigi — 會議
   - きょうはかいぎがあります。
   - 今天有會議。
7. **はじめる** / 始める / hajimeru — 開始（他動詞）
   - しごとをはじめるじかんです。
   - 是時候開始工作了。
8. **おわる** / 終わる / owaru — 結束（自動詞）
   - きょうのしごとはもうすぐおわります。
   - 今天的工作快要結束了。
9. **つかう** / 使う / tsukau — 使用
   - このAIツールをつかいます。
   - 我使用這個 AI 工具。
10. **〜たいです** / 〜tai desu — 想做〜
   - もっとにほんごをはなしたいです。
   - 我想要多說日文。

## 🗾 日文文法（N5）
### ます形動詞的肯定與否定 (Masu form conjugation)
**結構**：動詞ます形（例：食べます、食べません、食べました、食べませんでした）
用於表達現在、未來動作或習慣，以及過去動作的肯定與否定。是禮貌體的常用形式。
- わたしはまいにちコーヒーをのみます。(我每天喝咖啡。)
- きのうはしごとをしませんでした。(我昨天沒有工作。)
### 名詞 + は + 名詞 + です / じゃありません (Noun + wa + Noun + desu / ja arimasen)
**結構**：名詞１ + は + 名詞２ + です / じゃありません
用來判斷或介紹事物，表達「A是B」或「A不是B」。是日語最基礎的判斷句。
- これはわたしのPCです。(這是我的電腦。)
- あれはIoTデバイスじゃありません。(那個不是 IoT 裝置。)
