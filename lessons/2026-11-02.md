# 2026-11-02（週一）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行計畫或想法
   - *We need to implement this new feature soon.*
   - 我們需要盡快實施這項新功能。
2. **optimize** (v.) — 讓某事達到最佳效果
   - *How can we optimize this code for speed?*
   - 我們該如何優化這段程式碼來提升速度？
3. **troubleshoot** (v.) — 找出並解決問題
   - *I spent hours trying to troubleshoot the network issue.*
   - 我花了數小時試著排除網路問題。
4. **deadline** (n.) — 完成任務的最終日期
   - *The project deadline is next Friday, so let's hurry!*
   - 專案截止日期是下週五，我們快點吧！
5. **feedback** (n.) — 對成果的意見或建議
   - *Could you give me some feedback on my presentation?*
   - 你能給我一些關於我報告的回饋嗎？
6. **collaborate** (v.) — 與他人一起合作
   - *We should collaborate on this task to finish faster.*
   - 我們應該合作這項任務才能更快完成。
7. **solution** (n.) — 問題的解決方法
   - *I hope we can find a good solution to this bug.*
   - 我希望我們能找到解決這個錯誤的好方法。
8. **prototype** (n.) — 產品的最初模型
   - *The team is working on the first prototype of the device.*
   - 團隊正在製作這個裝置的第一個原型。
9. **integrate** (v.) — 將不同部分結合為一
   - *We need to integrate this module into the main system.*
   - 我們需要將這個模組整合到主系統中。
10. **sync** (v./n.) — 同步、保持一致
   - *Let's sync up later to discuss the project details.*
   - 我們晚點同步一下來討論專案細節。

## 📘 英文文法
### 間接問句 (Indirect Questions)
當問句嵌入另一個句子時，語序會變成陳述句，主詞在動詞前，且不需倒裝。
- Do you know where the server room is? (你知道伺服器機房在哪嗎？)
- I wonder if we can use this AI tool. (我在想我們是否能用這個AI工具。)
- Could you tell me what time the meeting starts? (你能告訴我會議幾點開始嗎？)
### 動名詞 (Gerunds)
動名詞是動詞加上-ing，可以作名詞使用，常放在介系詞後或作主詞與受詞。
- Debugging code can be really challenging. (偵錯程式碼可能真的很有挑戰性。)
- I enjoy learning about new embedded systems. (我很享受學習新的嵌入式系統。)
- He's good at solving complex technical problems. (他很擅長解決複雜的技術問題。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - しごとは まいにち あります。
   - 每天都有工作。
2. **かいしゃ** / 会社 / kaisha — 公司
   - かいしゃへ いきます。
   - 去公司。
3. **べんきょう** / 勉強 / benkyou — 學習
   - わたしは にほんごを べんきょうします。
   - 我學習日文。
4. **つかう** / 使う / tsukau — 使用
   - この ツールを つかいます。
   - 使用這個工具。
5. **わかる** / 分かる / wakaru — 懂、明白
   - IoTが 少し わかります。
   - 我稍微懂一點IoT。
6. **あたらしい** / 新しい / atarashii — 新的
   - あたらしい プロジェクトです。
   - 這是新的專案。
7. **まいにち** / 毎日 / mainichi — 每天
   - まいにち コーヒーを のみます。
   - 我每天喝咖啡。
8. **どこ** / どこ / doko — 哪裡
   - あなたの かいしゃは どこですか？
   - 你的公司在哪裡？
9. **これ** / これ / kore — 這個
   - これは AI ツールです。
   - 這是AI工具。
10. **すこし** / 少し / sukoshi — 一點點
   - にほんごが 少し できます。
   - 我會一點點日文。

## 🗾 日文文法（N5）
### 名詞1 + は + 名詞2 + です
**結構**：名詞1 + は + 名詞2 + です
用來表示「名詞1是名詞2」，是最基本的肯定判斷句，常用於自我介紹或描述事物。
- わたしは エンジニアです。(我是工程師。)
- これは おもしろい です。(這個很有趣。)
### 動詞(ます形) + ましょう
**結構**：動詞(ます形) + ましょう
表示「我們一起做...吧」或「我來做...吧」，用於提出建議或表達意願。
- いっしょに べんきょうしましょう。(我們一起學習吧。)
- この プロジェクトを はじめましょう。(我們開始這個專案吧。)
