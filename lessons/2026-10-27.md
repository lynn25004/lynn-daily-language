# 2026-10-27（週二）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **optimize** (v.) — 最佳化，讓效能更好
   - *We need to optimize this code for speed.*
   - 我們需要最佳化這段程式碼以提高速度。
2. **integrate** (v.) — 整合，合併不同部分
   - *Let's integrate this new module into the system.*
   - 我們將這個新模組整合到系統中吧。
3. **troubleshoot** (v.) — 排除故障，解決問題
   - *I spent hours troubleshooting the network issue.*
   - 我花了數小時排除網路問題。
4. **prototype** (n.) — 原型，初步的模型
   - *The team built a prototype in just two days.*
   - 團隊僅用兩天就建立了一個原型。
5. **efficient** (adj.) — 有效率的，不浪費時間
   - *This new tool is super efficient!*
   - 這個新工具超級有效率！
6. **curious** (adj.) — 好奇的，想知道更多
   - *I'm curious about how IoT security works.*
   - 我很好奇 IoT 安全是如何運作的。
7. **commute** (n./v.) — 通勤，上下班路程
   - *My morning commute usually takes 30 minutes.*
   - 我早上通勤通常需要 30 分鐘。
8. **deadline** (n.) — 截止日期，完成期限
   - *We are facing a tight deadline next week.*
   - 我們下週面臨一個很緊的截止日期。
9. **innovation** (n.) — 創新，新的方法或點子
   - *Innovation drives progress in renewable energy.*
   - 創新推動了再生能源的進步。
10. **feedback** (n.) — 回饋，意見或建議
   - *We appreciate your feedback on this design.*
   - 我們很感謝您對這個設計的回饋。

## 📘 英文文法
### Used to do (過去習慣)
這個片語用來表達過去常做但現在已不再做的事情，或描述過去的狀態。
- I used to read tech blogs every morning. (我以前每天早上都會看科技部落格。)
- Did you use to play video games a lot? (你以前很常玩電動嗎？)
- He didn't use to drink coffee, but now he does. (他以前不喝咖啡，但現在會喝了。)
### Gerunds as subjects/objects (動名詞作主詞/受詞)
動詞加上-ing形式變成動名詞，可以在句中作為主詞，或作為動詞、介系詞的受詞。
- Learning new languages is fun for me. (學習新語言對我來說很有趣。)
- I enjoy tinkering with IoT devices on weekends. (我喜歡在週末把玩 IoT 裝置。)
- He's good at troubleshooting software issues. (他很擅長排除軟體問題。)

## 🇯🇵 日文單字（N5）
1. **おはようございます** / ohayou gozaimasu — 早安
   - おはようございます、いい天気ですね。
   - 早安，天氣真好呢。
2. **おつかれさま** / otsukaresama — 辛苦了
   - 今日（きょう）も一日（いちにち）おつかれさまでした。
   - 今天也辛苦一整天了。
3. **しごと** / 仕事 / shigoto — 工作
   - わたしはしごとがすきです。
   - 我喜歡工作。
4. **やすみ** / 休み / yasumi — 休息、假日
   - きょうはやすみです。
   - 今天是假日。
5. **べんきょう** / 勉強 / benkyou — 學習
   - 毎日（まいにち）日本語（にほんご）をべんきょうします。
   - 我每天學習日文。
6. **つかれる** / 疲れる / tsukareru — 累
   - しごとでおつかれました。
   - 因為工作累了。
7. **おもしろい** / 面白い / omoshiroi — 有趣的
   - この本（ほん）はとてもおもしろいです。
   - 這本書很有趣。
8. **むずかしい** / 難しい / muzukashii — 困難的
   - 日本語（にほんご）はちょっとむずかしいです。
   - 日文有點難。
9. **わかる** / 分かる / wakaru — 懂、明白
   - 日本語（にほんご）がわかりますか。
   - 你懂日文嗎？
10. **いつも** / itsumo — 總是、一直
   - わたしはいつも朝（あさ）ごはんを食（た）べます。
   - 我總會吃早餐。

## 🗾 日文文法（N5）
### 「～ます」形 (動詞現在/未來肯定)
**結構**：動詞ます形
這是動詞禮貌形的肯定說法，用來表達現在習慣做的事情或未來會做的事情。
- 毎日（まいにち）日本語（にほんご）を勉強（べんきょう）します。(我每天學習日文。)
- 明日（あした）、会社（かいしゃ）へ行（い）きます。(我明天要去公司。)
### 「～ません」形 (動詞現在/未來否定)
**結構**：動詞ません形
這是動詞禮貌形的否定說法，用來表達現在不習慣做的事情或未來不會做的事情。
- テレビをあまり見（み）ません。(我不太看電視。)
- お酒（さけ）を飲（の）みません。(我不喝酒。)
