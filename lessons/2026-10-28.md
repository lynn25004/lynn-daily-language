2. **integrate** (v.) — 整合、結合
   - *We need to integrate this new feature smoothly.*

6. **collaborate** (v.) — 合作、協作

   - *It's important to prioritize tasks effectively.*
   - 有效地排定任務優先順序很重要。

## 📘 英文文法
### 片語動詞：動詞 + up
動詞與介係詞「up」結合，形成帶有新意義的片語動詞，常用於日常對話及職場情境。
- Can you help me set up this new monitor?（你能幫我設定這台新螢幕嗎？）
- We need to come up with a solution for this bug.（我們需要想出一個解決這個錯誤的辦法。）
- Let's catch up over coffee sometime next week.（我們下週找時間喝咖啡聊聊吧。）
### 表達偏好：Would rather
表達「寧願...也不願...」的偏好時使用，後面接動詞原形，比「prefer」更口語化。
- I'd rather work from home today than go to the office.（我今天寧願在家工作也不想去辦公室。）
- Would you rather have a meeting now or later?（你寧願現在開會還是晚一點？）
- He'd rather debug the code himself than ask for help.（他寧願自己偵錯程式碼也不願尋求協助。）

## 🗾 日文文法（N5）
### 基本句型：～は～です / ～ではありません
**結構**：名詞 + は + 名詞 + です / 名詞 + は + 名詞 + ではありません
用於說明主語是什麼或不是什麼，是日文最基本的肯定與否定句型。
- わたしはエンジニアです。（我是工程師。）
- これはわたしの本ではありません。（這不是我的書。）
### 動詞 ます形：～ます / ～ません
**結構**：動詞(ます形) / 動詞(ません形)
表示現在或未來發生的動作，以及習慣性動作，是禮貌體動詞基本型態。
- 毎日、プログラミングをします。（我每天寫程式。）
- いま、ごはんを食べません。（我現在不吃飯。）
