# 2026-08-06（週四）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施計畫
   - *Let's implement this new feature soon.*
   - 我們很快就實施這個新功能吧。
2. **optimize** (v.) — 優化、最佳化系統
   - *We need to optimize this code for speed.*
   - 我們需要優化這段程式碼以提升速度。
3. **prototype** (n.) — 原型、初步模型
   - *The team finished the first IoT prototype.*
   - 團隊完成了第一個物聯網原型。
4. **debug** (v.) — 除錯、排除故障
   - *I spent all morning trying to debug this circuit.*
   - 我花了一整個早上試著為這個電路除錯。
5. **integrate** (v.) — 整合、合併系統
   - *Can we integrate AI into our product?*
   - 我們能把 AI 整合到我們的產品中嗎？
6. **briefly** (adv.) — 簡短地、扼要地
   - *Can you briefly explain the project?*
   - 你可以簡短說明一下這個專案嗎？
7. **commute** (n.) — 通勤、上下班路程
   - *My morning commute is usually quite relaxing.*
   - 我早上的通勤通常蠻輕鬆的。
8. **deadline** (n.) — 截止日期、截稿
   - *We're approaching the project deadline.*
   - 我們快要接近專案截止日期了。
9. **solution** (n.) — 解決方法、答案
   - *I found a clever solution to the problem.*
   - 我找到了個解決問題的巧妙方法。
10. **feedback** (n.) — 回饋、意見反應
   - *We welcome your feedback on this design.*
   - 我們歡迎您對這個設計提出回饋。

## 📘 英文文法
### Used to (過去習慣)
用來描述過去經常發生但現在已不再發生的習慣或狀態，例如「我以前常…」。
- I used to work late every day before. (我以前每天都工作到很晚。)
- She used to develop embedded systems. (她以前是開發嵌入式系統的。)
- Did you use to drink coffee every morning? (你以前每天早上都喝咖啡嗎？)
### Should have + Vp.p. (過去應做但未做)
表示對過去某事感到後悔、遺憾，或批評某人過去應該做但卻沒有做的事情。
- I should have checked the code more carefully. (我應該更仔細地檢查程式碼。)
- You should have backed up your files! (你當時應該備份你的檔案！)
- He shouldn't have ignored the warning. (他當時不應該忽略那個警告。)

## 🇯🇵 日文單字（N5）
1. **おそい** / 遅い / osoi — 慢的、晚的
   - 今日は仕事が遅いです。
   - 今天工作結束得比較晚。
2. **はやい** / 早い / hayai — 早的
   - 毎日、早く起きます。
   - 我每天都起得很早。
3. **でんき** / 電気 / denki — 電、電力
   - このIoTデバイスは電気を使います。
   - 這個物聯網設備需要用電。
4. **わかる** / 分かる / wakaru — 懂、明白
   - この説明が分かりますか。
   - 你明白這個說明嗎？
5. **べんきょう** / 勉強 / benkyou — 學習
   - 私は日本語を毎日勉強します。
   - 我每天都學習日語。
6. **じかん** / 時間 / jikan — 時間
   - 休憩時間は１５分です。
   - 休息時間是15分鐘。
7. **こーひー** / コーヒー / cohii — 咖啡
   - 毎朝、コーヒーを飲みます。
   - 我每天早上都喝咖啡。
8. **あたらしい** / 新しい / atarashii — 新的
   - 新しいAIツールを使ってみます。
   - 我試用看看新的AI工具。
9. **つかう** / 使う / tsukau — 使用、利用
   - このシステムはAIを使っています。
   - 這個系統正在使用AI。
10. **みる** / 見る / miru — 看
   - 私は再生可能エネルギーのニュースを見ます。
   - 我會看再生能源的新聞。

## 🗾 日文文法（N5）
### ～ませんか？ (邀請/建議)
**結構**：動詞ます形 + ませんか
用於禮貌地邀請或建議對方一起做某事，通常期待對方給予肯定或否定的回應。
- 一緒にコーヒーを飲みませんか？ (要不要一起喝咖啡？)
- 今日、早く帰りませんか？ (今天早點回家好嗎？)
### ～たいです (表達願望)
**結構**：動詞ます形 + たいです
表達說話者想要做某事的願望或意圖，是非常直接且常用的表達方式。
- 新しいAIツールを勉強したいです。 (我想要學習新的AI工具。)
- 週末にゆっくり休みたいです。 (週末我想要好好休息。)
