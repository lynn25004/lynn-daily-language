## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施
   - *We need to implement this feature soon.*
   - 我們需要快點實施這個功能。
2. **debug** (v.) — 除錯、偵錯
   - *I spent hours to debug this code.*
   - 我花了好多小時除錯這段程式碼。
3. **solution** (n.) — 解決方案
   - *This new solution is quite efficient.*

4. **device** (n.) — 裝置、設備
   - *My IoT device is working well.*

5. **optimize** (v.) — 優化、最佳化
   - *We should optimize the system for speed.*

6. **renewable** (adj.) — 可再生的
   - *Renewable energy is important for future.*
   - 再生能源對未來很重要。
7. **commute** (v./n.) — 通勤
   - *How long is your daily commute?*
   - 你每天通勤多久？
8. **leisure** (n.) — 閒暇、空閒
   - *What do you do in your leisure time?*
   - 你閒暇時都做什麼？
9. **efficient** (adj.) — 有效率的
   - *This new process is very efficient.*
   - 這個新流程非常有效率。
10. **update** (v./n.) — 更新
   - *Did you update your phone's software?*
   - 你更新手機軟體了嗎？

## 📘 英文文法
### 現在完成式 (Present Perfect Simple)
表示過去發生的動作對現在有影響，或從過去持續到現在的經驗。
- I have worked on several IoT projects. (我參與過幾個物聯網專案。)
- She has learned a lot about AI tools. (她學到了很多關於 AI 工具的知識。)
- Have you ever debugged a complex system? (你曾經除錯過複雜的系統嗎？)
### 條件句 Type 1 (First Conditional)
用來描述未來可能發生且結果也可能實現的情況，常用於計畫或預測。
- If I finish work early, I will study Japanese. (如果我早點下班，我就會去學日文。)
- If the device works, we will launch it next month. (如果這個裝置運作良好，我們下個月就會推出。)
- If you optimize the code, it will run faster. (如果你優化程式碼，它會跑得更快。)

## 🗾 日文文法（N5）
### 「名詞 + を + 動詞(ます)」 (Object Particle 「を」)
**結構**：名詞 + を + 動詞(ます)
「を」是一個助詞，用來表示動詞的直接受詞，說明動作的對象。
- パンを たべます。(吃麵包。)
- 水を のみます。(喝水。)
### 「名詞 + と + 名詞」 (And/With Particle 「と」)
**結構**：名詞 + と + 名詞
「と」是一個助詞，用於連接兩個或多個名詞，表示「和」或「與」的意思。
- コーヒーと おちゃ。(咖啡和茶。)
- ペンと ノート。(筆和筆記本。)
