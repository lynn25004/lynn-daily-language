# 2026-09-19（週六）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **deploy** (v.) — 部署；配置（將軟體或系統上線）
   - *We need to deploy this new update by Friday.*
   - 我們需要在週五前部署這個新更新。
2. **troubleshoot** (v.) — 偵錯；解決問題（找出問題並解決）
   - *I spent all morning troubleshooting a bug in the code.*
   - 我花了一整個早上在解決程式碼裡的錯誤。
3. **component** (n.) — 零件；組成部分（系統或產品的小單元）
   - *Which component is causing the system to fail?*
   - 是哪個零件導致系統故障？
4. **prototype** (n.) — 原型；樣本（產品的初期試驗模型）
   - *We're building a prototype for our new IoT device.*
   - 我們正在為我們的新 IoT 裝置打造原型機。
5. **optimize** (v.) — 優化；最佳化（改善以達到最佳效果）
   - *Can you optimize this code to run faster?*
   - 你可以優化這段程式碼讓它跑得更快嗎？
6. **feedback** (n.) — 回饋；意見（對某事物的反應或建議）
   - *We get a lot of positive feedback on our AI tool.*
   - 我們的 AI 工具收到很多正向的回饋。
7. **integrate** (v.) — 整合；結合（將不同部分結合成一個整體）
   - *We need to integrate this new module into the system.*
   - 我們需要將這個新模組整合到現有系統中。
8. **efficient** (adj.) — 效率高的；有效的（用最少資源達到目標）
   - *An efficient algorithm saves a lot of computing power.*
   - 一個高效率的演算法能節省大量運算能力。
9. **collaborate** (v.) — 合作；協作（與他人共同工作達成目標）
   - *Let's collaborate on this renewable energy project.*
   - 我們來合作這個再生能源專案吧。
10. **deadline** (n.) — 截止日期；死線（完成任務的最終日期）
   - *The deadline for the project is next Monday.*
   - 這個專案的截止日期是下週一。

## 📘 英文文法
### 情態助動詞：can / could
用來表達能力、可能性、請求或許可。Could比can更客氣或表示過去的能力，在問句中也常用。
- I can write Python code. (我會寫 Python 程式碼。)
- Could you help me troubleshoot this issue? (你可以幫我解決這個問題嗎？)
- We could try a different approach if this doesn't work. (如果這方法不行，我們可以試試別的方法。)
### 動名詞 (Gerund) 作主詞/受詞
動詞加上-ing，可以變成名詞，用作句子的主詞或受詞，表示一個行為或活動，使句子更生動。
- Learning Japanese is fun. (學習日文很有趣。)
- I enjoy developing embedded systems. (我很喜歡開發嵌入式系統。)
- Troubleshooting code can be challenging but rewarding. (偵錯程式碼可能很有挑戰性但很有收穫。)

## 🗾 日文文法（N5）
### 名詞 + は + 名詞 + です / ではありません
**結構**：名詞１ + は + 名詞２ + です / ではありません
這是日文最基礎的肯定與否定句型，用來介紹或說明事物，表示「...是...」或「...不是...」。
- 私はエンジニアです。 (我是工程師。)
- これは私のプロジェクトではありません。 (這不是我的專案。)
### 名詞 + を + 動詞(ます形)
**結構**：名詞 + を + 動詞(ます形)
「を」是受格助詞，標示動詞的作用對象，表示對名詞「做某動詞的動作」或「使用某名詞」。
- 日本語を勉強します。 (我學習日文。)
- AIツールを使います。 (我使用 AI 工具。)
