## 📘 英文文法
### 條件句 (Conditional Sentences Type 1)
用於表達未來可能發生且結果可預期的情況，結構為 If + 主詞 + 現在式動詞, 主詞 + will/can + 原形動詞。
- If you finish early, we can go grab coffee. (如果你早點完成，我們可以去喝咖啡。)
- If the code compiles, the feature will work. (如果程式碼能編譯，這個功能就會運作。)
- I will learn more if I practice English daily. (如果我每天練習英文，我會學到更多。)
### 片語動詞 (Phrasal Verbs)
動詞與介係詞或副詞結合，形成新的意義，常見的有 look forward to (期待)、set up (設定)、figure out (弄清楚) 等。
- I'm really looking forward to the new AI seminar. (我真的很期待那個新的 AI 研討會。)
- Let's set up the new IoT device this afternoon. (我們今天下午來設定那個新的 IoT 裝置吧。)
- She needs to figure out the best solution. (她需要找出最佳解決方案。)

## 🇯🇵 日文單字（N5）

## 🗾 日文文法（N5）
### 〜ます / 〜ません / 〜ました / 〜ませんでした (肯定/否定/過去肯定/過去否定)
**結構**：動詞ます形 / 動詞ません形 / 動詞ました形 / 動詞ませんでした形
用於禮貌地表達動作的肯定、否定、過去肯定和過去否定，是初學者最常用的動詞變化形式。
- 毎日日本語を勉強します。(我每天學習日文。)
- コーヒーを飲みませんでした。(我沒喝咖啡。)
### 〜たいです / 〜たくないです (想做 / 不想做)
**結構**：動詞ます形去掉ます + たいです / 動詞ます形去掉ます + たくないです
用於表達說話者希望或不希望做某事的願望，是日常生活中常用來表達意願的句型。
- 新しいIoTデバイスを作りたいです。(我想製作新的 IoT 裝置。)
- 今日はどこへも行きたくないです。(今天我哪裡都不想去。)
