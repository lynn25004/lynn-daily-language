## 📘 英文文法
### 未來式 (will / be going to)
will 用於即興決定或預測；be going to 用於已有計畫或有跡象的預測。
- I will probably go hiking this weekend. (我週末可能會去健行。)
- We are going to debug the system tomorrow. (我們明天要去除錯這個系統。)
- Look at the clouds, it's going to rain soon. (看那些雲，很快就要下雨了。)
### 現在完成式 (Present Perfect)
用於描述過去發生的動作或經驗，其影響持續到現在，或表示已完成的事件。
- I have already finished my coding project. (我已經完成我的程式專案了。)
- Have you ever explored renewable energy safety? (你曾探索過再生能源安全嗎？)
- She has learned a lot about AI tools recently. (她最近學了很多關於 AI 工具的知識。)

## 🇯🇵 日文單字（N5）
1. **しゅうまつ** / 週末 / shuumatsu — 週末
   - しゅうまつは なにを しますか。
   - 週末要做什麼呢？
2. **しゅみ** / 趣味 / shumi — 興趣
   - あなたの しゅみは なんですか。
   - 你的興趣是什麼？
3. **べんきょう** / 勉強 / benkyou — 學習
   - まいにち にほんごを べんきょうします。
   - 我每天學習日文。
4. **つくる** / 作る / tsukuru — 製作
   - あたらしい デバイスを つくりたいです。
   - 我想要製作新的裝置。
5. **あたらしい** / 新しい / atarashii — 新的
   - あたらしい テクノロジーは おもしろいです。
   - 新的科技很有趣。
6. **たのしい** / 楽しい / tanoshii — 快樂的、有趣的
   - この プロジェクトは とても たのしいです。
   - 這個專案非常有趣。
7. **じかん** / 時間 / jikan — 時間
   - しゅうまつは じかんが ありますか。
   - 週末有時間嗎？
8. **ほん** / 本 / hon — 書
   - 私は よく テクノロジーの ほんを よみます。
   - 我經常讀科技方面的書。
9. **よむ** / 読む / yomu — 讀
   - ひらがなを よむことができます。
   - 我會讀平假名。
10. **すこし** / 少し / sukoshi — 一點點
   - いま、すこし にほんごを はなします。
   - 我現在會說一點點日文。

## 🗾 日文文法（N5）
### 動詞て形 + ください
**結構**：動詞て形 + ください
用於禮貌地請求或指示對方做某事。在學習中，可用於請教或尋求幫助。
- おしえて ください。 (請教我。)
- これを よんで ください。 (請讀這個。)
### 動詞ます形 + たいです
**結構**：動詞ます形 + たいです
表達說話者想做某事的願望或意圖。動詞ます形去掉ます加上たいです。
- あたらしい テクノロジーを べんきょうしたいです。 (我想學習新的科技。)
- しゅうまつは ゲームを したいです。 (週末我想玩遊戲。)
