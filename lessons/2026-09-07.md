## 📘 英文文法
### 情態助動詞：can/could
用於表達能力、可能性或請求，could比can更委婉或表示過去的能力。
- I can speak English well. (我能說好英文。)
- Could you please help me? (你可以幫我一下嗎？)
- We could finish this by tomorrow. (我們明天可能可以完成。)
### 動名詞作主詞或受詞
動名詞（V-ing）可以作為句子的主詞或動詞、介系詞的受詞。
- Working on IoT projects is fun. (研究物聯網專案很有趣。)
- He enjoys debugging code. (他喜歡除錯程式碼。)
- I'm good at solving problems. (我擅長解決問題。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - しごとが たくさん あります。
   - 有很多工作。
2. **かいぎ** / 会議 / kaigi — 會議
   - きょう、かいぎが あります。
   - 今天有會議。
3. **じかん** / 時間 / jikan — 時間
   - じかんが ありません。
   - 沒有時間。
4. **まいにち** / 毎日 / mainichi — 每天
   - まいにち にほんごを べんきょうします。
   - 我每天學習日文。
5. **つかう** / 使う / tsukau — 使用
   - この パソコンを つかいます。
   - 我使用這台電腦。
6. **むずかしい** / 難しい / muzukashii — 困難的
   - この もんだいは むずかしいです。
   - 這個問題很困難。
7. **たのしい** / 楽しい / tanoshii — 快樂的，有趣的
   - しごとは たのしいです。
   - 工作很有趣。
8. **べんきょう** / 勉強 / benkyou — 學習，讀書
   - にほんごの べんきょうを します。
   - 我會學習日文。
9. **あたらしい** / 新しい / atarashii — 新的
   - あたらしい アイデアが あります。
   - 我有一個新的想法。
10. **もんだい** / 問題 / mondai — 問題
   - もんだいを かいけつします。
   - 我會解決問題。

## 🗾 日文文法（N5）
### 動詞-ます形 + たいです (想做某事)
**結構**：動詞ます形 + たいです
表達自己的願望或希望做某事，是一種日常且常用於表達意圖的句型。
- コーヒーを のみたいです。 (我想喝咖啡。)
- にほんごを べんきょうしたいです。 (我想學習日文。)
### 名詞 + を + 動詞 (直接受詞)
**結構**：名詞 + を + 動詞
助詞「を」放在動詞的直接受詞之後，表示該名詞是動詞作用的對象。
- パンを たべます。 (我吃麵包。)
- メールを かきます。 (我寫郵件。)
