# 2026-10-14（週三）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施計畫或系統
   - *We need to implement the new security patch ASAP.*
   - 我們需要盡快實施新的安全補丁。
2. **optimize** (v.) — 優化、最佳化以提高效能
   - *Can you optimize this code for better performance?*
   - 你能優化這段程式碼以提高效能嗎？
3. **troubleshoot** (v.) — 排除故障、解決問題
   - *My Wi-Fi is down; I need to troubleshoot it.*
   - 我的 Wi-Fi 斷線了，我需要排除故障。
4. **prototype** (n.) — 原型、樣本產品
   - *The team finished the first prototype of our new IoT device.*
   - 團隊完成了我們新物聯網裝置的第一個原型。
5. **efficiency** (n.) — 效率、效能
   - *We're always trying to improve our energy efficiency.*
   - 我們一直在努力提高能源效率。
6. **collaborate** (v.) — 合作、協作完成專案
   - *Let's collaborate on this project to finish faster.*
   - 我們來合作這個專案，更快完成吧。
7. **deadline** (n.) — 截止日期
   - *I'm swamped with work, got a tight deadline next week.*
   - 我工作量很大，下週有個很緊的截止日期。
8. **innovative** (adj.) — 創新的、革新的想法
   - *That's an innovative solution for renewable energy storage.*
   - 那是再生能源儲存的創新解決方案。
9. **feedback** (n.) — 回饋、意見
   - *Please give me some feedback on my presentation.*
   - 請給我一些關於我的簡報的回饋意見。
10. **monitor** (v.) — 監控、監視系統或數據
   - *We use sensors to monitor the system's temperature.*
   - 我們使用感測器來監控系統的溫度。

## 📘 英文文法
### 未來簡單式 (will / be going to)
用於表達未來計畫、預測或當下決定。will 較口語，be going to 常用於預定計畫。
- I will start learning Python next month. (我下個月會開始學 Python。)
- We are going to deploy the update tomorrow morning. (我們明天早上要部署更新。)
- It looks like it's going to rain, so bring an umbrella. (看起來要下雨了，所以帶把傘吧。)
### 條件句 Type 1 (If + 現在簡單式, will + 原形動詞)
描述未來可能發生或真實情況的假設。如果條件成立，結果就會發生。
- If the system crashes, we will lose all unsaved data. (如果系統當機，我們會失去所有未儲存的資料。)
- If you finish your tasks early, you can leave. (如果你提早完成任務，就可以離開。)
- I will call you if I need any help with the coding. (如果我在寫程式時需要任何幫助，我會打給你。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - 仕事は楽しいですか？
   - 工作開心嗎？
2. **かいしゃ** / 会社 / kaisha — 公司
   - 私の会社は台北にあります。
   - 我的公司在台北。
3. **べんきょう** / 勉強 / benkyou — 學習
   - 毎日日本語を勉強します。
   - 我每天學習日文。
4. **ぱそこん** / パソコン / pasokon — 電腦
   - 新しいパソコンが欲しいです。
   - 我想要一台新電腦。
5. **でんき** / 電気 / denki — 電、電力
   - この電気製品は日本製です。
   - 這個電器是日本製的。
6. **つくる** / 作る / tsukuru — 製作、製造
   - IoTデバイスを作りたいです。
   - 我想製作 IoT 裝置。
7. **つかう** / 使う / tsukau — 使用
   - このAIツールは使いやすいです。
   - 這個 AI 工具很好用。
8. **いそがしい** / 忙しい / isogashii — 忙碌的
   - 最近、仕事がとても忙しいです。
   - 最近工作很忙碌。
9. **おもしろい** / 面白い / omoshiroi — 有趣的
   - このゲームは面白いですね。
   - 這個遊戲很有趣呢。
10. **じかん** / 時間 / jikan — 時間
   - 日本語の勉強に時間がかかります。
   - 學日文需要時間。

## 🗾 日文文法（N5）
### 動詞ます形 (肯定/否定/過去式)
**結構**：動詞(ます形)
用於表達禮貌的動詞現在肯定、否定與過去肯定、否定，是日語基本句型。
- 毎日コーヒーを飲みます。(我每天喝咖啡。)
- 昨日、会社へ行きませんでした。(我昨天沒去公司。)
### 名詞 + は + 名詞 + です / ではありません
**結構**：名詞１ + は + 名詞２ + です / ではありません
用於介紹事物、說明身份或描述狀態。表示「...是...」或「...不是...」。
- これは私のパソコンです。(這是我的電腦。)
- 田中さんはエンジニアではありません。(田中先生不是工程師。)
