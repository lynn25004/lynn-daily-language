# 2026-11-12（週四）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **optimize** (v.) — 優化，最佳化處理
   - *We need to optimize this code for better performance.*
   - 我們需要優化這段程式碼以提升效能。
2. **integrate** (v.) — 整合，結合多個部分
   - *It's tricky to integrate all these smart home devices.*
   - 把這些智慧家庭裝置都整合起來很棘手。
3. **deploy** (v.) — 部署，配置系統
   - *Finally, we can deploy the new system next week!*
   - 終於，我們下週可以部署新系統了！
4. **prototype** (n.) — 原型，初步模型
   - *The team is building a new prototype for the IoT device.*
   - 團隊正在為這款物聯網設備製作新原型。
5. **efficiency** (n.) — 效率，效能表現
   - *Improving energy efficiency is key for renewable tech.*
   - 提升能源效率對再生能源技術至關重要。
6. **collaborate** (v.) — 合作，協同工作
   - *Engineers often collaborate on complex projects.*
   - 工程師們常在複雜專案上互相協作。
7. **commute** (n./v.) — 通勤，上下班路程
   - *My commute to work usually takes about 30 minutes.*
   - 我通勤上班通常大約要花 30 分鐘。
8. **deadline** (n.) — 截止日期，最後期限
   - *We're trying to hit the deadline for the project launch.*
   - 我們正努力趕上專案發布的截止日期。
9. **feedback** (n.) — 回饋，意見反應
   - *Always good to get feedback on our product features.*
   - 能收到產品功能的回饋總是好事。
10. **innovative** (adj.) — 創新的，有革新意的
   - *They came up with a truly innovative solution for the problem.*
   - 他們為這個問題想出了一個真正創新的解決方案。

## 📘 英文文法
### 動名詞 (Gerunds) 作為主詞或受詞
動名詞 (-ing 形式) 可以像名詞一樣，在句子中擔任主詞或受詞，表達一個動作或活動。
- Developing new AI tools is exciting for engineers.（開發新的 AI 工具對工程師來說很令人興奮。）
- I enjoy learning about renewable energy safety.（我很喜歡學習再生能源安全。）
- Finishing this project on time is our top priority.（準時完成這個專案是我們的首要任務。）
### 情態動詞 (Modal Verbs) "Should" 和 "Could"
"Should" 表示建議或義務，而 "Could" 表示可能性或能力（過去式或更客氣的用法）。
- You should probably check the system logs first.（你應該先檢查一下系統日誌。）
- We could try a different approach to solve this bug.（我們可以嘗試不同的方法來解決這個錯誤。）
- Maybe I should start practicing more for the TOEIC test.（也許我應該多練習一下多益考試。）

## 🇯🇵 日文單字（N5）

   - わたしの しごとは エンジニアです。
   - 我的工作是工程師。

   - まいにち にほんごを べんきょうします。
   - 我每天學習日文。
3. **しゅみ** / 趣味 / shumi — 興趣
   - わたしの しゅみは IoT です。
   - 我的興趣是 IoT。
4. **じかん** / 時間 / jikan — 時間

## 🗾 日文文法（N5）
### 名詞 + は + 名詞 + です
**結構**：名詞 + は + 名詞 + です
用來介紹或說明 N1 是什麼，表示 N1 等於 N2。は是提示助詞，讀作 "wa"。
- わたしは たいわんじんです。（我是台灣人。）
- これは わたしの パソコンです。（這是我的電腦。）
### 動詞(ます形) + ましょうか
**結構**：動詞(ます形) + ましょうか
用來主動提議為對方做某事，或者徵求對方意見，語氣客氣且帶有詢問。
- てつだいましょうか。（需要我幫忙嗎？/ 我來幫忙吧？）
- いっしょに べんきょうしましょうか。（我們一起學習吧？）
