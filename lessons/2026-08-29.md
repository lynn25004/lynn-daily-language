## 🇬🇧 英文單字（TOEIC 600-800）
1. **debug** (v.) — 找出並修正程式錯誤
   - *I spent hours trying to debug this code.*
   - 我花了好幾個小時試著除錯這段程式碼。
2. **prototype** (n.) — 初步模型或樣品
   - *We built a small prototype for our IoT device.*
   - 我們為我們的物聯網裝置做了一個小型原型。
3. **algorithm** (n.) — 解決問題的步驟
   - *This algorithm helps sort data really fast.*
   - 這個演算法能幫助資料快速排序。
4. **optimize** (v.) — 改進效能或效率
   - *I need to optimize this circuit for better power usage.*
   - 我需要優化這個電路以改善電力使用。
5. **component** (n.) — 組成部分或零件
   - *Which component caused the system to fail?*
   - 是哪個零件導致系統故障的？
6. **fascinated** (adj.) — 對某事極為著迷
   - *I'm totally fascinated by renewable energy tech.*
   - 我完全被再生能源技術給迷住了。
7. **tinker** (v.) — 隨意修補或摸索
   - *I love to tinker with old gadgets on weekends.*
   - 我喜歡在週末修修補補舊小玩意兒。
8. **innovative** (adj.) — 具有創新精神的
   - *That's a very innovative approach to the problem.*
   - 那是解決這個問題的一個非常創新的方法。
9. **setup** (n.) — 裝置或系統的設置
   - *My new home lab setup is finally complete!*
   - 我的新家庭實驗室設置終於完成了！
10. **challenge** (n.) — 困難的任務或考驗
   - *Learning a new language can be a fun challenge.*
   - 學習一門新語言會是個有趣的挑戰。

## 📘 英文文法
### Used to do / Be used to doing
「used to do」指過去的習慣或狀態，現在已不同；「be used to doing」指習慣於某事，強調現在的適應。
- I used to write code in C++, but now I prefer Python. (我以前習慣用 C++ 寫程式，但現在我比較喜歡 Python。)
- It was hard at first, but I'm used to debugging complex systems now. (一開始很難，但我現在已經習慣除錯複雜的系統了。)
- Are you used to working from home yet? (你已經習慣在家工作了嗎？)
### Conditional Sentences (Type 1)
表達未來可能發生的真實情況，句型為「If + S + V (現在簡單式), S + will + V (原形動詞)」。
- If I finish my project early, I will go hiking this weekend. (如果我提早完成專案，我這個週末會去爬山。)
- If you optimize the code, the system will run much faster. (如果你優化程式碼，系統會跑得快很多。)
- If we use AI tools, we will save a lot of development time. (如果我們使用 AI 工具，我們會省下很多開發時間。)

## 🗾 日文文法（N5）
### ~ます / ~ません
**結構**：動詞ます形 / 動詞ません形
「ます」表示肯定現在或未來的動作；「ません」表示否定現在或未來的動作，是禮貌的說法。
- 毎日、コーヒーを飲みます。(我每天喝咖啡。)
- 今日は仕事をしません。(我今天不工作。)
### ~たいです
**結構**：動詞ます形 + たいです
表示說話者「想要做某事」的願望或意圖，動詞「ます形」去「ます」加上「たいです」。
- 新しいAI技術を勉強したいです。(我想要學習新的AI技術。)
- 週末はゆっくり休みたいです。(週末我想要好好休息。)
