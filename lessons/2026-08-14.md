# 2026-08-14（週五）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **integrate** (v.) — 整合，使結合
   - *We need to integrate this new module into our system smoothly.*
   - 我們需要把這個新模組順利整合到系統中。
2. **feature** (n.) — 主要特色，功能
   - *This new smartphone has many cool features, like AI camera.*
   - 這款新手機有很多很酷的功能，像是 AI 相機。
3. **optimize** (v.) — 優化，最佳化
   - *Let's optimize the code to make it run faster.*
   - 我們來優化程式碼，讓它跑更快。
4. **robust** (adj.) — 堅固的，穩定的
   - *This embedded system needs to be robust for outdoor use.*
   - 這個嵌入式系統必須很堅固，才能用於戶外。
5. **debug** (v.) — 除錯，找出問題
   - *I spent all morning trying to debug this tricky issue.*
   - 我整個早上都在努力為這個棘手的問題除錯。
6. **deadline** (n.) — 完成的截止日期
   - *The deadline for this project is next Friday.*
   - 這個專案的截止日期是下週五。
7. **prototype** (n.) — 產品原型，樣本
   - *We finished the first prototype of our IoT device yesterday.*
   - 我們昨天完成了我們 IoT 裝置的第一個原型。
8. **efficient** (adj.) — 效率高的，有效的
   - *Using AI tools can make our workflow more efficient.*
   - 使用 AI 工具可以讓我們的工作流程更有效率。
9. **feedback** (n.) — 寶貴的回饋意見
   - *Please give us your feedback on the new design.*
   - 請對新設計提供您的回饋意見。
10. **innovate** (v.) — 創造新事物，革新
   - *Our team always tries to innovate and find new solutions.*
   - 我們團隊總是努力創新並找到新解決方案。

## 📘 英文文法
### Conditional Sentences (Type 1)
表達未來可能發生的狀況及其結果，句型為「If + 現在式, will + 原形動詞」。
- If the system works, we will launch it next month. (如果系統運作正常，我們下個月就會推出。)
- If you have any questions, please ask me anytime. (如果你有任何問題，隨時都可以問我。)
- If we optimize the code, the app will run much faster. (如果我們優化程式碼，應用程式會跑快很多。)
### Passive Voice (被動語態)
主詞是動作的承受者時使用，強調動作而非執行者，句型為「S + be動詞 + 過去分詞」。
- The new feature was released last week. (新功能上週發布了。)
- This project is led by a senior engineer. (這個專案由一位資深工程師領導。)
- Renewable energy solutions are being developed globally. (再生能源解決方案正在全球各地開發中。)

## 🗾 日文文法（N5）
### 動詞て形 + ください
**結構**：動詞て形 + ください
向對方提出請求、指示或建議，語氣禮貌實用，日常或職場都常用。
- このファイルを読んでください。 (請讀這個檔案。)
- 電源を入れてください。 (請打開電源。)
### 〜が あります / います
**結構**：名詞 + が あります (非生物) / います (生物)
表示某處有某物或某人存在。非生物用「あります」，生物用「います」。
- 会議室にパソコンがあります。 (會議室裡有電腦。)
- わたしのチームに日本人エンジニアがいます。 (我的團隊裡有日本工程師。)
