# 2026-09-04（週五）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施計畫或功能
   - *We need to implement this new feature quickly.*
   - 我們需要快速實施這項新功能。
2. **optimize** (v.) — 優化、使某物達到最佳狀態
   - *Let's optimize the code for better performance.*
   - 我們來優化程式碼以獲得更好的性能吧。
3. **troubleshoot** (v.) — 排除故障、解決問題
   - *Can you help me troubleshoot this network issue?*
   - 你能幫我解決這個網路問題嗎？
4. **prototype** (n.) — 原型、初步模型
   - *The team is building a new prototype for testing.*
   - 團隊正在建立一個新的原型進行測試。
5. **integration** (n.) — 整合、結合不同部分
   - *System integration can be tricky sometimes.*
   - 系統整合有時可能很棘手。
6. **renewable** (adj.) — 可再生的、能自然補充的
   - *Solar power is a great renewable energy source.*
   - 太陽能是很棒的再生能源來源。
7. **algorithm** (n.) — 演算法、解決問題的步驟
   - *This algorithm helps process data really fast.*
   - 這個演算法能幫助資料處理得很快。
8. **debug** (v.) — 除錯、修正程式錯誤
   - *It took hours to debug that tiny error!*
   - 花了好多小時才把那個小錯誤除掉！
9. **feedback** (n.) — 回饋意見、對成果的反應
   - *We appreciate your feedback on the new design.*
   - 我們很感謝您對新設計的回饋意見。
10. **collaboration** (n.) — 合作、共同努力完成任務
   - *Team collaboration is key to our success.*
   - 團隊合作是我們成功的關鍵。

## 📘 英文文法
### 現在完成式 (Present Perfect)
描述過去發生但影響持續到現在，或在不特定時間點發生的動作或經驗。
- I've worked on this project for three months.（我已經在這個專案上工作三個月了。）
- Have you ever tried to debug a tricky IoT system?（你曾經試過排除棘手的物聯網系統故障嗎？）
- We haven't finished the prototype yet, but it's close!（我們還沒完成原型，但快了！）
### 被動語態 (Passive Voice)
當動作的執行者不重要、不清楚，或想強調動作的承受者時使用，構成為「be動詞 + 過去分詞」。
- The new feature was implemented last week.（新功能已於上週實施。）
- Our system is optimized for low power consumption.（我們的系統已優化以降低功耗。）
- Many AI tools are being developed to assist engineers.（許多AI工具正在被開發來協助工程師。）

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - 今日のしごとは大変ですか？
   - 今天的工作很辛苦嗎？
2. **べんきょう** / 勉強 / benkyou — 學習
   - 毎日、日本語をべんきょうしています。
   - 我每天都在學習日文。
3. **でんき** / 電気 / denki — 電、電力
   - このきかいはでんきで動きます。
   - 這台機器是用電力運作的。
4. **つくる** / 作る / tsukuru — 製作、創造
   - あたらしいシステムをいま、つくっています。
   - 我正在製作一個新系統。
5. **つかう** / 使う / tsukau — 使用
   - このAIツールをつかってみませんか？
   - 要不要試用這個AI工具？
6. **かいしゃ** / 会社 / kaisha — 公司
   - 私の会社はIoTせいひんを作っています。
   - 我的公司在製作IoT產品。
7. **むずかしい** / 難しい / muzukashii — 困難的、難的
   - このもんだいは少しむずかしいです。
   - 這個問題有點難。
8. **わかる** / 分かる / wakaru — 懂、明白
   - 日本語が少しわかります。
   - 我懂一點日文。

10. **まいにち** / 毎日 / mainichi — 每天
   - まいにち、コーヒーを飲みます。
   - 我每天都喝咖啡。

## 🗾 日文文法（N5）
### 「〜ます」否定形「〜ません」
**結構**：動詞(ます形) + ません
用於表示現在或將來的否定，或者請求對方不要進行某項動作。是日文動詞基本否定形式。
- 私はまだ日本語がはなせません。（我還不能說日文。）
- 今日のしごとはおわりません。（今天的工作還沒結束。）
### 「〜があります/います」 (存在句)
**結構**：場所 + に + 名詞 + が + あります/います
「あります」用於非生物，「います」用於生物，表示某物或某人存在於某地點。
- つくえの上に本があります。（桌子上有書。）
- 会議室にエンジニアがいます。（會議室裡有工程師。）
