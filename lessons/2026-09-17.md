# 2026-09-17（週四）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施
   - *We need to implement this new feature by next month.*
   - 我們需要在下個月前實施這個新功能。
2. **optimize** (v.) — 優化、最佳化
   - *Can you optimize the code for better performance?*
   - 你能優化程式碼以提升效能嗎？
3. **prototype** (n.) — 原型、初型
   - *The team is working on a prototype for the new IoT device.*
   - 團隊正在為新的物聯網設備製作原型。
4. **scenario** (n.) — 情境、情況
   - *Let's consider a few different scenarios for this project.*
   - 讓我們考慮一下這個專案的幾種不同情境。
5. **troubleshoot** (v.) — 故障排除
   - *I need to troubleshoot why the system crashed again.*
   - 我需要找出系統再次崩潰的原因。
6. **efficient** (adj.) — 有效率的
   - *Working efficiently helps us finish tasks faster.*
   - 高效率地工作能讓我們更快完成任務。
7. **commute** (n./v.) — 通勤
   - *My morning commute usually takes about 30 minutes.*
   - 我早上的通勤通常需要大約三十分鐘。
8. **sustainable** (adj.) — 永續的
   - *Renewable energy is a key part of a sustainable future.*
   - 再生能源是永續未來的重要一環。
9. **integrate** (v.) — 整合
   - *We need to integrate this module with the main system.*
   - 我們需要將這個模組與主系統整合。
10. **prioritize** (v.) — 優先處理
   - *I need to prioritize my tasks for the day.*
   - 我需要為今天的工作設定優先順序。

## 📘 英文文法
### 條件句 Type 1 (If... will...)
用於談論真實或非常可能在未來發生的事件和結果。
- If it rains tomorrow, we will stay home. (如果明天會下雨，我們就待在家。)
- If you finish your work early, we can go out. (如果你早點完成工作，我們就可以出去。)
- If the system works, the client will be happy. (如果系統能運作，客戶就會很高興。)
### 常用片語動詞
常見片語動詞的使用，讓口語表達更自然流暢。
- Can you help me set up this new device? (你能幫我設定這個新設備嗎？)
- I need to figure out how to solve this problem. (我需要弄清楚如何解決這個問題。)
- Let's catch up later for a coffee break. (我們晚點喝咖啡休息時聊聊吧。)

## 🗾 日文文法（N5）
### 動詞「ます形」的肯定與否定 (現在/過去)
**結構**：動詞(ます形)
用於表示動詞的現在肯定/否定，以及過去肯定/否定。可表達習慣、事實或計畫。
- 毎日コーヒーを飲みます。(我每天喝咖啡。)
- 昨日、日本語を勉強しました。(昨天我學習了日語。)
### 名詞的肯定與否定句
**結構**：名詞１ + は + 名詞２ + です / ではありません
用於說明或介紹某事物。動詞「です」表示肯定，「ではありません」表示否定。
- これは私のパソコンです。(這是我的電腦。)
- 彼はエンジニアではありません。(他不是工程師。)
