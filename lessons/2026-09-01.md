# 2026-09-01（週二）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **commute** (v./n.) — 上下班通勤
   - *My commute to work usually takes about 30 minutes.*
   - 我上班通勤通常需要大約 30 分鐘。
2. **deadline** (n.) — 工作截止日期
   - *We have a strict deadline for this project next week.*
   - 我們這個專案下週有很緊的截止日期。
3. **troubleshoot** (v.) — 解決系統問題
   - *I spent all morning trying to troubleshoot this software bug.*
   - 我花了一整個早上試著解決這個軟體錯誤。
4. **prototype** (n.) — 產品初始原型
   - *We are testing the new prototype for our smart home device.*
   - 我們正在測試我們智慧家庭裝置的新原型。
5. **optimize** (v.) — 使系統最佳化
   - *Our goal is to optimize the code for better performance.*
   - 我們的目標是優化程式碼以獲得更好的效能。
6. **renewable** (adj.) — 可再生的能源
   - *More companies are investing in renewable energy sources now.*
   - 現在有更多公司投資於再生能源。
7. **efficient** (adj.) — 有效率的
   - *Working from home can be very efficient for some tasks.*
   - 在家工作對於某些任務來說可以非常有效率。
8. **collaborate** (v.) — 共同合作
   - *Let's collaborate on this presentation to make it awesome.*
   - 我們來合作製作這個簡報，讓它更棒。
9. **feedback** (n.) — 意見回饋
   - *Your feedback on the new design is super helpful.*
   - 你對於新設計的意見回饋非常有幫助。
10. **update** (v./n.) — 更新資訊或軟體
   - *Did you get the latest software update for your phone?*
   - 你的手機有收到最新的軟體更新嗎？

## 📘 英文文法
### 條件句 (If 句型 - 第一類)
用來表達未來可能發生且結果可能實現的情況，常用於計畫或預測。
- If I finish this report early, I will go for a run。（如果我早點完成這份報告，我就會去跑步。）
- If the server is down, we'll need to troubleshoot it immediately。（如果伺服器當機，我們需要立即排除故障。）
- If you optimize the code, the app will run much faster。（如果你優化程式碼，應用程式會跑快很多。）
### 動詞片語：動詞 + up
許多動詞搭配 'up' 會形成特定意義的片語，常用於描述行動或狀態的變化。
- Can you set up the new IoT device for me?（你可以幫我設定那個新的 IoT 裝置嗎？）
- I need to look up some documentation for this embedded system.（我需要查閱一些關於這個嵌入式系統的文件。）
- Let's speed up the development process to meet the deadline.（我們來加速開發流程以趕上截止日期。）

## 🇯🇵 日文單字（N5）
1. **おはようございます** / ohayou gozaimasu — 早上好（禮貌）
   - 朝（あさ）、会社（かいしゃ）で「おはようございます」と言（い）います。
   - 早上在公司會說「早上好」。
2. **おつかれさまです** / otsukaresama desu — 您辛苦了（職場常用）
   - 長（なが）い会議（かいぎ）の後（あと）、「おつかれさまです」と言（い）います。
   - 開完冗長的會議後，會說「您辛苦了」。
3. **しごと** / 仕事 / shigoto — 工作、職務
   - 私（わたし）の仕事（しごと）はエンジニアです。
   - 我的工作是工程師。
4. **きゅうけい** / 休憩 / kyuukei — 休息、小憩
   - １時間（いちじかん）仕事（しごと）をして、少（すこ）し休憩（きゅうけい）します。
   - 工作一小時後，稍微休息一下。
5. **かいぎ** / 会議 / kaigi — 會議
   - 今日（きょう）は午前（ごぜん）に会議（かいぎ）があります。
   - 今天上午有會議。
6. **パソコン** / pasokon — 個人電腦
   - 私（わたし）は毎日（まいにち）パソコンを使（つか）います。
   - 我每天都使用電腦。
7. **でんき** / 電気 / denki — 電、電力
   - 部屋（へや）の電気（でんき）を消（け）します。
   - 關掉房間的電燈。
8. **もんだい** / 問題 / mondai — 問題、疑問
   - このシステムに問題（もんだい）があります。
   - 這個系統有問題。
9. **わかる** / わかる / wakaru — 懂、明白
   - この日本語（にほんご）がわかりますか？
   - 你懂這個日文嗎？
10. **がんばります** / がんばります / ganbarimasu — 我會努力的
   - JLPT N5（エヌご）のため、毎日（まいにち）がんばります！
   - 為了日檢 N5，我每天都會努力！

## 🗾 日文文法（N5）
### 動詞て形 + ください
**結構**：動詞て形 + ください
用來禮貌地請求或指示對方做某事，是很實用的日常表達。
- ちょっと待（ま）ってください。（請等一下。）
- 資料（しりょう）を読（よ）んでください。（請閱讀資料。）
### 名詞 + が あります / います
**結構**：名詞 + が あります / います
表示某物（あります）或某人/動物（います）的存在，用於描述環境或狀況。
- 会議室（かいぎしつ）にホワイトボードがあります。（會議室裡有白板。）
- 会社（かいしゃ）に新（あたら）しいエンジニアがいます。（公司裡有新工程師。）
