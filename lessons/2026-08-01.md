## 📘 英文文法
### 條件句 Type 1 (If + present simple, will + base verb)
表達未來可能發生的狀況，如果條件達成，某結果會發生。
- If the smart light turns on, I will know someone is home. (如果智慧燈亮了，我就知道有人在家。)
- If you update the firmware, the device will work better. (如果你更新韌體，裝置會運作更好。)
- If I have time this weekend, I'll build an IoT pet feeder. (如果我這週末有空，我會做一個 IoT 寵物餵食器。)
### Used to (過去習慣)
用來描述過去經常發生但現在已不再發生的動作或習慣。
- I used to manually switch off lights before smart home. (在智慧家庭之前，我以前習慣手動關燈。)
- Engineers used to write code on paper, imagine that! (工程師以前習慣在紙上寫程式，你能想像嗎！)
- My old laptop used to overheat a lot during coding. (我舊筆電以前寫程式時很常過熱。)

## 🗾 日文文法（N5）
### 〜ます / 〜ません (肯定/否定)
**結構**：動詞ます形 / 動詞ません形
動詞ます形表示禮貌的肯定動作；動詞ません形表示禮貌的否定動作。
- 毎日、日本語を勉強します。 (我每天學習日文。)
- 週末は仕事をしません。 (週末我不工作。)
### 名詞 + は + 名詞 + です / じゃありません
**結構**：名詞1 + は + 名詞2 + です / じゃありません
用來介紹或說明某物是什麼或不是什麼，は是主題標示助詞。
- これは私の新しい部屋です。 (這是我的新房間。)
- IoTは面白い技術です。 (IoT 是有趣的技術。)
