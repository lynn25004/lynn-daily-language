## 📘 英文文法
### Present Perfect (現在完成式)
用來描述從過去開始持續到現在的動作或經驗，或已完成但影響持續到現在的事件。
- I have worked on several IoT projects. (我曾參與過幾個物聯網專案。)
- She hasn't finished debugging the code yet. (她還沒調試完程式碼。)
- Have you ever presented at a tech conference? (你曾經在科技研討會上發表過嗎？)
### Conditional Sentences Type 1 (條件句型一)
用於談論未來可能發生且結果真實的可能性，結構是 If + 現在簡單式, will + 動詞原形。
- If the system works, we will launch it next month. (如果系統運作正常，我們下個月就會推出。)
- If you debug carefully, you will find the error quickly. (如果你仔細調試，你會很快找到錯誤。)
- I will go for a run if the weather is good tomorrow. (如果明天天氣好，我就去跑步。)

## 🇯🇵 日文單字（N5）

   - 今日は仕事が忙しいです。
   - 今天工作很忙。
2. **しごと** / 仕事 / shigoto — 工作
   - 私の仕事はエンジニアです。

   - 私の会社は台北にあります。

## 🗾 日文文法（N5）
### 名詞 + は + 名詞 + です
**結構**：名詞 + は + 名詞 + です
用於肯定句，表示「A是B」。は為提示助詞，發音為 wa，而非 ha。
- 私はエンジニアです。(我是工程師。)
- これは私のパソコンです。(這是我的電腦。)
### 動詞(ます形) + ましょう
**結構**：動詞(ます形) + ましょう
表示「我們一起...吧」或「做...吧」，用於提出建議或邀請對方共同進行某事。
- 明日、一緒に昼ごはんを食べましょう。(明天我們一起吃午餐吧。)
- 週末、新しいプロジェクトについて話しましょう。(週末我們聊聊新專案吧。)
