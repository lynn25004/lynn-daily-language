## 📘 英文文法
### 條件句型 Type 1 (If + 現在簡單式, will + 原形動詞)
用於描述未來可能發生且結果明確的事情，表達計畫、預測或因果關係。
- If I finish coding early, I will go for a run. (如果我提早寫完程式，我就會去跑步。)
- If the sensor works, we'll collect data. (如果感測器能運作，我們就會收集數據。)
- If you have questions, just ask me. (如果你有問題，直接問我就好。)
### 片語動詞 with 'up' (例如：set up, back up)
「動詞 + up」組合常表示向上、完成、建立或增加，理解其語境很重要。
- I need to set up my new development environment. (我需要設定我的新開發環境。)
- Did you back up all your important files? (你備份了所有重要的檔案了嗎？)
- Let's pick up some coffee on the way. (我們路上買點咖啡吧。)

## 🇯🇵 日文單字（N5）
1. **おはよう** / おはよう / ohayou — 早安
   - おはようございます！今日も一日頑張りましょう。
   - 早安！今天一天也一起努力吧。
2. **しごと** / 仕事 / shigoto — 工作
   - 仕事は面白いですが、時々大変です。
   - 工作很有趣，但有時候很辛苦。
3. **くるま** / 車 / kuruma — 汽車、車子
   - 私の車は新しいIoTデバイスでいっぱいです。
   - 我的車子裝滿了新的物聯網設備。
4. **でんしゃ** / 電車 / densha — 電車
   - 毎日、電車で会社に行きます。
   - 我每天搭電車去公司。
5. **まいにち** / 毎日 / mainichi — 每天
   - 毎日、日本語を勉強しています。
   - 我每天都在學習日文。
6. **たかい** / 高い / takai — 高的、貴的
   - あのスマートデバイスは少し高いですね。
   - 那個智慧設備有點貴呢。
7. **やすい** / 安い / yasui — 便宜的、簡單的
   - このAIツールは安くて使いやすいです。
   - 這個AI工具又便宜又好用。
8. **つかう** / 使う / tsukau — 使用
   - このソフトは初めて使うので、教えてください。
   - 這是第一次使用這個軟體，請教我一下。
9. **わかる** / 分かる / wakaru — 懂、明白
   - 日本語の文法が少しずつ分かります。
   - 我漸漸懂日文文法了。
10. **おそい** / 遅い / osoi — 慢的、遲的
   - 今日の電車はいつもより少し遅いです。
   - 今天的電車比平常稍微慢一點。

## 🗾 日文文法（N5）
### 名詞 + は + 名詞 + です / ではありません
**結構**：名詞１ + は + 名詞２ + です / ではありません
用於說明主語是什麼或不是什麼，是日語中最基礎的判斷句型。
- 私はエンジニアです。(我是工程師。)
- これは私のプロジェクトではありません。(這不是我的專案。)
### 動詞(ます形) + ましょうか
**結構**：動詞(ます形) + ましょうか
用於主動提出提供幫助，或禮貌地建議一起做某件事。
- 手伝いましょうか。(需要我幫忙嗎？)
- 一緒に新しいAIツールを試しましょうか。(我們一起試試新的AI工具吧？)
