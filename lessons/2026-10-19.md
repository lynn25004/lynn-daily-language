# 2026-10-19（週一）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 實施、執行計畫
   - *We need to implement this new feature by next week, engineer.*
   - 工程師，我們下週前需要實施這個新功能。
2. **optimize** (v.) — 優化、使最佳化
   - *Can we optimize the code to make it run faster and smoother?*
   - 我們可以優化程式碼讓它跑得更快更順暢嗎？
3. **troubleshoot** (v.) — 排除故障、檢修
   - *I spent an hour trying to troubleshoot that network issue this morning.*
   - 我今天早上花了一小時試圖排除那個網路問題。
4. **integrate** (v.) — 整合、使結合
   - *This new module needs to integrate seamlessly with our existing system.*
   - 這個新模組需要與我們現有系統無縫整合。
5. **feedback** (n.) — 回饋、意見
   - *Could you give me some honest feedback on my presentation slides?*
   - 你可以給我一些關於我簡報投影片的誠實回饋嗎？
6. **schedule** (n./v.) — 行程、排定時間
   - *What's your schedule looking like for tomorrow's team meeting?*
   - 你明天團隊會議的行程如何安排？
7. **commute** (n./v.) — 通勤時間或路程
   - *My commute to work usually takes about thirty minutes by scooter.*
   - 我通勤上班通常騎機車大約需要三十分鐘。
8. **collaborate** (v.) — 合作、共同工作
   - *We often collaborate with the design team on new product ideas.*
   - 我們經常與設計團隊合作開發新產品概念。
9. **innovative** (adj.) — 創新的、革新的
   - *Your idea for the IoT device sounds really innovative and exciting!*
   - 你關於物聯網設備的想法聽起來非常有創新性且令人興奮！
10. **prioritize** (v.) — 優先處理、排列優先順序
   - *I need to prioritize my tasks for today to hit the deadline.*
   - 我需要優先處理我今天的任務才能趕上截止日期。

## 📘 英文文法
### 條件句 (Conditional Sentences) Type 1
用於表達未來可能發生的狀況及其結果，假設語氣的真實條件句。
- If you finish your coding by noon, we can grab lunch together. (如果你中午前完成編碼，我們可以一起去吃午餐。)
- If the server goes down, we will have to restart the whole system. (如果伺服器當機，我們就必須重啟整個系統。)
- If I have time tonight, I'll definitely check out that new AI tool. (如果我今晚有時間，我一定會去看看那個新的AI工具。)
### Used to / Be used to
"Used to"表示過去的習慣或狀態；"Be used to"表示習慣於某事，後面接動名詞或名詞。
- I used to work late almost every day in my old job. (我以前的工作幾乎每天都加班。)
- Now, I'm used to waking up early for my commute. (現在，我習慣早起通勤了。)
- Engineers are used to dealing with complex problems and debugging. (工程師習慣於處理複雜問題和除錯。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作、職業
   - わたしはエンジニアのしごとをしています。
   - 我正在做工程師的工作。
2. **かいしゃ** / 会社 / kaisha — 公司
   - まいにちかいしゃへいきます。
   - 我每天去公司。
3. **べんきょう** / 勉強 / benkyou — 學習
   - にほんごのべんきょうはたのしいです。
   - 學習日文很有趣。
4. **じかん** / 時間 / jikan — 時間
   - きょうのしごとのおわりはなんじかんかかりますか。
   - 今天的工作結束要花多少小時呢？
5. **やすみ** / 休み / yasumi — 休息、假日
   - きょうはげつようびですが、やすみじゃありません。
   - 今天是星期一，但不是假日。
6. **わかる** / 分かる / wakaru — 懂、明白
   - このプログラミングのもんだいがわかりますか。
   - 你懂這個程式設計的問題嗎？
7. **つかう** / 使う / tsukau — 使用
   - わたしはAIツールをつかいます。
   - 我使用AI工具。
8. **かいぎ** / 会議 / kaigi — 會議
   - あしたのあさ、たいせつなかいぎがあります。
   - 明天早上有個重要的會議。
9. **はじめる** / 始める / hajimeru — 開始
   - さあ、しごとをはじめるじかんです！
   - 好了，是時候開始工作了！
10. **たいへん** / 大変 / taihen — 辛苦、不得了、嚴重
   - このIoTプロジェクトはすこしたいへんですね。
   - 這個IoT專案有點辛苦呢。

## 🗾 日文文法（N5）
### 〜ます / 〜ません / 〜ました / 〜ませんでした (動詞的肯定、否定、過去式)
**結構**：動詞(ます形)
用於表達動詞現在、未來、過去的肯定與否定，是日文敬體的基本形式，非常實用。
- わたしはまいにちしごとをします。(我每天都工作。)
- きのうはかいぎにいきませんでした。(昨天我沒有去會議。)
### 名詞 + は + 名詞 + です / ではありません (A是B / A不是B)
**結構**：名詞1 + は + 名詞2 + です / ではありません
用於介紹或說明主語的身份、狀態或屬性，是日文最基礎的肯定與否定句型。
- わたしは台湾のエンジニアです。(我是台灣的工程師。)
- これはわたしのパソコンではありません。(這不是我的筆記型電腦。)
