# 2026-09-24（週四）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施（計畫或系統）
   - *We need to implement the new system by next month.*
   - 我們需要在下個月前實施這個新系統。
2. **optimize** (v.) — 優化、最佳化（效能或效率）
   - *I'm trying to optimize the code for better speed.*
   - 我正在嘗試優化程式碼以提高速度。
3. **troubleshoot** (v.) — 排除故障、解決問題（技術性）
   - *Can you help me troubleshoot this network issue?*
   - 你能幫我解決這個網路問題嗎？
4. **prototype** (n.) — 原型、樣本（產品或系統）
   - *The team is building a prototype for the new IoT device.*
   - 團隊正在為新的物聯網設備建造一個原型。
5. **integrate** (v.) — 整合、結合（不同部分）
   - *We need to integrate this module into the main system.*
   - 我們需要將這個模組整合到主系統中。
6. **renewable** (adj.) — 可再生的（如能源）
   - *Solar power is a great example of renewable energy.*
   - 太陽能是可再生能源的一個很好的例子。
7. **scenario** (n.) — 情境、場景（可能發生的事）
   - *Let's consider a few different scenarios for this project.*
   - 讓我們為這個專案考慮幾種不同的情境。
8. **collaborate** (v.) — 合作、協作（與他人共同工作）
   - *It's always better to collaborate with colleagues on big tasks.*
   - 在大型任務上與同事合作總是更好的。
9. **feedback** (n.) — 回饋、意見（對工作表現等）
   - *We'll get feedback on our presentation next week.*
   - 我們下週會收到關於我們簡報的回饋。
10. **deadline** (n.) — 截止日期（完成工作的期限）
   - *The deadline for this report is super tight, unfortunately.*
   - 不幸的是，這份報告的截止日期非常緊。

## 📘 英文文法
### 過去習慣與現在習慣：Used to vs. Be used to
Used to 表示過去的習慣或狀態，現在已不復存在；Be used to 表示習慣於某事，強調習慣的狀態。
- I used to work on embedded systems full-time. (我過去是全職從事嵌入式系統工作。)
- I'm used to dealing with complex technical issues. (我習慣處理複雜的技術問題。)
- It took a while, but I got used to the new software. (花了一些時間，但我習慣了新軟體。)
### 條件句：假設語氣 Type 1 & Type 2
Type 1 假設未來可能發生的真實情況；Type 2 假設現在或未來不可能或非真實的情況。
- If we optimize this, the system will run faster. (如果我們優化這個，系統會跑得更快。)
- If I had more time, I would learn a new programming language. (如果我有更多時間，我會學一門新的程式語言。)
- What would you do if the project suddenly failed? (如果專案突然失敗，你會怎麼辦？)

## 🗾 日文文法（N5）
### 〜ます / 〜ません (動詞肯定/否定)
**結構**：動詞ます形 + ます / ません
動詞「ます形」接續「ます」表示肯定現在或未來的動作；接續「ません」表示否定。
- 毎日コーヒーを飲みます。 (我每天喝咖啡。)
- 明日会社へ行きません。 (我明天不去公司。)
### 〜たいです (表達願望)
**結構**：動詞ます形 + たいです
動詞「ます形」去掉「ます」後接「たいです」，表示「想做某事」的願望。
- 新しいAIツールを使いたいです。 (我想使用新的AI工具。)
- もっと日本語を勉強したいです。 (我想學更多日語。)
