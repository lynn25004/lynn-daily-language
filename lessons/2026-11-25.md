# 2026-11-25（週三）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **prototype** (n.) — 早期模型或試驗品
   - *We're building a prototype for the new IoT device.*
   - 我們正在為新的物聯網設備打造原型機。
2. **debug** (v.) — 排除程式錯誤
   - *I spent all morning trying to debug this code.*
   - 我花了一整個早上試圖排除這段程式碼的錯誤。
3. **deploy** (v.) — 部署、佈局
   - *We need to deploy the new software next week.*
   - 我們需要在下週部署新軟體。
4. **innovate** (v.) — 創新
   - *Let's brainstorm ways to innovate in renewable energy.*
   - 讓我們腦力激盪一下如何在再生能源領域創新。
5. **optimize** (v.) — 優化、使…最佳化
   - *Can we optimize the power consumption of this chip?*
   - 我們能優化這個晶片的功耗嗎？
6. **flexible** (adj.) — 靈活的、可變通的
   - *The work schedule is quite flexible here.*
   - 這裡的工作時間表相當靈活。
7. **collaborate** (v.) — 合作
   - *I often collaborate with my colleagues on projects.*
   - 我經常與同事合作專案。
8. **streamline** (v.) — 簡化流程
   - *We need to streamline the development process.*
   - 我們需要簡化開發流程。
9. **insight** (n.) — 深刻見解
   - *The AI tool gave us valuable insight into user behavior.*
   - 這個 AI 工具給了我們關於用戶行為的寶貴見解。
10. **efficient** (adj.) — 有效率的
   - *Renewable energy sources are becoming more efficient.*
   - 再生能源變得越來越有效率。

## 📘 英文文法
### 現在完成式 (Present Perfect Tense)
用於表示過去發生的動作對現在造成的結果或影響，或強調動作的經驗。
- I have already deployed the new system. (我已經部署了新系統。)
- Have you ever debugged a complex system before? (你以前有除錯過複雜的系統嗎？)
- She has worked on IoT projects for five years. (她已經在物聯網專案上工作五年了。)
### 被動語態 (Passive Voice)
當動作的對象比動作的執行者更重要時使用，或執行者不清楚。
- The prototype will be tested next week. (原型機將在下週進行測試。)
- This code needs to be optimized. (這段程式碼需要被優化。)
- New safety standards are being implemented. (新的安全標準正在被實施。)

## 🇯🇵 日文單字（N5）
1. **はじめまして** / 初めまして / hajimemashite — 初次見面
   - はじめまして、エンジニアの[名前]です。
   - 初次見面，我是工程師 [名字]。
2. **どうぞよろしく** / どうぞ宜しく / douzo yoroshiku — 請多指教
   - はじめまして。どうぞよろしくおねがいします。
   - 初次見面，請多多指教。
3. **ちょうさ** / 調査 / chousa — 調查
   - 新しい技術を調査しています。
   - 我正在調查新的技術。
4. **かいはつ** / 開発 / kaihatsu — 開發
   - IoTのシステムを開発しています。
   - 我正在開發物聯網系統。
5. **けいかく** / 計画 / keikaku — 計畫
   - 来週の計画を立てています。
   - 我正在制定下週的計畫。
6. **じかん** / 時間 / jikan — 時間
   - 開発に時間がかかります。
   - 開發需要花費時間。
7. **たいへん** / 大変 / taihen — 困難、辛苦
   - 仕事は大変ですが、面白いです。
   - 工作雖然辛苦，但是很有趣。
8. **しごと** / 仕事 / shigoto — 工作
   - どんな仕事が好きですか。
   - 你喜歡什麼樣的工作？
9. **むずかしい** / 難しい / muzukashii — 困難的
   - この問題は少し難しいです。
   - 這個問題有點困難。
10. **やすい** / 易い / yasui — 容易的
   - それは易い仕事ではありません。
   - 那不是一份容易的工作。

## 🗾 日文文法（N5）
### 〜ています
**結構**：動詞ます形 + ています
表示正在進行的動作、狀態的持續或習慣性行為。
- 今、プログラムを書いています。(我現在正在寫程式。)
- 私はAIについて勉強しています。(我正在學習 AI 相關知識。)
- 彼は毎日、図書館で勉強しています。(他每天都在圖書館學習。)
### 〜について
**結構**：名詞 + について
表示談話或思考的對象，相當於中文的「關於…」。
- 再生エネルギーについて話しましょう。(我們來談談再生能源吧。)
- この本は日本の歴史についてです。(這本書是關於日本歷史的。)
- IoTについて質問があります。(我對 IoT 有個問題。)
