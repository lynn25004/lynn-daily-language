## 📘 英文文法
### Used to (過去習慣)
用來表達過去經常發生或存在的習慣，但現在已不再如此。
- I used to code all night. (我以前常熬夜寫程式。)
- She used to work on embedded systems. (她以前從事嵌入式系統。
- We didn't use to have AI tools. (我們以前沒有 AI 工具。)
### Would rather (寧願、比較喜歡)
表達「寧願、比較喜歡」做某事，後接原形動詞，表示偏好。
- I'd rather work on IoT. (我寧願做 IoT 專案。)
- Would you rather debug or optimize? (你寧願除錯還是優化？)
- He'd rather stay home tonight. (他今晚寧願待在家。)

## 🇯🇵 日文單字（N5）
1. **きんようび** / 金曜日 / kinyoubi — 星期五
   - きょうはきんようびです。
   - 今天是星期五。
2. **しごと** / 仕事 / shigoto — 工作
   - しごとがおわりました。
   - 工作結束了。
3. **つかれる** / 疲れる / tsukareru — 疲倦
   - きょうはとてもつかれました。
   - 今天非常累。
4. **やすみ** / 休み / yasumi — 休息、假日
   - あしたはやすみです。
   - 明天是假日。
5. **しゅうまつ** / 週末 / shuumatsu — 週末
   - しゅうまつになにをしますか。
   - 週末要做什麼？
6. **べんきょう** / 勉強 / benkyou — 學習
   - にほんごをべんきょうします。
   - 學習日文。
7. **しゅみ** / 趣味 / shumi — 興趣
   - わたしのしゅみは、ほんをよむことです。
   - 我的興趣是讀書。
8. **だいじょうぶ** / 大丈夫 / daijoubu — 沒關係、沒問題
   - だいじょうぶですか。
   - 你還好嗎？
9. **はじめる** / 始める / hajimeru — 開始
   - そろそろはじめましょう。
   - 差不多該開始了。
10. **がんばる** / 頑張る / ganbaru — 加油、努力
   - しごと、がんばってください。
   - 工作請加油。

## 🗾 日文文法（N5）
### 動詞て形 + ください (請做...)
**結構**：動詞て形 + ください
用來禮貌地請求或命令對方做某事，表示「請做...」。
- これ、読んでください。(請讀這個。)
- 日本語を教えてください。(請教我日文。)
### 動詞(ます形)たいです (想做...)
**結構**：動詞(ます形) + たいです
表示說話者「想要做某事」的願望，將動詞ます形詞尾ます去掉後加上たいです。
- 日本へ行きたいです。(我想去日本。)
- もっと日本語を勉強したいです。(我想更努力學習日文。)
