## 📘 英文文法
### 現在完成進行式
用於表示動作從過去開始，一直持續到現在，並且可能還會繼續下去。
- I have been working on this project for three hours. (我已經在這個專案上工作三個小時了。)
- She has been studying Japanese since last year. (她從去年就開始學日文了。)
- They have been developing the new software for months. (他們開發新軟體已經好幾個月了。)
### 假設語氣過去式 (第二類)
用於描述與現在事實相反的假設情況，表達「如果...就...」的語氣。
- If I had more time, I would learn more programming languages. (如果我有更多時間，我會學更多程式語言。)
- If he were here, he would help us. (如果他在這裡，他就會幫我們。)
- If I knew the answer, I would tell you. (如果我知道答案，我就會告訴你。)

## 🗾 日文文法（N5）
### 「〜ています」的用法
**結構**：動詞ます形去掉ます + ています
表示動作正在進行、狀態持續或習慣性動作。
- いま、かいぎをしています。(現在，我們正在開會。)
- わたしはにほんごをべんきょうしています。(我正在學習日文。)
- えきはあそこです。(車站就在那裡。)
### 「〜なければなりません」
**結構**：動詞ない形去掉ない + ければなりません
表示「必須做某事」，是「～なくてはいけません」的另一種說法。
- しごとをしなければなりません。(我必須工作。)
- じゅぎょうにでなければなりません。(我必須去上課。)
- かいぎにしゅっぱつしなければなりません。(我必須要去參加會議。)
