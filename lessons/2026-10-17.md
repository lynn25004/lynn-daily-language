# 2026-10-17（週六）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行；實施
   - *We need to implement the new system soon.*
   - 我們需要盡快實施新系統。
2. **optimize** (v.) — 優化；最佳化
   - *Can we optimize this code for speed?*
   - 我們可以優化這段程式碼以提高速度嗎？
3. **component** (n.) — 零件；組成部分
   - *This component is crucial for the device.*
   - 這個零件對設備至關重要。
4. **troubleshoot** (v.) — 解決故障；排除問題
   - *Let's troubleshoot the network issue together.*
   - 我們一起解決網路問題吧。
5. **reliable** (adj.) — 可靠的；值得信賴的
   - *Is this data source reliable enough?*
   - 這個資料來源足夠可靠嗎？
6. **hobby** (n.) — 業餘愛好；嗜好
   - *What's your favorite hobby on weekends?*
   - 你週末最喜歡的嗜好是什麼？
7. **explore** (v.) — 探索；探究
   - *I want to explore new AI tools this month.*
   - 我這個月想探索新的 AI 工具。
8. **solution** (n.) — 解決方案；解答
   - *Do you have a solution for this problem?*
   - 你有這個問題的解決方案嗎？
9. **project** (n.) — 專案；計畫
   - *My IoT project is almost finished.*
   - 我的 IoT 專案快完成了。
10. **deadline** (n.) — 截止日期；最後期限
   - *The project deadline is next Friday.*
   - 專案的截止日期是下週五。

## 📘 英文文法
### 未來式：be going to
表示事先計畫好、即將發生的事情，或根據目前跡象判斷會發生的事。
- I'm going to work on my embedded project this weekend. (我這個週末要忙我的嵌入式專案。)
- Are you going to attend the tech meetup? (你打算參加那個科技聚會嗎？)
- It's going to rain soon; look at those clouds. (快要下雨了；看看那些雲。)
### 現在完成式：Have/Has + Vpp
描述從過去某時點開始持續到現在的動作或經驗，或已完成但影響持續到現在的動作。
- I have worked on several IoT projects. (我曾經參與過幾個物聯網專案。)
- Have you ever tried using this AI tool? (你曾經試過使用這個 AI 工具嗎？)
- She hasn't finished her report yet. (她還沒完成她的報告。)

## 🇯🇵 日文單字（N5）
1. **しゅうまつ** / 週末 / shuumatsu — 週末
   - 週末は何をしますか？
   - 週末你要做什麼？
2. **べんきょう** / 勉強 / benkyou — 學習；讀書
   - 日本語を勉強します。
   - 我學習日文。
3. **たのしい** / 楽しい / tanoshii — 快樂的；有趣的
   - 週末はとても楽しいです。
   - 週末非常愉快。
4. **いく** / 行く / iku — 去
   - どこへ行きますか？
   - 你要去哪裡？
5. **たべる** / 食べる / taberu — 吃
   - おいしいものを食べたいです。
   - 我想吃好吃的東西。
6. **みる** / 見る / miru — 看；觀看
   - 映画を見ます。
   - 我看電影。
7. **なに** / 何 / nani — 什麼
   - 何が好きですか？
   - 你喜歡什麼？
8. **どこ** / どこ / doko — 哪裡
   - 駅はどこですか？
   - 車站是在哪裡？
9. **ともだち** / 友達 / tomodachi — 朋友
   - 友達と会います。
   - 我會見朋友。
10. **きょう** / 今日 / kyou — 今天
   - 今日は土曜日です。
   - 今天是星期六。

## 🗾 日文文法（N5）
### 〜たいです (想做...)
**結構**：動詞ます形 + たいです
表達自己的願望或想做的事情，動詞的ます形去掉ます後接たいです。
- 新しいAIツールを使いたいです。(我想使用新的AI工具。)
- 週末はゆっくり休みたいです。(週末我想好好休息。)
### 〜ませんか (要不要...？)
**結構**：動詞ます形 + ませんか
用於邀請或建議對方一起做某事，語氣輕鬆友善，常用於日常對話。
- 一緒にコーヒーを飲みませんか？(要不要一起喝咖啡？)
- 明日、映画を見に行きませんか？(明天要不要去看電影？)
