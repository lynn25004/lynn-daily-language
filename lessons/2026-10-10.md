# 2026-10-10（週六）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **weekend** (n.) — 一週的結束，週六日
   - *What are your plans for the upcoming weekend?*
   - 你這個週末有什麼計畫啊？
2. **explore** (v.) — 探索、發掘新事物
   - *I want to explore new AI tools this month.*
   - 這個月我想探索新的 AI 工具。
3. **prototype** (n.) — 產品或系統原型
   - *The team is building a new IoT prototype.*
   - 團隊正在打造一個新的物聯網原型。
4. **efficient** (adj.) — 有效率的、高效率的
   - *We need to find a more efficient way to debug.*
   - 我們需要找到一種更有效率的除錯方式。
5. **innovative** (adj.) — 創新的、革新的
   - *That's an innovative solution for renewable energy.*
   - 那是個關於再生能源的創新解決方案。
6. **debug** (v.) — 找出並修正程式錯誤
   - *It took hours to debug that tiny error.*
   - 花了好幾個小時才把那個小錯誤除掉。
7. **update** (n./v.) — 更新、最新消息
   - *Any update on the embedded system project?*
   - 嵌入式系統專案有任何最新消息嗎？
8. **leisure** (n.) — 閒暇、空閒時間
   - *I enjoy reading books in my leisure time.*
   - 我喜歡在閒暇時間讀書。
9. **gadget** (n.) — 小器具、小裝置
   - *This new smart home gadget is pretty cool.*
   - 這個新的智慧家庭小裝置還蠻酷的。
10. **optimize** (v.) — 優化、最佳化
   - *We need to optimize the code for better performance.*
   - 我們需要優化程式碼以提升效能。

## 📘 英文文法
### 表達未來計畫：be going to
用來談論已經決定好、有計畫的未來行動，或根據目前跡象判斷即將發生的事。
- I'm going to visit my family this weekend. (我這個週末要去探望家人。)
- She is going to start a new project next month. (她下個月將要開始一個新專案。)
- Look at those dark clouds! It's going to rain soon. (看那些烏雲！要下雨了。)
### 假設語氣：If (現在簡單式), will (原形動詞)
用於描述在目前或未來可能發生的狀況，以及其結果，表達可能性或預測。
- If you study hard, you will pass the TOEIC test easily. (如果你努力學習，你就會輕鬆通過多益考試。)
- If the weather is good, we will go hiking tomorrow. (如果天氣好，我們明天就會去健行。)
- If I finish debugging early, I will relax more. (如果我早點完成除錯，我就會更放鬆。)

## 🇯🇵 日文單字（N5）
1. **しゅうまつ** / 週末 / shuumatsu — 週末
   - しゅうまつは なにを しますか？
   - 週末要做什麼呢？
2. **しごと** / 仕事 / shigoto — 工作
   - きょうは しごとが あります。
   - 今天有工作。
3. **やすみ** / 休み / yasumi — 休息、假日
   - きのうは 休みでした。
   - 昨天是休息日。
4. **べんきょう** / 勉強 / benkyou — 學習、讀書
   - まいにち にほんごを べんきょうします。
   - 我每天學習日文。
5. **たのしい** / 楽しい / tanoshii — 快樂的、有趣的
   - それは とても 楽しいです。
   - 那真是太有趣了。
6. **どこ** / どこ / doko — 哪裡
   - あなたの うちは どこですか？
   - 你家在哪裡？
7. **みる** / 見る / miru — 看
   - えいがを 見ます。
   - 看電影。
8. **きく** / 聞く / kiku — 聽、問
   - おんがくを 聞きます。
   - 聽音樂。
9. **する** / する / suru — 做
   - スポーツを します。
   - 做運動。
10. **ともだち** / 友達 / tomodachi — 朋友
   - ともだちと あそびます。
   - 和朋友玩。

## 🗾 日文文法（N5）
### 動詞的禮貌形：〜ます / 〜ません
**結構**：動詞ます形 / 動詞ません形
用於表達現在或未來將會發生的動作，以及其否定形式，是日文最基本的禮貌體動詞變化。
- わたしは ごはんを 食べます。 (我吃飯。)
- わたしは テレビを 見ません。 (我不看電視。)
### 描述和判斷：名詞 + は + 名詞 + です / ではありません
**結構**：名詞１ + は + 名詞２ + です / ではありません
用於說明或判斷事物是什麼，或不是什麼。動詞「です」表示肯定，而「ではありません」表示否定。
- これは ペンです。 (這是筆。)
- わたしは エンジニアではありません。 (我不是工程師。)
