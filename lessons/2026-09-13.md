# 2026-09-13（週日）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **implement** (v.) — 執行、實施
   - *We need to implement this new feature by next month.*
   - 我們需要在下個月前實施這項新功能。
2. **optimize** (v.) — 優化、最佳化
   - *Can you help me optimize this code for better performance?*
   - 你能幫我優化這段程式碼以提高效能嗎？
3. **troubleshoot** (v.) — 排除故障、解決問題
   - *I spent all morning troubleshooting the network issue.*
   - 我花了一整個早上排除網路問題。
4. **scenario** (n.) — 情境、場景
   - *Let's consider a few different scenarios for this project.*
   - 讓我們為這個專案考慮幾種不同的情境。
5. **integrate** (v.) — 整合、結合
   - *We need to integrate this module with the existing system.*
   - 我們需要將這個模組與現有系統整合。
6. **prototype** (n.) — 原型、樣本
   - *The team is building a prototype of the new IoT device.*
   - 團隊正在建造這個新物聯網裝置的原型。
7. **leisure** (n.) — 閒暇、空閒時間
   - *What do you usually do in your leisure time on weekends?*
   - 你週末閒暇時通常做些什麼？
8. **recharge** (v.) — 充電、恢復精力
   - *I like to recharge myself by hiking on Sundays.*
   - 我喜歡在星期天透過健行來恢復精力。
9. **insight** (n.) — 洞察力、見解
   - *Your insight on the market trends was very helpful.*
   - 你對市場趨勢的見解非常有幫助。
10. **monitor** (v.) — 監控、監視
   - *We need to monitor the system's performance closely.*
   - 我們需要密切監控系統的效能。

## 📘 英文文法
### 條件句 (Conditional Sentences Type 1)
用於描述未來可能發生且結果可預期的情況，表示「如果...，就會...」。
- If you finish early, we'll grab some coffee. (如果你早點完成，我們就去喝咖啡。)
- If it rains tomorrow, I will stay home and read. (如果明天會下雨，我就會待在家讀書。)
- If the system crashes, we will lose all our data. (如果系統當機，我們會失去所有資料。)
### 動詞片語 with "Look"
動詞片語在日常會話中很常用，例如 look up (查詢), look into (調查), look forward to (期待)。
- I need to look up that new vocabulary word. (我需要查那個新單字。)
- The manager will look into the complaint next week. (經理下週會調查這項投訴。)
- I'm really looking forward to our trip next month! (我真的很期待我們下個月的旅行！)

## 🗾 日文文法（N5）
### 動詞「～ます / ～ません / ～ました / ～ませんでした」
**結構**：動詞(ます形)
用於表達現在或未來的肯定、否定，以及過去的肯定、否定。這是日文動詞的基本禮貌形式。
- わたしは まいにち コーヒーを のみます。 (我每天喝咖啡。)
- きのうは テレビを みませんでした。 (昨天我沒有看電視。)
### 「～が あります / います」 表達存在
**結構**：名詞 + が + あります / います
「あります」用於表示非生物（物品、地點）的存在；「います」用於表示生物（人、動物）的存在。
- つくえの うえに ほんが あります。 (桌子上有書。)
- へやに ねこが います。 (房間裡有貓。)
