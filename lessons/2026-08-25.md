# 2026-08-25（週二）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **firmware** (n.) — 嵌入式系統中的軟體
   - *The new firmware update fixed some bugs.*
   - 新的韌體更新修復了一些錯誤。
2. **deploy** (v.) — 部署、配置（系統或軟體）
   - *We plan to deploy the new system next month.*
   - 我們計畫下個月部署新系統。
3. **optimize** (v.) — 優化、最佳化效能
   - *Can we optimize this code for better performance?*
   - 我們能優化這段程式碼以提高效能嗎？
4. **feature** (n.) — 功能、特色（產品或軟體）
   - *This new phone has many cool features.*
   - 這款新手機有很多很酷的功能。
5. **troubleshoot** (v.) — 排除故障、解決問題
   - *I spent an hour trying to troubleshoot the network issue.*
   - 我花了一小時試圖排除網路問題。
6. **workflow** (n.) — 工作流程、作業程序
   - *We need to streamline our workflow to be more efficient.*
   - 我們需要簡化工作流程以提高效率。
7. **commute** (n./v.) — 通勤時間或路程
   - *My daily commute takes about 30 minutes.*
   - 我每天通勤大約需要30分鐘。
8. **insight** (n.) — 洞察力、深刻見解
   - *Your feedback gave me valuable insight.*
   - 你的回饋給了我寶貴的見解。
9. **initiative** (n.) — 主動性、積極性
   - *She always takes the initiative in team projects.*
   - 她在團隊專案中總是積極主動。
10. **feedback** (n.) — 回饋意見、反應
   - *Please give me some feedback on my presentation.*
   - 請給我一些關於我簡報的回饋意見。

## 📘 英文文法
### 條件句第一型 (If... will...)
描述未來可能發生且結果可預期的情況，用於計畫、建議或警告。
- If we finish this early, we'll have time for a coffee break.（如果我們早點完成，我們就有時間喝咖啡了。）
- If you need help with the code, just ask me.（如果你需要程式碼的幫助，儘管問我。）
- If the system works, we will deploy it next week.（如果系統運作正常，我們下週就會部署它。）
### 動詞片語 with 'up' (常用於工作情境)
許多動詞加上 'up' 會形成新的意義，常用於日常與職場溝通，表達完成或提升。
- Let's set up a meeting for next Tuesday.（我們下週二來安排一個會議吧。）
- Can you look up the data for this project?（你能查一下這個專案的數據嗎？）
- I need to back up my files before the update.（我需要在更新前備份我的檔案。）

## 🇯🇵 日文單字（N5）

   - わたしは まいにち、しごとを します。
   - 我每天都工作。
2. **べんきょう** / 勉強 / benkyou — 學習、讀書
   - わたしは にほんごを べんきょうします。
   - 我學習日文。
3. **まいにち** / 毎日 / mainichi — 每天
   - まいにち、コーヒーを のみます。

   - にほんごの べんきょうは たいへんですが、たのしいです。

## 🗾 日文文法（N5）
### 名詞 + は + 名詞 + です
**結構**：名詞 + は + 名詞 + です
用來介紹或說明某事物是什麼，是日文最基本的肯定句型。
- わたしは エンジニアです。（我是工程師。）
- これは わたしの パソコンです。（這是我的電腦。）
### 動詞ます形（肯定・否定）
**結構**：動詞ます / 動詞ません
用於禮貌且肯定的語氣，表示現在或未來的動作；否定則用「ません」。
- まいにち、コーヒーを のみます。（我每天都喝咖啡。）
- きょうは しごとを しません。（我今天不工作。）
