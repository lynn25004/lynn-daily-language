# 2026-09-23（週三）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **firmware** (n.) — 韌體（硬體上的軟體）
   - *We need to update the device's firmware for better performance.*
   - 我們需要更新設備的韌體以獲得更好的效能。
2. **optimize** (v.) — 優化（使達到最佳狀態）
   - *I need to optimize this code to run faster.*
   - 我需要優化這段程式碼讓它跑更快。
3. **troubleshoot** (v.) — 故障排除（解決問題）
   - *Can you help me troubleshoot this network issue?*
   - 你能幫我解決這個網路問題嗎？
4. **scenario** (n.) — 情境（可能發生的情況）
   - *Let's consider a few different deployment scenarios.*
   - 我們來考慮幾種不同的部署情境。
5. **implement** (v.) — 實施（執行計畫或系統）
   - *We plan to implement the new feature next month.*
   - 我們計劃下個月實施這個新功能。
6. **allocate** (v.) — 分配（分派資源）
   - *We need to allocate more memory for this program.*
   - 我們需要為這個程式分配更多記憶體。
7. **commute** (n./v.) — 通勤（上下班路程）
   - *My daily commute takes about 30 minutes.*
   - 我每天通勤大約需要30分鐘。
8. **deadline** (n.) — 截止日期（完成任務的期限）
   - *The project deadline is approaching fast!*
   - 專案的截止日期很快就到了！
9. **feedback** (n.) — 回饋（意見或反應）
   - *Please give me some feedback on my presentation.*
   - 請給我一些關於我報告的回饋。
10. **recharge** (v.) — 充電（恢復精力）
   - *I need to recharge my energy with a cup of coffee.*
   - 我需要一杯咖啡來補充精力。

## 📘 英文文法
### Conditional Sentences (Type 1)
表達未來可能發生且結果真實的情況，結構為 "If + S + V (現在式), S + will + V (原形)。"
- If it rains tomorrow, we will stay home. (如果明天會下雨，我們就待在家。)
- If you finish early, you can go home. (如果你早點完成，你就可以回家。)
- If he studies hard, he will pass the exam. (如果他努力讀書，他會通過考試。)
### Phrasal Verbs with "up"
許多動詞和 "up" 結合形成片語，常表示「完成」、「增加」或「向上」。
- Please pick up your trash. (請撿起你的垃圾。)
- I need to back up my files. (我需要備份我的檔案。)
- Let's set up the new IoT device. (我們來設置這個新的物聯網設備。)

## 🇯🇵 日文單字（N5）
1. **おきる** / 起きる / okiru — 起床
   - わたしはまいにちろくじにおきます。
   - 我每天六點起床。
2. **はたらく** / 働く / hataraku — 工作
   - エンジニアとして、かいしゃではたらきます。
   - 身為工程師，我在公司工作。
3. **でんしゃ** / 電車 / densha — 電車
   - まいにちでんしゃでかいしゃへいきます。
   - 我每天搭電車去公司。
4. **つかう** / 使う / tsukau — 使用
   - このツールをつかって、しごとをします。
   - 我使用這個工具來工作。
5. **むずかしい** / 難しい / muzukashii — 困難的
   - このもんだいはとてもむずかしいです。
   - 這個問題非常困難。
6. **たのしい** / 楽しい / tanoshii — 快樂的、有趣的
   - にほんごのべんきょうはとてもたのしいです。
   - 學日文很有趣。
7. **あたらしい** / 新しい / atarashii — 新的
   - あたらしいデバイスをかいはつしています。
   - 我們正在開發新型設備。
8. **わかる** / 分かる / wakaru — 懂、明白
   - せんせいのせつめいがよくわかります。
   - 我很明白老師的說明。
9. **ごはん** / ご飯 / gohan — 飯、餐點
   - ひるごはんをたべます。
   - 我吃午餐。
10. **やすみ** / 休み / yasumi — 休息、假日
   - きんようびはかいしゃのやすみです。
   - 星期五是公司的休息日。

## 🗾 日文文法（N5）
### 名詞 + と + 名詞
**結構**：名詞 + と + 名詞
用來連接兩個或多個名詞，表示「和」、「以及」的意思，通常用於並列。
- わたしはペンとノートをもっています。 (我帶著筆和筆記本。)
- きょうはしごととべんきょうがあります。 (今天有工作和學習。)
### 動詞(ます形) + ましょう
**結構**：動詞(ます形) + ましょう
表示「我們一起做...吧！」的提議或勸誘，或是表達「我來做...吧！」的意願。
- いっしょにカフェへいきましょう。 (我們一起去咖啡館吧！)
- このしごとをはじましょう。 (我們開始這項工作吧！)
