# 2026-10-22（週四）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **firmware** (n.) — 設備中固定的軟體
   - *We need to update the firmware on these devices.*
   - 我們需要更新這些設備的韌體。
2. **optimize** (v.) — 優化、使效率最高
   - *Let's optimize the code to run faster.*
   - 我們來優化程式碼，讓它跑得更快。
3. **deploy** (v.) — 部署、配置（軟體或設備）
   - *When can we deploy the new system?*
   - 我們什麼時候可以部署新系統？
4. **scenario** (n.) — 情境、設想
   - *What if we consider a different scenario?*
   - 如果我們考慮另一種情境呢？
5. **troubleshoot** (v.) — 排除故障、解決問題
   - *Can you help me troubleshoot this network issue?*
   - 你能幫我排除這個網路問題嗎？
6. **integrate** (v.) — 整合、使...合併
   - *We need to integrate this module with the main system.*
   - 我們需要將這個模組整合到主系統中。
7. **sustainable** (adj.) — 可持續的、永續的
   - *Renewable energy is key for a sustainable future.*
   - 再生能源是永續未來的關鍵。
8. **interface** (n.) — 介面（使用者、軟硬體）
   - *The user interface of this app is very intuitive.*
   - 這個應用程式的使用者介面非常直觀。
9. **innovation** (n.) — 創新、革新
   - *AI tools drive a lot of innovation in our field.*
   - AI 工具推動了我們領域的許多創新。
10. **feedback** (n.) — 回饋、意見
   - *Please give me some feedback on my presentation.*
   - 請給我一些關於我簡報的回饋。

## 📘 英文文法
### 第一類條件句 (Conditional Type 1)
用來表達未來可能發生或真實情況的假設，結構是 "If + 主詞 + 現在簡單式, 主詞 + will + 原形動詞"。
- If you study hard, you will pass the TOEIC test. (如果你努力學習，你就會通過多益考試。)
- If the system crashes, we will restart it immediately. (如果系統當機，我們會立刻重啟它。)
- If I finish early, I'll go for a walk. (如果我早點忙完，我就去散步。)
### 片語動詞：搭配 "up" 的常用片語
許多動詞加上 "up" 後會產生不同意思，常用於日常或職場情境，例如 "set up" (設定)、"pick up" (學習/接人)、"follow up" (追蹤)。
- Could you help me set up this new IoT device? (你能幫我設定這個新的物聯網裝置嗎？)
- I need to pick up a new skill for this project. (我需要為這個專案學習一項新技能。)
- Let's follow up on this issue next week. (我們下週再追蹤這個問題。)

## 🗾 日文文法（N5）
### 名詞 + は + 名詞 + です (N1 wa N2 desu)
**結構**：名詞1 + は + 名詞2 + です
這是日語最基本的肯定句型，用來介紹或描述「名詞1」是什麼或屬於什麼類別，表示「名詞1是名詞2」。
- 私はエンジニアです。 (我是工程師。)
- これは私の本です。 (這是我的書。)
### 動詞(ます形) + ましょうか / ませんか
**結構**：動詞(ます形) + ましょうか / ませんか
「ましょうか」表示「要不要我為您做…？」（提供協助）或「我們一起做…好嗎？」（提議）。「ませんか」則是用來邀請對方做某事。
- 手伝いましょうか？ (要不要我幫忙？)
- 一緒にコーヒーを飲みませんか？ (要不要一起喝咖啡？)
