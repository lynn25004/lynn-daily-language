# 2026-11-16（週一）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **optimize** (v.) — 優化，最佳化
   - *We need to optimize this code.*
   - 我們需要優化這段程式碼。
2. **implement** (v.) — 執行，實施
   - *Let's implement this new feature.*
   - 我們來實施這個新功能吧。
3. **troubleshoot** (v.) — 排除故障，解決問題
   - *Can you help troubleshoot this bug?*
   - 你能幫忙排除這個錯誤嗎？
4. **scenario** (n.) — 情境，情況
   - *Imagine a worst-case scenario.*
   - 想像一下最糟的情況。
5. **feedback** (n.) — 回饋，意見
   - *Your feedback is really helpful.*
   - 你的回饋真的很有幫助。
6. **integrate** (v.) — 整合，結合
   - *We should integrate these systems.*
   - 我們應該整合這些系統。
7. **prototype** (n.) — 原型，樣本
   - *The team is building a prototype.*
   - 團隊正在製作一個原型。
8. **sustainable** (adj.) — 可持續的，永續的
   - *We need sustainable energy solutions.*
   - 我們需要永續的能源解決方案。
9. **efficient** (adj.) — 高效率的
   - *This new process is very efficient.*
   - 這個新流程非常有效率。
10. **monitor** (v.) — 監控，監視
   - *We need to monitor system performance.*
   - 我們需要監控系統效能。

## 📘 英文文法
### 動名詞作主詞
動名詞 (-ing 形式) 作為句子的主詞，表示一項活動或行為，使句子更生動。
- Learning new tech is exciting.（學習新科技很令人興奮。）
- Debugging code takes time.（偵錯程式碼需要時間。）
- Working from home is common now.（現在在家工作很常見。）
### 現在完成式 (Present Perfect)
表示從過去某個時間點開始，一直持續到現在或對現在有影響的動作或狀態，強調經驗或成果。
- I have worked on IoT projects.（我曾經參與過物聯網專案。）
- She has learned a lot of AI tools.（她學會了很多 AI 工具。）
- We haven't finished the report yet.（我們還沒完成報告。）

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - 明日、仕事があります。
   - 明天有工作。
2. **かいぎ** / 会議 / kaigi — 會議
   - 今日の会議は何時からですか。
   - 今天的會議是幾點開始？
3. **じかん** / 時間 / jikan — 時間
   - 時間がないので、急ぎましょう。
   - 沒時間了，我們快點吧。
4. **まいにち** / 毎日 / mainichi — 每天
   - 私は毎日日本語を勉強します。
   - 我每天學日文。
5. **わかる** / 分かる / wakaru — 懂，了解
   - 質問が分かりますか。
   - 你懂這個問題嗎？
6. **あたらしい** / 新しい / atarashii — 新的
   - 新しいパソコンが欲しいです。
   - 我想要一台新電腦。
7. **つくる** / 作る / tsukuru — 做，製作
   - 私たちはIoTデバイスを作ります。
   - 我們製作IoT裝置。
8. **むずかしい** / 難しい / muzukashii — 困難的
   - この問題は少し難しいです。
   - 這個問題有點難。
9. **つかう** / 使う / tsukau — 使用
   - このツールは使いやすいです。
   - 這個工具很好用。
10. **きゅうけい** / 休憩 / kyuukei — 休息
   - １０分休憩しましょう。
   - 我們休息十分鐘吧。

## 🗾 日文文法（N5）
### 名詞 + が + あります/います
**結構**：名詞 + が + あります / います
「あります」表示無生命物的存在，「います」表示有生命物的存在，語氣輕鬆。
- 部屋に本があります。（房間裡有書。）
- 会社に同僚がいます。（公司裡有同事。）
### 動詞(ます形) + ましょう
**結構**：動詞(ます形) + ましょう
用來提議或邀請對方一起做某事，語氣輕鬆自然，適合日常會話。
- 一緒にコーヒーを飲みましょう。（我們一起喝咖啡吧。）
- 明日、新しいプロジェクトを始めましょう。（明天我們開始新專案吧。）
