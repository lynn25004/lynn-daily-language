## 🇬🇧 英文單字（TOEIC 600-800）
1. **configure** (v.) — 設定、配置系統參數
   - *Can you help configure this new device?*
   - 你能幫我設定這個新裝置嗎？
2. **troubleshoot** (v.) — 排除故障、解決問題
   - *I need to troubleshoot this network issue.*
   - 我需要解決這個網路問題。
3. **integrate** (v.) — 整合、納入新功能
   - *We want to integrate AI into our system.*
   - 我們想把 AI 整合到我們的系統中。
4. **prototype** (n.) — 原型、樣品模型
   - *The team built a new prototype quickly.*
   - 團隊很快地做了一個新原型。
5. **efficient** (adj.) — 效率高的、有效的
   - *We need a more efficient workflow.*
   - 我們需要更有效率的工作流程。
6. **deadline** (n.) — 截止日期
   - *The project deadline is next Friday.*
   - 專案截止日是下週五。
7. **feedback** (n.) — 回饋、意見
   - *Please give me some feedback on this.*
   - 請給我一些關於這件事的回饋。
8. **prioritize** (v.) — 優先處理
   - *Let's prioritize urgent tasks first.*
   - 我們先把緊急任務優先處理吧。
9. **innovative** (adj.) — 創新的、新穎的
   - *That's a truly innovative solution!*
   - 那真是個創新的解決方案！
10. **debug** (v.) — 除錯、偵錯程式
   - *I spent hours trying to debug this code.*
   - 我花了好幾個小時在除錯這段程式碼。

## 📘 英文文法
### Used to (過去習慣、狀態)
用於表達過去經常發生或存在的習慣、狀態，但現在已不再如此。後面直接接動詞原形。
- I used to code all night. (我以前常熬夜寫程式。)
- There used to be a cafe here. (這裡以前有間咖啡廳。)
- He used to work in embedded systems. (他以前做嵌入式系統。)
### Modal verbs for possibility (might, may, could)
這些情態助動詞用於表示可能性或推測，語氣上通常帶有不確定性，後面直接接動詞原形。
- It might rain later. (等一下可能會下雨。)
- The system may crash if we don't update. (如果我們不更新，系統可能會當機。)
- We could finish early today. (我們今天可能會提早結束。)

## 🗾 日文文法（N5）
### ~て ください
**結構**：動詞て形 + ください
用於禮貌地請求或指示對方做某事，類似中文的「請做…」。可以對上級或平輩使用。
- これを よんで ください。(請讀這個。)
- しごとを おしえて ください。(請教我工作。)
### ~が あります / います
**結構**：名詞 + が + あります / います
表示某物或某人存在於某處。「あります」用於非生物，如物品、事物；「います」用於生物，如人、動物。
- ここに ペンが あります。(這裡有筆。)
- へやに だれか います。(房間裡有人。)
