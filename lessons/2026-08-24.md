# 2026-08-24（週一）英日文每日課程

## 🇬🇧 英文單字（TOEIC 600-800）
1. **integrate** (v.) — 整合，將新功能併入
   - *We need to integrate this new feature into the system.*
   - 我們需要將這個新功能整合到系統中。
2. **optimize** (v.) — 優化，使程式最佳化
   - *Let's optimize the code to make it run faster.*
   - 我們來優化程式碼，讓它跑更快。
3. **troubleshoot** (v.) — 排除故障，解決問題
   - *Can you help me troubleshoot this network issue?*
   - 你能幫我解決這個網路問題嗎？
4. **prototype** (n.) — 原型，產品的雛形
   - *We're building a prototype for the new IoT device.*
   - 我們正在為新的物聯網設備建造原型。
5. **deploy** (v.) — 部署，配置軟體
   - *It's time to deploy the new software update.*
   - 是時候部署新的軟體更新了。
6. **collaborate** (v.) — 合作，協作完成專案
   - *We often collaborate with other teams on big projects.*
   - 我們經常與其他團隊在大專案上合作。
7. **deadline** (n.) — 截止日期，任務的最後期限
   - *The deadline for this task is really tight.*
   - 這個任務的截止日期非常緊迫。
8. **feedback** (n.) — 反饋，意見和建議
   - *Please give me some feedback on my presentation.*
   - 請給我一些關於我簡報的反饋。
9. **innovation** (n.) — 創新，引入新方法或產品
   - *Continuous innovation is key to staying competitive.*
   - 持續創新是保持競爭力的關鍵。
10. **scalable** (adj.) — 可擴展的，能應對增長
   - *We need a scalable solution for future growth.*
   - 我們需要一個可擴展的解決方案來應對未來增長。

## 📘 英文文法
### 現在完成式 (Present Perfect)
用來描述從過去某個時間點開始，一直持續到現在的動作或經驗，或對現在有影響的過去事件。
- I have worked on several embedded projects. (我參與過幾個嵌入式專案。)
- She has already finished debugging the code. (她已經調試完程式碼了。)
- Have you ever used this AI tool before? (你以前用過這個AI工具嗎？)
### 不定詞 (Infinitives) 作目的狀語
在句中使用 "to + 動詞原形" 來表示動作的目的或原因，通常回答「為什麼」的問題。
- We came to the office to discuss the new design. (我們來辦公室是為了討論新設計。)
- He uses AI tools to speed up his development process. (他使用AI工具來加速他的開發流程。)
- I study Japanese to achieve my JLPT N5 goal. (我學習日文是為了達到我的JLPT N5目標。)

## 🇯🇵 日文單字（N5）
1. **しごと** / 仕事 / shigoto — 工作
   - 私のしごとはエンジニアです。

   - まいにち日本語をべんきょうします。

   - かいしゃへ行きます。

## 🗾 日文文法（N5）
### 名詞 + を + 動詞(ます形)
**結構**：名詞 + を + 動詞(ます)
表示動詞作用的對象，常用來表達「做某事」、「吃某物」、「喝某物」等。
- ごはんをたべます。 (吃飯。)
- レポートをかきます。 (寫報告。)
### 名詞 + で + (場所/工具)
**結構**：名詞 + で
「で」用於表示動作發生的地點，或是使用某種工具、交通方式來完成動作。
- 会社ではたらきます。 (在公司工作。)
- バスでかいしゃへ行きます。 (搭公車去公司。)
